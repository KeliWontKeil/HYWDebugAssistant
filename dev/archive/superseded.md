## 3. 状态与生命周期类（基线草案 → 定稿）

| 项 | 基线草案 | 定稿（取代者） |
|---|---|---|
| 生命周期阶段集 | `Created → Initialized → Running → Stopping → Stopped → Disposed`，可能还需 `Disabled / Faulted / Recovering` | **ADR-0014**：框架状态机 `Registered → Active ⇄ Disabled → Removed`；前/后者为转换过程；**Faulted/Recovering 不作框架状态**（异常走 Issue） |
| 故障传播语义 | "单模块故障 → 降级/标记下游、阻断支路" | **ADR-0015**：模块"故障"首先是**模块自身状态**；不采用停机/降级/阻断表述；下游"无输入"是合法状态 |
| 核心流程链 | `Workspace → Composition → Core Runtime → Runtime Binding → Module Runtime`（含 "Core Runtime" 旧术语） | 表述更新为"用户拼接声明 → Composition → Core 构成 → Binding → Module 执行" |
