# ADR-0012 Runtime 图景与增量重建/慢消费/护栏（批次 4 首批）

> 状态：Accepted（用户裁决，批次 4）
> 关联批次：批次 4
> 关联主文档章节：§7
> 取代：无 · 被取代：R3（风暴/环护栏中的"可选每口发送护栏/环检测提示"）由 **ADR-0029** C4-1 收窄为"安全护栏（静默）+ 轻量提示（可见）"，不做限流/环检测/阻断
> **收窄/修订说明**：本次收窄仅涉及 R3；R1（增量重建单位）与 R2（慢消费者有界缓冲丢旧）结论不变（R2 的"背压"可选项按 **ADR-0029** C4-1 与 `architecture/07` §7.1 在 v1 不做）。

## 问题

Runtime 域的图景与首批概念裁决：增量重建单位（PQ-RT-01）、慢消费者/丢帧策略（PQ-RT-06）、风暴/环护栏归属（批次 3 Gate 解冻项）。

## 决策

1. **图景（认可）**：组合声明在常驻框架中被解释为一组**模块间的直接绑定（数据通路）**；数据单元流按序**直通**（Core 不中转，§7.2）；无全局 run/stop（模块加入即运行）；变更 = ChangeSet 原子应用 → 增量重建受影响局部；框架统一承载模块活动（自发活动为模块属性，ADR-0004）；模块业务上下文独立于数据面。
2. **R1 增量重建单位（PQ-RT-01）**：重建单位 = **绑定及其邻接数据面**；变更只重织受影响的连接/绑定衔接；**模块实例、配置与业务状态保留**（"插拔线不重置模块"）。删除/替换/配置结构变更才触达模块；配置更新 = 框架通知模块，热生效或请求重建由模块自决（衔接批次 5）。
3. **R2 慢消费者策略（PQ-RT-06）**：**有界缓冲 + 丢弃式默认**（实时场景默认丢最旧保最新）；**不阻塞上游**；策略可由模块口声明（丢旧/丢新/背压可选）。
4. **R3 风暴/环护栏**：框架提供**轻量中立防御护栏**（默认宽松；可选每口发送护栏/环检测提示），仅防失控转发风暴拖垮全局；不改变"自连/环允许"的裁决（ADR-0010）。

## 影响

- §7 新增冻结节；PQ-RT-01/06 关闭；PQ-RT-03/05 部分（策略语义已裁，实现 Gate）；PQ-RT-07 部分（原子 ChangeSet 已裁 ADR-0011，瞬态细节衔接批次 5）。
- Gate 登记：线程/调度/队列与背压实现、复制共享实现、批量传输优化。
