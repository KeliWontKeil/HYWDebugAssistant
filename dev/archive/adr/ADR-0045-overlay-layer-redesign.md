# ADR-0045：叠加信息层重设计（灰玻璃 + 中心类型方块 + 方向渐变流动线）

> **状态**：**Accepted（2026-09 · 用户第十五轮设计草案 + 逐条裁决 D1–D9，已实现，待复验）**
> **关联**：ADR-0039 D5（叠加信息层首次落地）· ADR-0044（方向语义色，D4 悬置项的闭环）· ADR-0034（不做跨窗口覆盖窗）· `09` §6/§8 · `05` §5.18/§5.25 · 主文档 §10.1-4 · `implementation/02` P39
> **修订对象**：`09`（叠加层视觉规格）· `05`（分层与 z-order、消费者表）· 主文档 §10.1-4 + 修订表 **1.0.14** · `implementation/04`（D 组验收项）· `implementation/02` P39 补充

## 1. 背景：用户判定"当前叠加层过于不清晰，甚至看起来像'出了 bug'"

用户原话："当前叠加层过于不清晰，甚至看起来像是'出了 bug'一样"。**根因核查（四条，全部是代码事实）**：

| # | 现象 | 根因 |
|---|---|---|
| ① | 线几乎看不见、像断掉 | 线只从**端口标记中心**画到**窗口边缘**：`Anchor()` 取 `width − Band/2`（标记中心）、`BorderPoint()` 取 `width` ⇒ 长度 = **`Band/2` = 10 px**；两窗拼接后整条线也只有 20px |
| ② | 线**压在标记标签上**、糊成一团 | XAML 中 `<ctrl:ConnectionOverlay>` 排在 `PortMarkers` **之后** ⇒ 画在标记**之上**，9px 对端标签与 11px 网络名互相叠 |
| ③ | "没有箭头"的观感 | **上一轮才修**（`DrawArrow` 缺 `DrawGeometry`，箭头从来没画出来过）⇒ 历史印象 + 线又是残段 |
| ④ | 线太细、颜色来源混乱 | `Pen(1.2)`；线 = `AccentSecondary`（主题派生色）、箭头 = 方向色 ⇒ 同一条线上两种来源的颜色 |

**结论**：不是调参问题，而是**几何起点选错**（用"标记中心"这种中间锚点）+ **层级排错**。

## 2. 用户设计草案（原文要点）

> "1. 叠加层**默认关闭**……它属于**调试/信息观测**用。2. 开启时我希望的视觉效果是'**模块上覆盖了一层灰色玻璃**，然后信息显示在该灰色玻璃上'，信息字体应该较大，可以有较为详细的信息；模块**中心点绘制'方块'**，连线从模块的中心方块处向外连线，线条可以粗一些……线条**颜色以数据流方向决定**，语义色同发送/接收色，**在边界处渐变过渡**，同时使用'**看起来像是在流动的虚线**'；模块有**几种不同的数据类型就有几个中心框**，颜色与数据类型语义色相同（仍然与网络标签一样**先预留**）。"
> 并自陈："可能并不完善以及可实现性不佳，以及部分概念描述/实现冲突。"

## 3. 逐条评估与决策（D1–D9）

| # | 议题 | 裁决 | 落地 |
|---|---|---|---|
| **D1** | 默认关闭 | **默认 `false`**（用户："这正是为何要设计快捷键的原因"）；**旧配置显式值保留** | `ApplicationSettings` / `ModuleViewViewModel` / `ModuleWindowsViewModel` / `SettingsPanelViewModel` 回退值四处的默认改为关；`SettingsService` 的键读取顺序不变（文件里写过就以文件为准）。默认键 = **L**（既有 `HotkeyCatalog.ToggleMarkers`） |
| **D2** | "灰玻璃"怎么实现 | **最简常见实现**：一层半透明深色遮罩（同"弹窗时主窗口变暗"），**不做背景模糊**、**不进设置项** | XAML `Border#OverlayScrim` + token `OverlayScrim`（浅色主题 `#0F172A`@55%、深色 `#000000`@45%）；其上文字用 `OverlayInk`/`OverlayInkMuted`（**两套主题都用浅色墨水** —— 遮罩是深的） |
| **D3** | 线色表达哪个维度 | **线 = 方向**（发送/接收色）、**方块 = 类型色**，两者靠**几何**关联 | 线用 `DirectionSend`/`DirectionReceive` 渐变；方块填充 = `PacketTypePalette.For(type)`（未映射 → 占位色） |
| **D4** | "边界处渐变过渡" | **颜色渐变**（发送色 → **中点色** → 接收色）；未拼接时末端 **alpha 淡出** | `LinearGradientBrush`（绝对坐标端点）：本端方向色 → `MidColor(send, receive)`；未拼接再追加一个"中点色透明"停点 |
| **D5** | 连线起点 | **该口类型对应的中心方块**（不是模块中心一个点） | `LineOf()`：起点 = `BoxCenter(boxes, port.TypeText)` |
| **D6** | 线形 | **直线**（正交折线留作后续评估） | `context.DrawLine` |
| **D7** | 未连接的口 | **画短虚线残段 + `未连`**（40% 透明） | `UnconnectedStubLength = 26`；"没连上"本身是调试信息 |
| **D8** | 动画 | **20Hz 流动虚线，不做开关** | `OverlayAnimationClock`（共享时钟）+ `DashStyle.Offset` |
| **D9** | 信息密度 | **"一眼级"**：标题 / 类型 / 网络名 / 速率 / 对端 / 汇总；详情仍留悬停提示 | 字号 12 / 11 / 10（旧的 9px 太小） |
| **附加** | 层级 | 用户："**压暗模块内容正是我想要的效果**，以突出叠加层的信息，减少凌乱程度" | 层级改为：内容 → **遮罩 → 图形层** → **端口标记** → 按钮簇（**推翻 ADR-0039 D5 的"叠加层在标记之上"**） |

## 4. 视觉规格（生效值）

| 项 | 规格 |
|---|---|
| **遮罩** | 半透明深色（token `OverlayScrim`），覆盖整窗；`IsHitTestVisible=False` |
| **中心类型方块** | 每个 **distinct `TypeText`** 一个：**14×14、圆角 2**；填充 = 类型语义色 @85%；1px 描边；方块**下方**类型文本（11px）；整组（方块 + 文本）在模块中心居中；放不下自动换行（行距 12） |
| **连线** | 起点 = 该口类型方块中心 → 终点 = **窗口边界**上端口带中心线；**直线**；**粗 2.5 DIP**；虚线 `dash 6 / gap 4` |
| **线色** | 本端方向色 →（**中点色**）渐变；中点色 = 发送色与接收色的 50% 混合 —— **两端独立算出的同一个值** ⇒ 拼接处颜色**恰好相接** |
| **流动** | `DashStyle.Offset` 由 **共享 20Hz 时钟**推进；**发送 = 向外、接收 = 向内**（互为相反数） |
| **箭头** | 端部 6px 实心三角，颜色 = 该口方向色（流向 = 发送朝对端边缘、接收朝本模块内） |
| **未拼接** | 末端 14px 淡出 + 标注对端 `实例.口名`（10px） |
| **已拼接** | 不淡出、**不标对端**（线延续到邻窗；标在缝上会糊）——判据 = `PortMarkerViewModel.PeerAdjacent`（新增，由 `AreNodesJoined` 计算） |
| **未连接** | 短虚线残段（26px、40% 透明）+ `未连` |
| **信息** | 左上：`实例名 · 模块名`（12px）· 线旁 45% 处：网络名（11px）+ 速率（10px）· 右下：`投递 Σ · 丢弃 Σ`（10px，**按网络去重**） |
| **调参入口** | 全部为 `ConnectionOverlay` 的公开常量（`LineThickness`/`DashLength`/`DashGap`/`TypeBoxSize`/`Gutter`…）+ `Tokens.axaml` 的三个遮罩/墨水色 |

## 5. 落地（代码事实）

| 项 | 落点 |
|---|---|
| 遮罩 | `ModuleWindow.axaml` 新增 `Border#OverlayScrim`；token `OverlayScrim`/`OverlayInk`/`OverlayInkMuted`（深浅两套） |
| 层级 | `ConnectionOverlay` 从"标记之后"移到**标记之前**（`OverlayScrim` → `Overlay` → `PortMarkers`） |
| 图形 | `Ui/Controls/ConnectionOverlay.cs` **重写**：类型方块、渐变虚线、箭头、信息；`LineBrush`/`ArrowBrush` 等**死属性清理**（P39 纪律：每个公开属性都要有消费者） |
| 动画 | 新增 `Ui/Controls/OverlayAnimationClock.cs`：**一个** 20Hz `DispatcherTimer` + 弱引用订阅；叠加层关闭时**退订**，无订阅者**停表** |
| 纯函数（可断言） | `TypeBoxesOf` / `LineOf` / `MidColor` / `DashOffsets` / `DashPhase` |
| 拼接判据 | `PortMarkerViewModel.PeerAdjacent`（新增）+ `ModuleWindowsViewModel.ResolvePeerAdjacent`（复用既有 `AreNodesJoined`）；`RefreshOverlayPeers` 内一并刷新 |
| 默认值 | 四处默认改为**关闭**（D1）；旧配置键行为不变 |

## 6. 验证

| 层 | 结果 |
|---|---|
| **T0** | `Core.Api` · `Core` · `Ui` · `FrameworkUi` 编译 **0 警告 0 错误** |
| **T1** | `ModuleWindowVisualTests` **15/15**（新增 5 项）· `FrameworkUiTests` **14/14** · `ModuleWindowUsabilityTests` **10/10** · `ModuleWindowsTests` **40/40** · `SettingsServiceTests` **11/11** |
| **新增断言** | ① **默认关闭**（控件可见性 + VM + 设置模型三处）且开关真正控制可见性；② **层级**：遮罩 < 图形层 < 端口标记，且两层都 `IsHitTestVisible=false`；③ **几何**：方块数 = 数据类型数、方块组在中心、线起点 = 方块中心、终点 = 窗口边界、线长 ≫ 旧的 10px 残段；④ **纯函数**：中点色**两端对称**且 = 算术平均、虚线相位 ∈ [0,周期) 且发送/接收**互为相反数**；⑤ **动画纪律**：叠加层关闭时**不订阅**共享时钟、可见时 **+1**、关闭后**退订**；⑥ **拼接判据**：相隔 400px → `PeerAdjacent=false`，紧贴 → `true` |
| **T2 / T3** | **未跑**（按用户裁决：UI 调整期不跑完整门禁，最小验收指标就绪后再跑一轮） |

## 7. 明确不做（边界与后续）

| 项 | 归属 |
|---|---|
| 正交折线路由（多口模块更整齐） | 后续（先看直线观感；折线的虚线相位/圆角更复杂） |
| "静止虚线"开关（无动效） | 后续（觉得晃眼再加；D8 裁决不做开关） |
| 拼接处"淡出"（当前拼接时不淡出，避免公共边出现凹口） | 已按 D4 定为不做 |
| **类型 → 颜色**映射（当前全部是占位色） | 用户提供映射后**只改 `PacketTypePalette`** |
| 叠加层开启时**隐去端口标记的名称文本**（减少与玻璃上网络名的重复） | **待用户复验后决定**（本轮未改标记渲染） |
| 叠加层的说明性文案 / 图例（"粗虚线=数据流、方块=数据类型"） | 需要时进设置项 ToolTip 或 `?` 弹窗 |
