## 0. 怎么跑起来

1. **关闭正在运行的应用**（否则构建写不进 `App` 输出）。
2. 在工程根执行：

```powershell
.\build.ps1                    # 完整门禁，应全绿
.\tools\dev.ps1 -Mode Run      # 启动应用（先停掉 VS 设计器宿主，避免文件锁）
```

**预期**：外壳窗口出现；正式模块包已自动装入 `modules\`（`text-sender` / `hex-sender` / `data-monitor` / `hex-string-converter`），无需手工选路径。

看真实渲染结果（可选）：

```powershell
.\tools\dev.ps1 -Mode Snapshots
```

打开 `artifacts\snapshots\`（叠加层三窗、调色板、八个模块视图；每个页签各一张）。截图**没有自动化判据**，只看“能不能看、挤不挤、字有没有被裁”。

**前置**：① 基础功能可用（外壳与多窗口 · 建网与拓扑 · 配置 · 人机操作三通道 · 持久化与设置）；② 正式模块包可装入可用；③ 先跑一次完整门禁。
