## 怎么读这张表

| 列 | 含义 |
|---|---|
| 键 | 声明面里的键名（写进 `view.json`）。 |
| 类型 | `string` / `number` / `integer` / `bool` / `enum` / `array`。 |
| 必填 | ✔ = 这个 kind 必须写它（漏了是**硬伤**，整份声明作废、界面全空）。 |
| 缺省 | 不写时框架用的值。**`—` = 没有缺省**（必填键才有这一档）。 |
| **适用** | **什么条件下这个键才被消费**。不满足条件时写了**没有任何效果** —— 那是静默，不是特性。写声明照这一列判：满足就写全，不满足就别写。 |
| 取值 | `enum` 的合法字面量。 |
| 说明 | 这个键管什么。 |

## 尺寸轴（`width` / `height` 的写法）

两个轴各写一个对象，对象里**三种口径三选一**（**同时写两个 = 硬伤**：读取器拒绝加载）：

| 写法 | 含义 |
|---|---|
| `{ "pixels": 128 }` | 固定像素（DIP）。适合按钮、单行输入这类就该这么大的东西。 |
| `{ "fill": true }` | 吃满这一层分给它的空间。只对**有上限**的那一层有意义（网格的格子、流式里的宽度）。 |
| `{ "adaptive": true }` | 按内容自适应（这一块要多大由它的内容决定）。 |
| `{ "min": 30 }` / `{ "max": 200 }` | 下限 / 上限，可与上面三种任一同时写。 |

**每个会渲染的元素两轴必写**，一个都不省：轴键整个没写 = 硬伤（几何没有缺省口径）。
绝对坐标 / `panel` 容器里的元素两轴还必须都是 `pixels`（见下）。

## 硬伤与警告

**硬伤**（任一出现 ⇒ 整份声明作废、界面全空，模块加载后宿主会报出来）：

- version 缺失或 ≠ 1
- 未知键 / 未知 kind / 未知枚举字面量
- frame.ports[] 的口名缺失或重名；edge 缺失或不认识；offset 不在 0..1
- 数据面的某个口在 frame.ports[] 里没有条目、或有条目但没有显式 edge（未声明就没有位置 —— 不做惯例推断；宿主读完声明后按数据面口名对账）
- 类型不符；数值小于 min 或大于 max；同轴 min > max
- 某个轴给了多个策略 / 未知策略；**某个轴整个没写**（每个会渲染的元素两轴必写 —— 几何没有缺省口径）；absolute / panel 容器里的元素缺任一个轴，或该轴不是 pixels
- 容器没有 children 或 children 为空
- `tabs` 的直接子节点（页载体）声明了 `width` / `height`（页内容的尺寸由页签那一层决定：`tabs.rows` 分页签条与页内容、页内容按自己的下限占位；载体自己不生成控件）
- grid 里只写 columnSpan / rowSpan 却不给 column / row（跨度没有起点）
- column/row 越界（含 span 越界）；columnSpan / rowSpan < 1
- 引用不存在的 sources 名字；同一角色键写错（如 data 写在 commandButton 上）
- sources 里 name 缺失或重名

**警告**（那一条忽略或夹住，其余照常生效）：

- 非 grid 容器声明了 columns / rows / column / row / span（该条忽略）
- grid 容器里元素声明了 x / y（该条忽略）
- window.max 小于有效下限（该条忽略）
- window.min 小于框架地板（= window.min 的缺省值，由端口标记几何推出）⇒ 夹到地板（否则用户能缩到把端口标记裁掉）
- 声明了 rendered:false 的 kind（已登记、框架尚未渲染 ⇒ 界面会缺这一块，但不拒绝加载）
- frame.ports[] 里的口名在数据面不存在（声明了却接不上，须宿主加载时对账）
- sources 里未被任何元素引用的条目（声明了却接不上）
- views[] 里第 0 个以外的条目（今日只渲染第 0 个）
