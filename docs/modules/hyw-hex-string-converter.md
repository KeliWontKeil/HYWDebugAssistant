# hyw/hex-string-converter（HEX ↔ 字符串转换器）

> 状态：**开发中**（阶段 0 ✅ 已裁 · **阶段 3 ✅ 已实现** · 阶段 4 模块测试 ✅ —— 见 §10）
> 版本：`1.0.0` ｜ 包 ID：`hyw/hex-string-converter/1.0.0` ｜ 代码：`src/Modules/Business/HexStringConverter/`
> **功能角色（层①）**：**十六进制/字符串转换器**
> 一句话职责：一个**离线小工具** —— 把十六进制文本转成字符串、把字符串转成十六进制文本；**没有任何端口、不参与组网**

> 填写规范：`implementation/06-module-standard-and-development-process.md`（§A 四层视角 · §B 判据 · §C 结构 · §D 大小 · §E 七阶段）。
> **用户原始需求（含草图）**："字符串转换工具**不存在任何端口**，它只是一个应用小工具……输入 hex 转字符/字符串，输入字符串转 hex，**如果转换失败，将文本框边框显著标红**，同样可拉伸长宽，**左侧输入框有多个标签，可以储存多条不同消息，也不持久化，重启即丢**。"
> **D4 裁定（用户 2026-09）**：① **char 组与 hex 组各自一个 `TabPages`**，每个 tabpage 提供**多组文本输入区（多个标签页）**，**不持久化，关闭模块就清空**；② **两个方向各一按钮**；③ **点按钮或敲回车**（回车走**应用级设置**的提交键 `multilineSubmitKey`，模块不做声明）。

## 3. 视图

**结构（按 D4 裁定）**：

```
TabPages 「char 组」（N 页，每页一个多行 TextInput：char1…charN）
   └ 每页内：TextInput(该页, InputKind = Text, 多行)  +  CommandButton「转成 HEX」
TabPages 「hex 组」（N 页，每页一个多行 TextInput：hex1…hexN）
   └ 每页内：TextInput(该页, InputKind = Hex, 多行)   +  CommandButton「转成字符」
结果区（每组一个，只读）：charResult（由「转成字符」写入）· hexResult（由「转成 HEX」写入）
```

| 项 | 内容 |
|---|---|
| 元素 | `TabPages`×2（分别含 N 个页；每页 `TextInput` + 一个 `CommandButton`）+ `TextLog`(A5)×2（结果区） |

## 8. 已知限制

- **零口**：不参与组网、不进拓扑；它**不能**被连到任何模块上（这是设计意图 —— 纯工具）。
- **不持久化**：多页内容与结果都是运行期状态；**关闭模块（移除实例）即全部清空**（用户明确要求）。
- **结果行是定宽的**（框架硬约束：同一数据源样本长度一致，上限 1024 字节/行）⇒ 长 hex 串会**折成多行**显示（见 §9 C6）。
- **只支持 UTF-8 文本**（与文本发送器同一口径，`decisions.md` 7.25）：**非法/被截断的字节序列明确报错**（红框），**不静默替换**；十六进制方向**永不丢**（它显示/接收的就是原始字节）。
- **按钮路径依赖 7.27 的框架扩展**：在它落地前，"点按钮转换"拿不到**当前**输入（只能用最后一次提交的值）—— 本模块与四模块**同批**落地，故不阻塞。
- **不做**：字符集选择（GBK 等）· 文件导入导出 · 正则/转义处理 —— 需要时另立模块或扩展页。
