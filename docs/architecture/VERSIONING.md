# 版本与兼容（唯一口径）

> 一页说完：**只有一套版本号、一个写处、一张兼容矩阵**。其余"版本"（模块版本、数据类型版本、格式版本、契约区间）一律不存在。

## 1 唯一的版本号

四段：`主.小.修订.轮次`（`M.m.p.r`）。它**就是**程序集版本，也是 NuGet 包版本 —— 显示、提交标题、发布清单、程序集元数据全部同一个字符串，没有第二种写法。

| 字段 | 含义 | 何时 +1 | 谁决定 | 提升后 |
|---|---|---|---|---|
| 主 `M` | 兼容世代 / 对外承诺。`0` = 开发期未定型；`1` 起 = 承诺不破坏模块与数据契约 | 首次对外发布，或明确断代 | 开发者显式 | 小/修订归 0，轮次归 1 |
| 小 `m` | 能力批次（新增/删除功能、可感知行为变化；0.x 内允许破坏性变更） | 一批功能交付 | 开发者显式 | 修订归 0，轮次归 1 |
| 修订 `p` | 缺陷修复（能力集合不变） | 修完缺陷的构建 | 开发者显式 | 轮次归 1 |
| 轮次 `r` | 该版本线的第几次构建，从 1 起 | 每次交付 / 自测构建 | **脚本自动（唯一自动项）** | — |

**0.x 政策**：主版本为 0 期间不承诺跨版本数据可读、不承诺旧模块包可加载、不承诺同 ID 多版本共存；破坏性变更只需显式提升版本，不需要迁移代码。

## 2 唯一事实源

- 数字只写在仓库根 `version.props`（四段），由 `tools/version.ps1` 写入。
- `Directory.Build.props` 把它拼成一个 `<Version>`；`AssemblyVersion` / `FileVersion` / `InformationalVersion` / NuGet 包版本都由 SDK 从它派生 —— **不得单独覆盖任何版本项**。
- 门禁 `tools/audit-versions.ps1` 拦三件事：多出来的版本字段、代码/资源/文档里的版本字面量、模块清单里的第二段版本。

## 3 提升与提交

| 命令 | 效果 |
|---|---|
| `tools/version.ps1` | 显示当前版本 |
| `-Value` | 只打印 `M.m.p.r`（供其他脚本取用） |
| `-Round` | 轮次 +1 |
| `-Minor` / `-Patch` / `-Major` | 对应位 +1，低位按上表归零 |
| `-Set M.m.p.r` | 显式设置四段（允许跨版本线；低于当前值只告警） |
| `-Commit "<说明>"` | 轮次 +1 → 写文件 → `git add -A` → 提交标题 `M.m.p.r <说明>` |
| `-DryRun` | 只打印，不写盘 |

- 主 / 小 / 修订**从不自动**提升；构建、测试、门禁**从不**改版本。
- **提交是推荐而非强制**：手工提交、不带版本号的中间态提交、跨轮次或跨版本提交都允许；版本号只要求"交付构建那一刻"正确，不要求与每个提交一一对应。
- 手动编辑 `version.props` 也合法（它仍是唯一事实源），只是推荐用脚本避免四段手误。

## 4 什么有版本，什么没有

| 对象 | 有版本？ | 说明 |
|---|---|---|
| 产品构建（全部第一方程序集） | 是（唯一） | 交付 / 排障 / 回滚的指认依据 |
| SDK NuGet 包 | 是（= 产品版本） | 包是产品派生物，不是第二套契约编号 |
| 发布清单 `release.json` | 是（`version` 字段） | 只描述"这次构建" |
| 模块标识 | 否 | 标识 = 作者/模块名；新旧由包内容决定 |
| 数据类型 | 否 | 标识即身份；改形状就是破坏性变更 |
| 设置 / 组合件 / 主题 / 文本表 / 图标表 / 色板 | 否 | 能解析就用，解析失败就报错或丢弃；不迁移 |
| 第三方依赖 | 是，但归中央包管理 | 与本机制无关 |

## 5 兼容与处置

| 对象 | 兼容判据 | 不兼容时 | 数据动作 |
|---|---|---|---|
| 模块 → 宿主 | 程序集能加载、入口实现 `IModule`、依赖可解析 | 拒绝该模块并报错（文案带上编译时引用的 SDK 版本），其余照常 | 不修复，包留在磁盘 |
| 同 ID 模块导入 | 不存在同 ID | 拒绝并提示"退出应用、删除旧包目录后重新导入" | 不覆盖 |
| 默认目录内重建（同 ID） | 无判据，按内容重建 | 标记"需重启" | 重启后生效 |
| 端口 / 数据类型 | 语义相同 + 形状完全一致 + 两侧声明时标识相同 | 拒绝连接并说明差异 | 不自动转换 |
| 组合件 | 可解析 + 记录内标识合法 | 该记录丢弃并告警；结构损坏则整文件拒绝 | 原文件不改 |
| 设置 | JSON 可解析 | 用默认值 + 告警 | 载入时不改写原文件；保存时才覆盖 |
| 主题 / 文本表 / 图标表 | 可解析且形状对 | 跳过该项并告警 | 不迁移 |
| 色板契约 | 可解析（随程序集出货） | 抛出（构建产物坏了） | — |

**禁止**：迁移函数与版本分支、兼容区间语法、旧字段兼容读、为旧包保留的垫片、第二个版本字段。

## 6 常见操作

- **发一次交付构建**：`tools/version.ps1 -Round`（或 `-Commit "<说明>"`），然后正常构建 / 打包 / 发布。
- **改公开契约**：确认影响面 → 直接改；模块全部重编；按 §3 显式提升版本。不写兼容层。
- **改本地文件形状**：直接改读写代码；旧文件要么还能解析（未知字段忽略、缺失字段取默认），要么被明确拒绝。不写迁移。
- **加依赖**：改 `Directory.Packages.props`（第三方版本不属本机制）。
