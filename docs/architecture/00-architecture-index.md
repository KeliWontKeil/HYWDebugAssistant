## 1.1 分册里的〔源: …〕标记怎么读

收敛期重写时为保留可追溯性，各分册在小节后保留了 `〔源: …〕` 标记。读法：

| 标记形式 | 指向 |
|---|---|
| `architecture/18 §2.3`、`04 §4.1`、`06 §6.3` 这类**旧编号** | 收敛前的分册，原文在 `docs/archive/architecture/`（如 `18-network-semantics.md`）；**与现在同名的 01–10 不是同一份**，别混淆 |
| `ADR-0042 D6` 这类 | 归档的 ADR 原文 `docs/archive/adr/ADR-0042-*.md`；其**现行结论**在 `docs/decisions.md` |
| `代码 src/…`、`tests/…` | 代码仓库里的实际实现（**以代码为准**） |
| `implementation/0X`、`主文档 §X` | 现行文档（路径未变） |
**模块文档**（一模块一页：职责 / 声明面 / 配置 / 视图 / 契约扩展 / 验收点）在 `docs/modules/`；开发分**两轨**（模块轨 / 框架轨）与**契约扩展通道**见 `docs/implementation/05-two-track-development-workflow.md`。
