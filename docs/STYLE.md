## 1. 工程基线

| 项 | 现行 |
|---|---|
| SDK | **.NET SDK 10.0.401**（`rollForward=latestPatch`、`allowPrerelease=false`），需 PowerShell 7+；TFM `net10.0` |
| 语言 | `Nullable` / `ImplicitUsings` 开启 · `LangVersion=latest`；`record` / 模式匹配 / 集合表达式可用 |
| 警告 | **`TreatWarningsAsErrors=true`** + `AnalysisLevel=latest-Recommended` + `EnforceCodeStyleInBuild=true`（局部 `NoWarn` 必须注明原因） |
| 分析器 | **仅内置 .NET 分析器**；不引入 StyleCop / Roslynator |
| 依赖版本 | **中央包管理（CPM）**，全部锁在 `Directory.Packages.props`（Avalonia 12.1.2 系列 · CommunityToolkit.Mvvm 8.4.2 …）——版本号以该文件为唯一来源 |
| 风格规则 | `.editorconfig` 随解决方案提供，不依赖全局设置 |

## 2. 命名与文件

| 项 | 约定 |
|---|---|
| 命名 | 类型/成员 `PascalCase`；私有字段 `_camelCase`；接口 `I` 前缀；异步方法 `Async` 后缀；常量 `PascalCase`；**禁止滥用缩写**（`Id`/`Ui`/`Fft` 等公认者除外） |
| 文件 | 一文件一公共类型；文件名 = 类型名；**文件作用域命名空间**（`namespace X;`）；命名空间与目录结构一致 |
| 注释 | **中文**；标识符与 API 名保持英文。注释只承载「**为什么**」（不写日期、不写决定编号、不抄用户原话、不抄读数） |
| XML 文档注释 | **`Sdk` 面向模块作者的公共 API 必须写**；Core/UI 内部公共成员按需 |
| 禁止 | `#region`（用文件分区替代）· `async void`（除事件处理）· `catch` 吞异常 · 热路径 `Thread.Sleep` · 魔法数字（用具名常量） |

## 3. 架构铁律

完整依赖链与各层「可放 / 禁止放」见 [`architecture/CODEX.md`](architecture/CODEX.md) §1。这几条是**违反即失败**（由 `tests/HYWDebugAssistant.ArchitectureTests` 强制）：

- **`Sdk` 零依赖**：不得引用任何框架程序集或 UI 框架（也不得引 `Infrastructure`）。
- **模块只引 `Sdk` / `Sdk.Ui` / `Sdk.AccessKit`**：模块不得引用其它框架层、不得引用任何 UI 框架、不得引用另一个模块；**不得引用 `Access`**（外部接入的适配器/参数类型/catalog 在框架侧）。
- **模块包只带模块自有文件**：`Sdk` / `Sdk.Ui` / `Sdk.AccessKit` / `Access` / 外部接入第三方依赖由宿主提供；模块包内出现宿主程序集即失败（AR-24）。
- **`Ui` / `FrameworkUi` 不得引 `Core` 内部实现**：界面访问运行面只经 `Core.Api`；契约面允许 `Sdk` / `Sdk.Ui`。不得引 `Hosting` / `DataPlane` 实现类型、`Infrastructure`（也不得引模块程序集）。
- **数据面不依赖管理面与 UI**：投递路径里永远不可能出现 UI 等待或 Core 转发。
- **`App` 是唯一白名单组合根**，只做装配，**不得承载业务/机制逻辑**。
- **任何框架程序集不得引用模块程序集**（模块由包加载，不在编译期被依赖）。

**热路径纪律**（数据单元的产生 / 传递 / 解析 / 缓冲 / 绑定，每单元代码路径）：

| 禁止 | 替代 |
|---|---|
| LINQ | `for` / `foreach` + `Span<T>` |
| 装箱、`params object[]` | 泛型 / 结构体 / 重载 |
| 闭包捕获与委托分配 | 缓存委托 / 结构体回调 / 静态方法 |
| 热路径字符串拼接与插值 | `Span` / `StringBuilder` |
| 每单元 `new` / `byte[]` | `ArrayPool<T>.Shared` 租还 + 池化缓冲 |
| 异常作控制流 | 返回值 / Try 模式 |
| 每单元 `Task` 分配 | `ValueTask` |

## 4. 这个项目踩过的坑

> 只留**仍然会重犯**的。看到同类症状先来这里对一遍。

**Avalonia / UI**

- **XAML 警告不受 `TreatWarningsAsErrors` 约束** → 会静静地出现在构建日志里，要单独看。`TextBox.Watermark` 已过时，用 `PlaceholderText`。
- **第三方控件「自带模板」不会自动生效**：没有模板 = 什么都不画，且**不报错**。「控件不出现」按「**有没有模板 → 有没有尺寸 → 有没有被裁/被盖**」排查；每个自绘/第三方控件都要一条「真的出像素」判据。
- **资源类型错误只在运行时炸**（编译期不报，如把 `CornerRadius` 资源写成 `x:Double`）⇒ 视图层必须有真实 App 资源 + 真实窗口的无头用例。
- **资源查找顺序决定覆盖是否生效**（主题字典 → 自身条目 → 合并字典，后加者优先）；覆盖要写在会被优先读到的那一层，并在每次应用前按快照还原上一轮覆盖。
- **`ButtonChrome` 的 `:is(Button)` 必须排除 Toggle 派生控件**：`CheckBox` / `RadioButton` 派生自 `ToggleButton`，而 `ToggleButton` 派生自 `Button`；不排除时它们会拿到 Button 模板，表现为"所有开关变成按钮"。
- **布尔控件只有两种滑块**：宿主界面（设置 / 交互页）用 `UiToggle`，模块视图用 `ModuleToggle`；两者都是轨道 + 圆钮、ON 走 `AccentPrimary`。不要在设置页重新引入 `CheckBox`。
- **模板是一个命名域**：同一模板内两套分支不得用同名 `Name`（被 `IsVisible=false` 的那套也算）；模板内要被定位/被样式命中的元素一律用 `Classes`。
- **自绘必须显式声明「哪些属性变化要重绘」**（`AffectsRender`），每个公开属性都要有消费者。
- **静态 / 单例 / 进资源字典的画刷按跨线程共享处理**（用不可变画刷）。"单独跑绿、一起跑红"先怀疑**共享可变状态**，不要先怀疑测试。
- **全量测试的 `VisualSnapshots` 必须独立进程**：无头渲染平台配置是**进程级**的。
- **零尺寸的几何会被校验过滤**：「边缘 / 线」要用专门通道表达，别用零宽矩形。
- **失焦不是提交**：输入控件的提交只在 Enter / 显式调用发生；失焦只结束编辑。内容靠逐键写入的视图状态承载 —— 否则"点别处"会被模块读成"按了动作"（实测：填完内容随便点一下，发送器就发了一条）。
- **被拒绝的动作撤销并遗忘**：不要跨帧保存"用户意图"再自动生效；否则表现是"报错之后补上参数，它自己就执行了"。
- **只挂 tooltip 的容器必须有背景**（`Background="Transparent"`）：透明背景的 `Grid`/`Panel` 在空白处不参与命中，指针会落到祖先上 —— 症状是"必须指到文字才看得到提示"。
- **提示分层**：短语直接显示；一句解释挂标签 tooltip；多句/教程进分区帮助入口（标题行右侧、弹出层）。帮助与 tooltip 不重复；列表容器不挂提示，条目根挂一个"标题 + 简述"。
- **页面级帮助放在页面顶行、列表框之外**：放进某个列表的框里，读者会以为它是那个控件的帮助；列表的"双击做什么"并入帮助正文，不做常驻提示行。
- **悬停提示的底色必须不透明**：提示层叠在各种界面之上，而带 `surface` 标记的底色会被 `surfaceOpacity` 乘成半透明 —— 提示层要用不参与该乘算的底色（`ToolTip` 用 `BgWorkspace`，别用 `BgChrome`）。
- **标题不许长在控件里**：控件自带标题时，标题的文本宽度会替视图决定邻居还能剩多宽（窄字段的输入框被挤成 0，于是有人改用"标签换行/堆叠"绕开——那只是把毛病换个位置）。标签一律是**独立元素**（`ModuleLabel`），摆在它自己的矩形里；字段的编辑器与标题各一条矩形。
- **文本装不下要"说实话"**：标签与值默认单行 + 省略号 + 悬停全文；状态行这类长度不受控的文本**必须显式声明截断**，否则就是硬切半个字。想让它装得下，先动预留、字号、换行，不要动别人的坐标。
- **单位是文本，不是控件概念**：`ms` / `条` / `个` 就是普通标签；字节计数的 B/KB/MB 在值文本里。不要再给控件加"单位槽"或第二条单位渲染路径。
- **坐标归视图、唯一主人**：每个元素一条矩形；控件只在自己的矩形里排版，不许外扩、不许带外部边距、不许让外尺寸随内容变。坐标全部内联在视图的 `.axaml`（唯一视图事实源、可预览、编辑点一处）；模块之间不共享坐标常量类。
- **可取消的事件不得挂不可逆的副作用**：`ShutdownRequested` / `Closing` 这类"请求/询问"只做决定，不做拆解；真正的收尾挂 `Exit`，并用一次性闸门把执行次数收敛为一次 —— 否则"取消"之后应用还活着、东西已经拆了（表现为模块窗口空着、旧模块唤不回）。
- **退出只有一个出口**：询问 / 保存 / 记住策略 / 关模块窗 / 放行外壳 / 收尾都走 `ShellExitCoordinator`；`Closing` 只做"取消 + 请求"，别在别处再写一套。主窗用 `ClosingBehavior=OwnerWindowOnly`（主窗先决定；取消时子窗一个都不关）。
- **"先拆后关"会留下空壳**：窗口的视图摘除只挂在 `Closed`（取消关闭时子窗的 `Closing` 根本不会到）；管理器要记住窗口的 `Closed` 并从表里移除，别对已关闭窗口再 `Show`。
- **输入控件的框与圈只许画在一处**（`Ui/Styles/InputChrome.axaml`）：宿主、预览器、模块共用一份；`FluentBridge` 与模块主题不许再给 `TextBox`/`ComboBox` 写边框/底色。常态 1px，聚焦/报错用 2px **叠加圈**，聚焦不得改边框厚度（文字不位移）；下拉的选中项不用强调色、不加粗。**chrome 要清掉外来主题的尺寸下限**（Fluent `TextBox` 的 `MinWidth=64`；文本面内层的 `MinHeight/Height`），否则窄框里的右对齐文本会被顶出矩形——尺寸只由视图矩形与上下文样式给。
- **运行期只读不是换控件**：外观通道的 `ReadOnly` 只停止编辑（`IsReadOnly`、不进 Tab 序、隐藏光标），控件与边框都不变；只有"声明只读 / 显示模式"才换文本叶子。
- **框架不许生成"给用户看的句子"**：跨层只传**事实**（状态、端点、失败种类、原始参数值、底层细节），句子由看到它的那一层（模块）用自己的表生成。框架表只放底层诊断（Issue / 异常细节）。判据：把这句话的措辞改掉，改动应该只落在模块表里。
- **配置字段的文本属主 = 声明该接入的模块**，不是参数类型所在程序集：参数类型可以留在框架侧（协议实现需要），但用户是在模块窗口里看这张表单。
- **静默丢弃必须有可见提示**：未打开时的发送被拒要计入事实（`RejectedUnits`），由模块的状态句说明（「… · 发送已丢弃（N 次）」）；禁止弹窗 / Toast，也不要把丢弃藏进计数。
- **故障即释放**：会话级故障后，适配器句柄在实例线程上释放一次，故障态与原因保留；事件 / 泵线程只报事实，不关句柄（串口的 `SerialPort.Close` 在 `DataReceived` 上调用会死锁 / 重入）。
- **计数只在显式清零时归零**：打开 / 关闭连接不清零；清空按钮只清计数，不清队列数据、活动连接数与故障态。

**几何与自绘**

- **一个量化口径**：像素只在一处取整（如 `ScreenPixels.Round`），窗口只做「整数 ÷ 缩放」；**只由驱动者写模型**（交互中被指针拖着的成员不要被刷新回写）。
- **量化"边"而不是"分别量化位置和尺寸"**：模型保持整 DIP，落位时把矩形四边各自取整、位置与尺寸由同一整数矩形反推；分别取整会让 `round(x·s)+round(w·s) ≠ round((x+w)·s)`，在缩放 ≠100% 时表现为拼接处偶发 1px 缝。
- 自绘要换算坐标系：**物理像素 ÷ 缩放**、原点取客户区（`PointToScreen(0,0)`）、根容器 `ClipToBounds`。
- 「**外框矩形**」与「**客户区矩形**」是两个矩形（装饰窗口 `Position` 是外框、`Bounds` 是客户区）；要可见外框请用 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`。
- 判定一律用**事件发生前**的几何，并做成**显式参数**传进去；**别拿被自己移动的对象当输入基准**（自反馈会振荡）。
- 几何函数**要么全用世界坐标、要么全用局部坐标**，跨窗/跨层一律经**显式换算函数**；几何用例失败先怀疑坐标口径。
- **「相对尺寸」是错位之源**：凡「两端各算一半、拼起来要对得上」的几何，尺寸/坐标必须来自**同一个变量**。
- **「留白」是几何参数**：先算最坏情况的实际长度再定留白；极窄尺寸要有明确退化策略。
- **贴边绘制会被自己的裁剪吃掉**：「没画」与「画了看不见」要分开；可见性判据容忍贴边超出，绘制时按「线宽 / 2」内缩，**两条一起改**。

**数据与模型**

- **身份必须由框架给出**；显示名（可空、可重复）永远不能当键。高频刷新路径**一律不抛**（宁可少显示）。
- **可由集合推导的状态一律派生、不要另存**。
- **「同一个值 ≠ 同一个事实」**：用相等判断「有没有变」之前，先确认被比的对象**携带了那个差异**；携带不了就把差异**显式建模**。
- **值语义类型里含集合/数组/字典时，默认相等不可靠**（`record` 的 `==` 会退化为引用比较）——需要值语义就自己写比较并配一条用例。
- **值类型从集合取出后是只读副本**，改动必须写回；「半值半引用」的复合类型最危险（部分生效会掩盖部分失效）。
- **新增公开面字段的同一笔改动里必须写完生产者与消费者**，且两端共用同一来源；断言「来源 / 一致性」而不是某个具体值。
- **「建议」不能混进「问题清单」**：诊断分级必须与消费方语义一致（`Problems` 空 = 合法）；**凡在自家正确样例上报警的检查，先怀疑检查本身**。
- **观测型指标必须可重复读（幂等）**：区分「事件」（消费一次就没了）与「观测」；凡「读的时候才算」的指标都要问「同一次刷新读两次会怎样」。
- **「查不到 ≠ 数值为 0」**：两套「看起来都像键」的标识是静默归零的高发现场，先用一条端到端断言把数值钉住。
- **「指标来源唯一」要落到「只有一个写入点」**；删第二来源时顺手检查它是否还承担了刷新时机 / 口径统一。
- **周期性刷新重建集合会拆掉用户正在交互的控件**（悬停乱闪、游标/弹窗状态归零）⇒ 列表走**增量同步**（结构相等则一个元素都不动）；行模型一律用**值语义 `record`**。区分「刷新数据」（改属性）与「重建视图」（动集合）。

**契约与持久化**

- **给公开构造器/记录加可选参数 = 改签名 = 二进制破坏**（已编译的消费方加载即 `MissingMethodException`）；SDK 新增「可选声明」一律用 **`init` 属性**；**改 SDK 后必须重编全部模块**。
- **格式迁移 = 读旧写新 + 清旧字段 + 升版号**；迁移前先写「旧文件加载」用例；两字段并存时以新字段为准并报警，**不猜测、不静默取旧值**。
- 模块配置走反射式 `JsonSerializer` 时默认**不允许** `±Infinity`/`NaN`、枚举写成**数字** ⇒ `ConfigurationJson.Options` 显式设 `NumberHandling = AllowNamedFloatingPointLiterals` + `JsonStringEnumConverter`；新增配置类型时检查默认值是否含特殊浮点值。
- **「读即登记」**：凡「上层按对象取数据」的接缝都要有明确的「对象从哪来」规则（配置面 = `Read<T>` 首次调用写入默认值，否则只读配置的模块保存组合件时配置整块丢失）。
- **一个「成功/失败」背后有性质不同的原因时，返回值用枚举**（不要挤进一个 `bool`）。
- 在**查询路径**里做文件系统访问会被每帧调用（60 Hz × N 个模块）⇒ 这类判定**在扫描时算一次并缓存**，查询面只读缓存。
- **只读的出厂内容不得住进可写根**：出厂资源在 `resources/seeds/`（只被投放器读），用户数据在 `settings/` `workspace/` `logs/`；**"能不能写"是划分唯一标准**，不要按"看起来像不像资源"分。
- **投放 = 缺什么补什么**：目标存在就一个字都不改（用户可能改过它）；删了不复活靠设置里的投放记录，不靠"每次都重投"；失败要撤掉本次半成品，否则"目标已存在"会让重试永远不再发生。
- **主题是设置的子项**：主题文件夹带自己的壁纸，不要另立"壁纸仓库"再让主题引用——那会让"删主题"和"删壁纸"变成两件事。
- **从 JSON 读浮点一律用不变文化**（`NumberStyles.Float | CultureInfo.InvariantCulture`）：`.` 小数点在非英语区域是千位分隔符，`0.55` 会被读成 55。
- **构建不往用户目录写**：构建产物只有 `resources/` 与 `modules/`；`settings/` `workspace/` `logs/` 只能由运行期创建。

**界面文本**

- **文本是文件、不是代码**：文案住 `resources/i18n/<程序集简名>/<culture>.json`（模块住在包内 `i18n/`），**不要编译进 DLL**；代码/XAML 里新增中文即审计判红。
- **键 = `area.group.element.role`**，同一界面区域的键聚在一起、表内按键排序；占位符只用 `{0}`/`{1}`，需要格式就先在代码里格式化再传参。迁移时**逐字搬移**，不要顺手润色（会把"改文案"和"改行为"混成一次提交）。
- **缺表要响、缺键可见**：表找不到 ⇒ 该拥有者的键显示 `⟦键⟧` 并报一次诊断；缺键只显示标记，由审计在构建期拦。**不许让缺表静默成空白**。
- **豁免必须写理由**：`// i18n-exempt: <理由>` 只给"表还没加载就可能触发"的引导期文案、字体族名这类**不可表化**的东西；审计会打印豁免清单，新增一条豁免等于给自己加一条待复核项。
- **模块文本随模块、框架文本随框架**：模块包带 `i18n/`；声明面用 `DisplayNameKey`/`DescriptionKey`/`TitleKey`/`GroupKey`（键 → 字面量 → 名称，三级回落）；外部接入的参数类型归框架侧，其标题进框架表。
- **快照测试的 headless 会话进程内只建一次且不释放**：per-test `StartNew` + `using` 会在 `Dispose` 抛 `NullReferenceException`（与断言无关的假红）。
- **两类读者、两种写法**：给用户看的（控件/状态/提示/帮助）只写"做什么、结果怎样"，不出现 `契约/承载/订阅/视图状态/落盘/口径` 这类内部词与代码名；给排障者看的（Issue/异常/声明校验）写"动作 + 原因 + 关键值"，异常消息原样附在末尾，不写教学式长句、不引用文档章节。
- **能生成的不写死**：数量、路径、当前快捷键、解析出的绑定都从数据生成（快捷键清单由 `HotkeyService` 生成）；表里只放格式与说明，否则就是死文本。
- **括号只放单位、示例、可选项**；拿括号做补充说明、或同一个控件既挂 tooltip 又在帮助里复述一遍，都要改。
- **测试不得以文案为判据**：断言的对象是**键能否解析、结构对不对**（类别 / 对象路径 / 计数 / 顺序 / 往返），不是文案长什么样。测试里出现文案字面量等于把交付物复制成第二份事实源，文案一改测试就红；数据输出（十六进制、时间戳、单位）用往返 / 分词 / 大小写 / 长度等结构判据，不写死字面量。资源与文本审计第⑦段会拦；确需在断言里比一段测试数据文本时，用 `// i18n-test-data: <理由>` 行级豁免（目标 0 处）。

**流程**

- **同一语义写两遍必然分叉** —— 抽成唯一实现。
- **同类交互出现第二遍就抽公共件**，抽的时候**顺手删旧路径**；「精简」是公共件的准入条件。
- 修一处后**全仓搜同款写法**。
- **「死开关」比崩溃更糟**：设置项可改、可持久化，但没有任何绑定消费它 ⇒ 用户以为功能坏了也不会报错。规则：**每个可交互控件都必须有真实落点**（能指出「谁读它」）。
- 捷径/缓存必须能回答「**读错了会怎样**」，且答案是「**只慢不错**」；答不上来就别加。
- **「设计意图」（功能怎么分解、块之间什么顺序）只能声明、不能从结构反推**；派生只适合「确实是结构属性」的东西（判据 = **能否被结构唯一确定**）。
- 依赖渲染引擎语义的东西（虚线相位 `DashStyle.Offset`、渐变端点、字体度量、像素对齐）**先写能测量的探针**，量**单调可测的量**，并把探针留在测试里当文档。

**资源与图标**

- **图标是显式 SVG**：框架 `resources/icons/<owner>/icons.json` → 相对 `.svg`（**Fluent UI MDL2**，`viewBox 2048`，旧观感）；模块的 `resources/` 由 `module.json` 的 `resources` 声明、模块自己持有（`refresh.svg` 是 **Fluent UI System Icons** 20px，配 24×20 小按钮）；界面用 `ModuleButton.Icon` / `Ui.IconButton` / `Ui.Glyph` 的 `Icon` 取；不要画 `<Path>`、不要写码位/`Glyph*`——改图标 = 改 SVG + 重启，缺键显示键名并由审计/模块包校验拦。
- **框架资源 vs 模块自有资源**：框架 `resources/`（模块共有、只读、只含框架 owner）与模块 `resources/`（模块自有、`module.json` 声明）两套根，互不回退；标准 `i18n`/`icons` 仍由框架 catalog 读模块自己的根，模块自定义 kind 走 `Sdk` 的 `IResourceAccess`；模块不新增框架 kind/审计规则，模块包由 `verify-module-packages` 校验。
- **Avalonia 类型选择器是精确匹配**：`Glyph` 是 `Sdk.Ui.Icon` 的薄子类，`TextBlock.icon` / `Button.icon` 不会命中；图标样式必须写具体类型 `ui|Glyph.icon` / `ui|IconButton.icon` / `ui|ModuleButton.icon`（见 `Ui/Styles/Controls.axaml` / `Sdk.Ui/Themes/Controls.axaml`）；图标按钮与普通按钮同面（`ButtonChrome` 五态）。

## 5. 提交

## 6. 依赖引入

新增依赖必须**同时**满足：

1. **许可** ∈ {MIT, Apache-2.0, BSD, ISC, Zlib…}（构建期门禁自动检查，**含传递依赖**）；
2. 说明**不可替代性**（自研成本 vs 收益）；
3. 记录到 `architecture/CODEX.md` 的对应章节（引入新依赖属根本性决定）；
4. 在 `Directory.Packages.props` **锁定版本**。

**禁止**：GPL/LGPL · 需采购或登录授权的组件 · **无许可声明**的包（首例已拦截：`AvaloniaUI.DiagnosticsSupport`——Accelerate 商业线 + 无许可声明 + 强制遥测）。
