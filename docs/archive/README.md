## 6. 维护规则

1. **单一事实源**：结论只在①/②/③各一处定义，其他文档一律**引用**而不复述（复述必然漂移）。
2. **状态唯一**：章节冻结状态只在 `roadmap.md` 与本文件的表格维护；章节内不重复声明进度。
3. **变更纪律**：改冻结结论 → 新 ADR（Superseded）+ 回写主文档 + 登记修订记录；只改措辞 → 修订记录。
4. **不许共存的失效信息**：被取代的表述必须删除或移入 `docs/archive/`，不得与生效结论并排（见 `superseded.md` §7 教训）。
5. **编号规则**：顶层域用 ADR-XXXX；架构设计用 `docs/architecture/NN[-字母]`（字母后缀表示补遗或专项分析）；不新增并行编号体系。
6. **副本同步**：`docs/methodology/` 为权威源，`.dsh/skills/` 副本修改后须同步（两者内容必须逐字节一致）。
