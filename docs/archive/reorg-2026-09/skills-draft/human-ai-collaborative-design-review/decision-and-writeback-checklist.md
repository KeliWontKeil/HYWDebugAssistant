# 检查清单：拟冻结前 / 裁决后 / 交付后

> 用法：三张表对应流程的三个时点。任一项答"否"就停下来补齐，不要"先冻结再补"。

## 表 1 · 拟冻结前（把一条候选结论变成冻结结论之前）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 层定位 | 我能说出"这是哪一层的问题"，且**上层已冻结**。 |
| 2 | 类型判定 | 它是 A 类（是什么）还是 B 类（怎么做）？**B 类一律转登记，不裁决。** |
| 3 | 类比处理 | 若源头是某个类比/比喻：映射表已写出，**采纳与不采纳及其边界已标注**，且已请人确认。 |
| 4 | 命题化 | 若源头是自由文本裁决：已转写为**编号命题清单**并取得"确认即冻结"的回执。 |
| 5 | 逆例自检 | 措辞已对照**既有不变式 / 反模式清单 / 验收判据**自查，无冲突。 |
| 6 | 无重叠 | 与已冻结章节**无重叠、无一物多主、无循环依赖**。 |
| 7 | 归属 | 若产生了新对象/新原则：它**真的属于本层**（不是在给上层补漏）。 |
| 8 | 替代关系 | 我能说出"**它替代了什么**"。 |
| 9 | 影响面 | 我能列出"**哪些下游表述必须同步改**"（文件 + 章节）。 |
| 10 | 可检查 | 若它是一条"约束"，它**能不能映射到可执行检查**（检索/构建/测试/规则）？不能则说明它只是愿望。 |
| 11 | 记录形式 | 已确定走"新决策记录 + 取代关系"还是"仅修订措辞"。 |

## 表 2 · 裁决后（同一次迭代内完成，不留给下次）

- [ ] 决策记录已写：含**背景 / 候选 / 放弃的方案及原因 / 影响面**。
- [ ] 主文档相应章节已回写。
- [ ] 表 1 第 9 项列出的**每一处下游表述**都已同步改（逐条勾掉，不靠记忆）。
- [ ] 被取代的旧表述**已搬家或删除**——没有任何地方"旧说法与新生效说法并排"。
- [ ] **数量/区间/条目数/版本号**这类量词没有在第二处被复述（只保留指向唯一来源的引用）。
- [ ] 状态只更新了**那一个权威位置**，正文没有重复声明进度。
- [ ] 若引入了例外：例外已登记到**唯一登记处**，并写明**复查条件**（时点或事件），不是"临时"。

## 表 3 · 交付后（人手工验证之前与之后）

**交付前**
- [ ] 报告里明确写了"**我跑了哪一层**"，没有把局部通过说成全量通过。
- [ ] 给出了**可复现的验证步骤**（命令 + 前置条件 + 预期）。
- [ ] 明确写出"**哪部分没验**、由谁验"。
- [ ] 若影响了用户可见行为：验收清单已同步（新增/改写条目，且预期写成"人能看到的现象"）。
- [ ] 临时使用的诊断探针/临时脚本**已删除或已转正为回归断言**（不留半成品入口）。

**交付后**
- [ ] 人的反馈被逐条处理，每条落到"已改 / 已登记 / 已说明不改及原因"三者之一，**没有静默丢弃**。
- [ ] 若人的判断推翻了我的归因：**文档里的归因已更正**。
- [ ] 若本轮出现"口径换代"（新做法取代旧做法）：旧做法**已从生效文档中清出**，测试/断言里的旧口径已一并改掉（不留双轨）。
- [ ] 未完成项**已显式登记**（在哪份文件的哪一行），不是"记得就行"。

## 反模式速查（出现任意一条即停）

1. 无图景先裁内部结构。
2. 主题批内层序颠倒（下层在上层未冻结时被裁决）。
3. 把 B 类当 A 类提问（涉及格式/编号/分类/调度时先判层）。
4. 直接形式化人的类比（缺映射表或确认）。
5. 缺逆例自检（新表述与既有原则冲突未被发现）。
6. 过早冻结递归/嵌套/机制规则。
7. 用"写代码验证设计"绕过结构冻结。
8. 把倾向扩写为结论；代答；打包默认。
9. 同一条结论在两处定义（尤其编号区间、条目数）。
10. 失效旧表述与生效结论并存。
11. 关键约束只写在文档里，没有可执行检查。
12. 治理机制超出收益（批/编号/徽标用得过重，读文档的成本超过写代码）。
