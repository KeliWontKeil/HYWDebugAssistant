## 3. 后期大 ADR 的内容分层与可压缩部分（0046 / 0048–0054）

> 判断口径：**A 类 = 现行设计结论**（必须留）；**B 类 = 决策记录**（谁裁的、替代方案——保留但可压缩）；**C 类 = 实施期发现 / 一次性取证**（可移入变更记录或 LESSONS）；**D 类 = 已过时方案对比**（可删）。
