## 1. A 类：清除已作废内容（快速建网 R0–R6，ADR-0037 D1 整体作废）

### 1.1 `§2.5 用户操作模型` — 行 185

- **原文要点**："**快速建网**：设置项开启时，新加入模块的**未连接接收口**自动匹配既有**未连接发送口**（规则见 §6.2）；'是否参与自动建网'为口级开关。"
- **改后要点**："**建网**：**网络标签同名即连**（命名网络）＋ **接触且对齐即连**（未打标签的口，匿名直连）；**打标签的口只参与命名网络**，**拖开即自动断开**。"
- **依据**：ADR-0037 D2/D3（现行两条机制）· 作废来源 ADR-0037 D1。
- **是否可能丢信息**：**否**。"口级开关"的功能等价物保留 —— 现行规则里"口打上标签"即退出对齐建网（ADR-0037 D3"标签"行），故"口可以选择不参与自动建网"这一**能力**未丢失，只是机制从"开关"变为"打标签"。

### 1.2 `§6.2 组合操作集与快速建网` — 行 544–551 整块（行 540 标题同时改名）

- **原文要点**：`**快速建网规则（R0–R6，ADR-0018）**` 七条 —— R0 设置项默认开/不抢占已连口；R1 主动方=最新加入的模块；R2 新模块未连接接收口匹配既有未连接发送口；R3 优先级（唯一>最近加入>不建网）；R4 契约不匹配跳过；R5 自动命名 `net-N`、断开后不重连；R6 乱序不建网。
- **改后要点**：整块替换为 **B 类新增的现行建网规则**（见 §2）。标题 `组合操作集与快速建网（ADR-0011/0018）` → `组合操作集与建网规则（ADR-0011/0018/0037/0050/0051）`。
- **依据**：ADR-0037 D1/D2/D3/D7（作废 + 现行）· ADR-0050 M1–M14 · ADR-0051 D1。
- **是否可能丢信息**：**逐条核对，无有效信息丢失**：
  - R0/R1/R2/R3/R6（候选选择、最近加入者、抢占、乱序）**整体作废**（ADR-0037 D1 明确："其'候选选择/最近加入者/抢占'等语义只对'加入即连'有意义"）；
  - R4"契约不匹配 → 跳过候选"的**现行等值**已写入新规则（"**不兼容即忽略、不自动转换**"，ADR-0051 D1/D3）；
  - R5 的"自动命名 `net-N` + 可改名 + 手动断开后不再自动重连"：**"自动命名 `net-N` + 可重命名 + 冲突提示"仍有效**，已在同节 §6.3"命名"条（行 565）保留；"手动断开后不再自动重连"随"加入即连"作废而失去对象（现行对齐网络由几何派生、拖开即断、拖回即重连，ADR-0037 D2"生命周期"），**未丢失现行事实**。

## 3. B 类：新增内容 —— §6.2 现行建网规则（唯一新增）

- **位置**：`§6.2`（标题行 540）+ 正文行 544–555。
- **性质**：**本轮唯一新增的规范表述**（其余改动均为删除/改写/对齐）。
- **依据逐条**：

| 新规则条 | 结论来源 |
|---|---|
| 两条机制（命名网络 = 标签同名即连；对齐网络 = 未打标签 + 接触且对齐） | ADR-0037 D2 |

| 建网/拆网判定：每次变更提交后整体重算、不做增量；派生网络先移除再重建；拖开即断开；加载与显式网络不动 | ADR-0037 D2（派生 vs 显式 / 触发时机 / 生命周期）|
| 判定只有一份实现（`DockRule`）+ UI 只经 `Core.Api` 预览查询 + 建网只在布局提交后 | ADR-0037 D3/D4 |
| 口两态与严格单向 | ADR-0022（经 ADR-0051 D3 保留）|
| 多源 N:M：同名标签多发送端一条网络 · 逐 (源,宿) 对 · 按到达 · 来源不进数据面 · 宿口多路合法 · 几何不自动合并 · 停流规则 | ADR-0050 M1/M2/M3/M4/M5/M6/M8/M9 |
| 与兼容规则的关系：传递语义一致 + 形状完全一致才可建投递；不兼容保留声明 + Issue；不自动转换；同一宿口永不混入两种长度 | ADR-0051 D1/D2/D3 |
| 开关 `alignAutoNetwork`（含旧键兼容读） | ADR-0037 D7 |
| 不引入业务分类 | ADR-0004/P16（原 R0–R6 块尾条，保留）|
| 细节指向现行分册《网络语义》（不写文件名） | 任务纪律 §B3 |
