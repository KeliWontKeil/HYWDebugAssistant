# ADR-0005 领域模型细节裁决（Definition 组成 / 归属 / 端口 / 类型边界）

> 状态：Accepted（用户裁决，批次 1）
> 关联批次：批次 1（回审）
> 关联主文档章节：§4.4、§4.5、§4.6、§4.7
> 取代：无（前置：ADR-0002/0003/0004 提供支点）
> 被取代：部分条目（持久化归属表述）被 ADR-0016 取代

## 问题

在模块构成分层与模块—框架运行机制（ADR-0004）冻结后，回审四个挂起点状问题。

## 决策

1. **PQ-DM-01 Definition 组成**：Definition = 框架可加载模型的**对外声明集合（6 项）**：①身份与版本标识；②目录/用户元数据；③对外契约声明（Interface 集合，契约语言批次 2）；④可配置项声明（Configuration Schema，语言 Gate）；⑤可选视图声明（形态批次 7）；⑥宿主/生命周期能力声明（批次 5）。**实现手段（原语层+行为层）属模块实现域（SDK，技术选型后），不进入 Definition 对外语义**；Composite 属组合复用层，与 Definition 并列不混（ADR-0003）。
2. **PQ-DM-03 归属**：Configuration = Instance 持有、可持久化（Schema 在 Definition）；Runtime State = 运行期数据、通常重建（"记忆"需求走 Configuration）；Presentation = 运行期由 Instance 派生的视图、不持久化（视图偏好可入 Configuration/Layout）；Layout = Workspace 会话内容、随保存单元持久化（机制批次 6）。
3. **PQ-DM-04 接口实例（端口）**：确认存在**端口级接口实例端点**；Connection 两端锚定端口而非 Definition 的契约声明；多同型接口由此可区分（命名/编号/契约匹配细化批次 2）。
4. **PQ-DM-09 类型边界**：Definition **不携带业务数据类型声明**；模块间交换 = 契约化载荷（形状由 Interface 契约描述，语言批次 2）；Core 对具体类型无知（P16）；Config Schema 基础类型属配置声明，不属业务数据流类型。

## 影响

- PQ-DM-01/03/04/09 关闭；§4.4/§4.5/§4.6 回写。
- 为批次 2（Interface/契约语言）与批次 6（持久化机制）提供前置边界。
