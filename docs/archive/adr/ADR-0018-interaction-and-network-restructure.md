# ADR-0018 交互与连接重构：几何/连接解耦 + 网络统一模型（批次 7 首批）

> 状态：Accepted（用户裁决，批次 7）
> 关联批次：批次 7
> 关联主文档章节：§2.5、§6.1、§6.2、§6.3、§10
> 取代：P9 语义（吸附=兼容的 UI 表现）、§2.5 操作模型、§6.2 操作集、§6.3 拓扑构造形态；并修订 **ADR-0008 第 5 条**、**ADR-0010 S1①**、**ADR-0017 重锚定口径**
> 被取代：**ADR-0037**（第 4 条**快速建网规则 R0–R6 整体作废**）；其余条款仍生效

## 问题

批次 7 形态论证中用户提出：定型"结构块"难以给出好形态（复杂拓扑排版混乱、动态实现困难），倾向原理图式"网络标签"；进而提出更彻底的构想——**把网络功能内化为"口"自身的一部分**（口上展现网络名/方向/连接状态），**使几何吸附与连接建立彻底解耦**。

## 决策

1. **几何/连接解耦（N1）**：**吸附与拼接仅作为位置排列/对齐**（排版与美学），不再承担连接语义；**连接完全由"网络（Network）"承担**；模块拼接过程不作为连接操作呈现。
2. **网络统一模型（Q1）**：连接统一为**网络**——直连 = 匿名网络，标签 = 命名网络；文档层/持久化/重锚定/Issue 归属均只有"网络"一种声明。
3. **网络标记 = 口的一部分（Q2 落点）**：网络表现依附于**口**（模块边缘内部）：网络名（弱化显示）+ 方向标识 + 连接状态；**方向语义默认按口的能力自动判定**（发送口为源、接收口为宿），可选显式标注（多源冲突 → Issue 标注不阻断）。
4. **快速建网规则（R0–R6）**：
   - R0 设置项"快速建网"（默认开）；只处理尚未加入网络的口，不抢占、不改动已连口；
   - R1 主动方 = 最新加入的模块实例（按添加顺序）；
   - R2 匹配方向 = 新模块的**未连接接收口** → 既有模块的**未连接发送口**；新模块的发送口**不主动匹配**（等待下游加入）→ 按数据流顺序添加即成链；
   - R3 优先级 = ①候选唯一→建网；②多候选→取**最近加入**者（时间序）；③仍歧义→**不建网**并提示候选数（宁可少连不可连错）；**几何位置不参与优先级**；
   - R4 契约不匹配 → 跳过该候选（可提示）；
   - R5 自动网络标记为"自动网络"（自动命名 `net-N`，可改名）；**用户手动断开后不再自动重连**；
   - R6 乱序（无法按 R2 匹配）→ **不自动建网** + 提示可手动建网（不猜、不反向补连）。
   - **不引入业务分类**：源/过程/汇的差异由**口的方向能力**天然体现（符合 ADR-0004/P16）。
   > **已失效**：由 **ADR-0037 D1** 取代（快速建网"加入即连"机制被整体作废，改为"标签同名即连 + 接触且对齐即连"）。本 ADR 第 1/2/3/5/6/7 条（几何与连接解耦、网络统一模型、网络标记依附于口等）仍生效。
5. **命名策略（N4）**：自动命名（`net-N`）+ 可重命名 + 冲突提示；名字默认弱化显示（色/符号为主），悬停/展开看全名。
6. **连线呈现（N3）**：网络连线**默认隐藏**；**热键 + UI 切换按钮**显示；显示时为模块间**有向/流动样式**（流动视觉）；口上网络标记为常驻基本信息。
7. **分线器视觉件正式撤销（Q4/N5）**：由"网络标记 + （可选）连线"取代；有状态结构操作仍为内容模块（ADR-0010 不变）。"阻止吸附"问题**消解**——口级开关变为"是否参与自动建网"。

## 影响

- §2.5（操作模型：吸附=对齐；建网/断网=连接操作）、§6.1–§6.3（网络统一模型、操作集重述、拓扑构造=网络标记）、§10（形态与呈现规格）、§17.3 去向表 P9 行、术语表（新增"网络 Network"）。
- 机制层不变：网络展开为绑定（ADR-0008/0010、§7.2）；持久化按网络成员重锚（ADR-0017 适配）。
