# ADR-0009 Interface 收尾（统一数据面 / 生命周期 / 约束登记）

> 状态：Accepted（用户裁决，批次 2）
> 关联批次：批次 2
> 关联主文档章节：§5
> 取代：无 · 被取代：无
> **正文落点说明**：本 ADR 结论已并入主文档 §5（生效）；批次 10 文档瘦身时其逐条索引迁出至 `docs/archive/pq-closed.md`（PQ-IF-08~11）。**结论仍生效**，索引位置见该归档文件。

## 问题

PQ-IF-08/09（控制/命令/状态是否特殊化为独立接口语义）、PQ-IF-10（Interface 生命周期语义）、PQ-IF-11（形状之外约束表达）。

## 决策

1. **统一数据面（PQ-IF-08/09，方案 A）**：不设特殊"命令接口/控制接口/状态接口"类型。一切内容经数据单元流 + 契约；运行期控制（命令）= 模块声明的数据口（发送/双向）承载命令消息；模块状态 = Runtime State + 上报通道（批次 5），不占数据口；界面按钮/仪表属视图/配置面。命令/数据/事件是**契约传递语义**而非接口种类。
2. **PQ-IF-10 关闭**：口 = 模块成员，生命周期随模块实例（§4.10/对象卡）；连接生命周期属组合/绑定（批次 3/4）；无独立 Interface 生命周期层。
3. **PQ-IF-11 登记 Gate**：契约可含提示性标注（如"高频连续流"）供 UI/调试参考，不作语义；速率/背压/缓冲等通信机制语义归批次 4/Gate（衔接 PQ-RT）。

## 影响
