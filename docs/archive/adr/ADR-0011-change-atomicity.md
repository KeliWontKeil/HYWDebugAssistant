# ADR-0011 变更原子性（PQ-CP-08）

> 状态：Accepted（用户裁决，批次 3）
> 关联批次：批次 3
> 关联主文档章节：§6.2
> 取代：无 · 被取代：无

## 问题

全在线变更（§7.1）下每个组合操作即时生效；"替换模块并重连"等多步操作需避免半成品状态与部分失败的残留（PQ-CP-08）。

## 决策

**单操作原子 + 复合 ChangeSet**：
- 单个组合操作（Connect/Disconnect/Add/Remove/Enable/Disable…）原子——要么完整应用、要么回滚一致，无半状态；
- 需要多步一起做（如替换模块并重连）时，由 UI/命令层组装为**一次复合变更（ChangeSet）**：Core 整体校验（规则 + 能力/契约）→ 一次性应用 → 增量重建；任一步失败则**整体拒绝**；
- 无跨用户会话的全局事务/锁（单用户桌面 + 全在线场景不匹配）。

## 影响

- PQ-CP-08 关闭；批次 3 全部裁决完成并冻结。
- ChangeSet 概念进入组合操作语义（§6.2），供批次 4（增量重建单位）衔接。
