# ADR-0019 Presentation 余项（无 UI 模块 / 多链路组织 / 解耦收敛 / 方向语义）

> 状态：Accepted（用户裁决，批次 7）
> 关联批次：批次 7
> 关联主文档章节：§10
> 取代：无（补充 ADR-0018） · 被取代：正文第 3 条"模块自定义视图由模块提供"由 **ADR-0026**（C1-3）与 **ADR-0028**（Q3-7/路线 d）改为"视图由框架按模块声明渲染，模块不提供 View 类型、不依赖 UI 框架"
> **收窄/修订说明**：仅第 3 条（Presentation/Runtime 解耦收敛）中的"模块自定义视图由模块提供"被收窄；第 1 条（无 UI 模块）、第 2 条（多链路组织）、第 4 条（网络方向语义）结论不变。

## 决策

1. **无 UI 模块（PQ-PR-02）**：**允许**（纯逻辑/服务型模块）；其状态/配置通过**兜底入口**访问（模块清单/管理视图，列出全部实例），避免"无 UI 即不可管理"；有 UI 模块的视图形态由模块声明（ADR-0005）。
2. **多链路组织与呈现（PQ-UX-05 / PQ-PR-04）**：**无分组容器**（延续无容器定性）——所有模块视图在同一模块区**自由排列**；链路靠**网络标记同色/同符号**视觉区分；提供**聚焦/高亮**（选中网络或模块 → 相关者高亮、其余弱化）；用户以位置自由分组（排版自由）。分组框/泳道/多页面为可选 UX 元素，非框架概念（Gate）。
3. **Presentation/Runtime 解耦收敛（PQ-PR-07）**：视图 = **Instance 的派生物**（独立开关/重排，不影响运行）；**口上标记（网络名/方向/状态）由框架渲染**（ADR-0006 成员机制）；模块自定义视图由模块提供；运行由 Core 承载——**无需额外解耦层**。
4. **网络方向语义确认（Q2 落点）**：默认按**口的能力自动判定**（发送=源／接收=宿）+ **可选显式标注** + 多源冲突 → Issue（不阻断）。
