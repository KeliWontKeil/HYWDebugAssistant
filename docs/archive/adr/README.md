## 3. 编号规则与模板（来源：ADR-0000 §2–§5）

- **编号连续递增**：`ADR-0001`、`ADR-0002` …；`ADR-0000` **保留给规则文件本身**。
- **文件名**：`ADR-XXXX-<英文 kebab-case 短名>.md`。
- **引用格式**：`见 ADR-0001` 或 `（ADR-0001）`。
- **状态机**：

  ```text
  Proposed ──→ Accepted ──→ Deprecated
      │            │
      └──→ Rejected         (或被) Superseded（由新 ADR 取代）
  ```

  | 状态 | 含义 |
  |---|---|
  | Proposed | 已提出，等待人工评审 |
  | Accepted | 评审通过，成为冻结决策（须同步回写主文档） |
  | Rejected | 被否决（保留记录，说明否决理由） |
  | Deprecated | 曾接受，现已弃用（说明替代） |
  | Superseded | 被后续 ADR 取代（注明取代者编号） |
- **纪律**：只有**人工（用户）评审通过**的决策才可标 `Accepted` 并回写主文档；实现 / 设计 Agent 不得自行提升状态；
  推翻已冻结决策**不得静默修改**主文档，必须新开一条 Superseded/Deprecated 记录；
  仅涉及措辞/排版（非语义）的变更无需 ADR，直接走主文档修订记录。
- **实践偏离（如实登记）**：规则称"正文不可改写，只在头部标注取代关系"，但 ADR-0046/0048/0049/0050/0052/0053 等在**正文内**就地下插了"已由 00XX 修订/作废"注记。本轮收敛**沿用既成事实**，不回溯改写正文。
