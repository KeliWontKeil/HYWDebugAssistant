# ADR-0043：端口标记内容重排（类型窄色条 · 名称去状态后缀 · 箭头放大 · 指示灯加大贴边 · 类型只进悬停）

> **状态**：**Accepted（2026-09 · 用户第十三轮反馈要求，已实现，待用户复验手感）**
> **关联**：ADR-0037（端口标记标准化）· ADR-0039（模块窗口视觉 + 叠加信息层）· ADR-0041（第十一轮 UI 修订）· `05` §C5-2/§5.15/§5.22 · `09` §5/§7 · `UI-ADJUST.md` §3 第十三轮

## 1. 背景与问题

用户第十三轮对**端口标记（模块网络标签）**提出一组"看起来不对、但根因不在颜色"的问题，原话要点：

| # | 用户反馈 | 归属 |
|---|---|---|
| ① | "标签长了就**溢出错位**" | 排版：文本驱动的三段式布局没有固定槽位 |
| ② | "**箭头太小**看不清" | 尺寸 |
| ③ | "指示灯**半径 +1**，并**移到最边缘**" | 尺寸 + 位置 |
| ④ | "标记上**不要显示连接状态**" | 信息冗余（灯已经表达） |
| ⑤ | "标记上**不要显示数据包类型**（标签名都很长，放不下）"；但**悬停可以显式给出类型** | 信息分层 |
| ⑥ | "悬停里**不要显示'上次操作'**" | 瞬时状态不入悬停 |
| ⑦ | "编辑弹窗**太大**；提示信息**收进帮助按钮**（像主界面那样）" | 弹窗尺寸 + 文本规则 |
| ⑧ | "标签后的'**（未连）**'去掉" | 冗余后缀 |
| ⑨ | "加一条**窄的颜色条**表示**数据包类型**；这个颜色**先预留可修改**，映射方式我之后告诉你" | 新元素 + **待定映射** |

用户附了一张**手绘草图**（自述"画得不准确"）：蓝色色条在左端 → 网络名 → 橙色向上箭头 → 绿色指示灯（带圈）。草图只作**读数顺序**的提示，不作像素依据。

## 2. 现状核查

| 项 | 现状 | 结论 |
|---|---|---|
| 排版 | `ColumnDefinitions="*,28,12,Auto"` 四段（名称/类型/箭头/灯），**但不是四段都固定宽度**：名称 `*` 与灯 `Auto` 随内容/尺寸变化 | ① 的根因：**槽位不固定** ⇒ 名称一长就挤压右侧、类型文本还给"挤没了"加一层抖动 |
| 类型 | 标记上**显示类型文本**（占 28 px 槽位） | ⑤ 的根因：类型文本与长网络名抢同一条 114 px 的标记 |
| 连接状态 | `NetworkText` 在未连时追加"**（未连）**"，同时还有指示灯 | ④⑧ 的根因：**同一件事说两遍**，且"（未连）"抢宽度 |
| 悬停 | `PortMarkerViewModel.EditResult`（"上次操作"结果文本）被写进 `Tooltip` | ⑥ 的根因：**瞬时状态**（最近一次操作结果）被持久化到标记状态并常驻悬停 |
| 编辑弹窗 | `Width="268"`，**行内**展开多句提示 | ⑦ 的根因：把"说明书"放进弹窗正文，违反既有文本规则（`UI-ADJUST.md` §0：多句 → `?` + Flyout） |

## 3. 决策

### D1. 标记槽位**固定四段**，顺序 = 读数顺序

| 槽位 | 宽度 | 内容 |
|---|---|---|
| ① **类型窄色条** | **6**（`PortMarkerStripWidth`） | 数据包类型（颜色 = **占位**，见 D5） |
| ② **网络名** | `*`（吃剩余） | `NetworkText`；超长 `CharacterEllipsis` |
| ③ **方向箭头** | **20** | 字号 **16**（`PortMarkerArrowFontSize`）；发送 = 主色、接收 = 次色（按边向外/向内不变） |
| ④ **连接指示灯** | **8**（`PortMarkerLampSize`，`Auto`） | 贴到标记端部（**Margin = 0**，不再留 3 px） |

- 标记占地**不变**（竖排 20×114 / 横排 114×20），**贴边不变**；变的是**内部槽位**。
- **顺序的语义**：竖排分支整体旋转 −90°（把 `(x,y)` 映射为 `(y,−x)`, ADR-0039 D3），内容 `x` 小的一端落到**屏幕下方**（文字自下而上读）⇒ "色条在最前、灯在最末"在屏幕上表现为 **灯在上端、色条在下端**，与草图给出的**读数顺序**一致。
- 该结论**由无头测试钉住**（`ModuleWindowVisualTests.端口标记_类型色条与指示灯应贴在标记两端`），不再靠纸面推演。

### D2. 标记上**不显示**连接状态文本与数据包类型文本

- 删除"（未连）"后缀；`NetworkText` 只剩三种取值：**标签名** / 已连但无标签 = `（直连）` / 无标签且未连 = `无网络`。
  - 说明：`（直连）`、`无网络` 是**网络名占位**（"这条网络叫什么"），**不是连接状态提示**；连接状态统一由**指示灯**（颜色 + 形状双重编码）承担。
- 标记上**不出现类型文本**；类型只在**悬停提示**里显式给出。

### D3. 悬停提示：给出**类型**，剔除**瞬时状态**

- 保留：`口名（方向）` · `状态` · **`类型：X`** · 网络名/网络/对端/投递/丢弃/流量 · `双击填写/清除网络名`。
- 删除：**"上次操作"**（`PortMarkerViewModel.EditResult` 字段整体移除，`CommitPortLabel` 不再写它）。
- 反馈闭环不丢：提交结果仍**返回并送状态栏**（`RaiseNotice`），只是不再挂在标记上。

### D4. 编辑弹窗：**收窄** + 提示进 `?` 帮助弹窗

- `Width: 268 → 188`（只放"标题 + 输入框 + 按钮"）。
- 行内多句提示**移除** → 标题右侧 **`?` 帮助按钮 + Flyout**（`Button.helpIcon`，与外壳各页同一做法：点击弹窗、点外部关闭、**不占版面**）。
- 失败原因仍在弹窗内就地显示（ADR 前置：失败保持打开，不丢用户输入）。

### D5. 类型颜色 = **可替换的占位**（映射待用户给出）

- `PacketTypePalette`（`Ui/ViewModels`）：`Map`（**当前为空**）+ `Placeholder`（`#9AA4B2`，中性灰蓝）+ `For(typeText)`（未映射 → `Placeholder`）。
- `PortMarkerViewModel.TypeBrush => PacketTypePalette.For(TypeText)`。
- **映射落地时只改 `PacketTypePalette`**（往 `Map` 里加条目）：**视图模型与 XAML 都不动**。

## 4. 落地（代码事实）

| 项 | 落点 |
|---|---|
| 尺寸 token | `Tokens.axaml` 新增 `PortMarkerArrowFontSize=16` · `PortMarkerLampSize=8` · `PortMarkerStripWidth=6`（标记本体 20/114/字号 11 不变） |
| 标记模板 | `ModuleWindow.axaml` 两条分支（竖排/横排）统一 `ColumnDefinitions="Auto,*,20,Auto"`；色条 `Border` + 灯 `StateIndicator` 用 **`Classes`（`typeStrip` / `markerLamp`）**标识而**非 `Name`** |
| 新元素 | 色条 `Background="{Binding TypeBrush}"`（宽取 token）；灯 `Width/Height` 取 token 且 `Margin=0`、`HorizontalAlignment=Right` |
| 视图模型 | `PortMarkerViewModel`：删 `EditResult`；`NetworkText` 去"（未连）"；新增 `TypeBrush`；`Hint` 改述为**帮助弹窗文本**；`OnTypeTextChanged` 追加通知 `TypeBrush`/`Tooltip`；`OnPeerTextChanged` 追加通知 `Tooltip` |
| 调色板 | `Ui/ViewModels/PacketTypePalette.cs`（新增；`For` 走空表 → 占位色） |
| 弹窗 | `Width=188` + 标题行 `Grid ColumnDefinitions="*,Auto"` + `Button.helpIcon` → `Flyout` 绑 `{Binding Hint}` |
| 调用方 | `ModuleWindowsViewModel.CommitPortLabel` **删除** `marker.EditResult = message`（状态栏 `RaiseNotice` 保留） |

### 4.1 附带踩坑（已记入 `implementation/02` P38）

模板里**两个分支（竖排/横排）处于同一命名域**，给对应元素取**同名 `Name`** 会直接抛
`Control with the name 'TypeStrip' already registered.`（**运行时**、首次布局时才炸）。
⇒ 模板内需要被测试定位的元素一律用 **`Classes`**（`portMarker` 已是此做法）。

## 6. 边界（本轮**没有**改的）

- 标记占地 20×114 / 114×20、**与外边框重合**、`PortMarkerPanel` 定位与命中不变；
- 指示灯仍由**连接状态**驱动（`StateVisual`），只是变大贴边；
- "即将自动建网"高亮、窗内连线/对端信息（叠加信息层）不变；
- 双击标记 → 弹窗 → 提交/清除/取消的**交互链路**不变（只收窄版面、搬走提示文本）；
- 类型 → 颜色**映射未定**，占位色是**刻意中性**的（不假装已分类）。
