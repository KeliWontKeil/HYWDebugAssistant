# ADR-0010 结构块专题与组合概念（S1/S2/S3/C1/C2 · Supersede P5/P6 域结论）

> 状态：Accepted（用户裁决，批次 3）
> 关联批次：批次 3
> 关联主文档章节：§4.3、§6.3、§6.4
> 取代：P5/P6 域结论（§4.3 原"Module 分 Functional/Structural；Structural 仍是普通 Module"）
> 被取代：S1 ①（拓扑构造"视觉承载"表述）被 ADR-0018 取代（网络标记依附于口；分线器视觉件撤销）

## 问题

PQ-IF-07 已登记"拓扑视觉由结构块承载、模块保持单口外观"（ADR-0008）；IF-B 已裁无状态分发归连接机制。结构块从"功能模块"淡出的方向需正式定稿（解冻此前"暂缓结构块"），并裁决 Composition 概念层（连接建模/环与自连/验证）。

## 决策

1. **S1 结构块本体**：结构块**退出模块分类**，定位为**组合层"拓扑构造元素"**：① 组合文档层表达分线（1:N）/汇线（N:1）拓扑与视觉承载（模块保持单口外观）；② 运行时层纯拓扑构造**映射到绑定机制多播/汇合，无独立转发对象**；③ 带逻辑的结构操作 = 普通内容模块（S2）。**P5/P6 Supersede**：框架只维护"内容模块"一类；"功能/结构"仅作用户侧角色描述，不构成框架机制。
2. **S2 逻辑结构模块**：缓冲/同步/聚合/条件路由 = 普通内容模块（作者实现、按功能命名），不再用"结构块"类名。
3. **S3 连接建模**：多播拓扑连接 = **单声明对象（一个源口 + N 个目标口）**；绑定展开 N 条直连管道（机制复制）。
4. **C1 环/自连/重复**：自连**允许**（只要能力/契约判定可连；无意义自连按"合法但无意义"标注，不设禁）；**风暴/无限递归防护属另一层运行机制**（Gate：批次 4/后续），连接规则不管辖；环**允许**存在 + UI 提示；重复连接**去重幂等**。
5. **C2 验证两级制**：编辑时规则校验（自连无禁、重复去重等即时提示）+ 建立时能力/契约判定并标注（可连/无数据流/不可连）；**无运行前全量闸门**（全在线语义）；设计错误与"无数据流"分两类呈现（§8.2 类 a）。

## 影响

- §4.3 分类修订（框架仅内容模块一类）；§6.3 重写（拓扑构造 + 连接模型 + 逻辑模块）；§6.4 PQ 状态更新；§17.3 去向表 P5/P6 标注修订。
- PQ-CP-02/03/04/07 关闭；PQ-CP-08（原子性）批次 3 后半；PQ-CP-06 → 批次 5；PQ-CP-09 → 批次 4；PQ-SC-01/02 重定义。
