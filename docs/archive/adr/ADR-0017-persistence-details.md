# ADR-0017 持久化细节（格式/分工/异常加载/重锚定 · PQ-PS-01~04）

> 状态：Accepted（用户裁决，批次 6）
> 关联批次：批次 6
> 关联主文档章节：§9
> 取代：无（前置：ADR-0016 组合件载体模型）
> 被取代：重锚定/连接口径表述由 ADR-0018（网络统一模型）修订

## 决策

1. **PS-01 格式与版本迁移**：**文本格式方向**（可读、可 diff、易迁移；组合件只含声明）——具体格式（JSON/TOML/…）→ Gate；文件**内嵌 Schema 版本**；加载时**能迁移则自动迁移，不能则明确拒绝并保护原文件**（不破坏、不静默降级）。二进制/大数据（录波）另行考虑（Gate）。
2. **PS-02 序列化分工（含前向保真）**：Configuration 按 Definition 的 Schema 序列化（**未知字段保留**，支撑 AC-4 无损往返）；Composition = 实例引用（InstanceID + Definition ID/版本）+ 连接（源口→多目标口）+ 拓扑构造；Layout = 视图位置与呈现偏好；契约引用 = 具名契约 ID/版本（或内联形状）；**Runtime State / 绑定不序列化**。
3. **PS-03 异常加载**：**缺失 Definition** → 实例保留"缺失"占位（配置与连接保留）+ Issue 标注，其余照常加载运行（不静默丢弃）；**版本不兼容** → 尝试按声明版本加载，不匹配则缺失态 + Issue（用户可手动指定替代版本）；**损坏** → 尽量部分恢复（跳过损坏节点 + Issue），完全不可解析则**拒绝加载并保护原文件**；建议自动备份/快照。
4. **PS-04 成员（口）重建与连接重锚定**：加载组合件 → 实例化模块（Definition+版本）→ 恢复配置 → **按声明/脚本重建成员（口）** → 按 `InstanceID.口名` **重锚连接**；**口消失** → 相关连接进入**悬空态**（保留声明 + Issue，不静默丢弃）；口新增不影响既有连接。
