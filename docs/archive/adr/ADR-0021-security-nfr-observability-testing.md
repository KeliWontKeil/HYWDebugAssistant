# ADR-0021 安全模型 / NFR 冻结范围 / 可观测性 / 测试方案（批次 9）

> 状态：Accepted（用户裁决，批次 9）
> 关联批次：批次 9
> 关联主文档章节：§12、§13、§14
> 取代：无 · 被取代：§四 T5 中的"风暴护栏（自连/环）"由 **ADR-0029** C4-1 取代（不做环检测；T5 改为覆盖停止超时路径）
> **收窄/修订说明**：仅 §四 测试方案 T5（故障注入）的"风暴护栏（自连/环）"一项被取代；§一（安全与隔离）、§二（NFR 冻结范围）、§三（可观测性方案）结论不变。

## 决策

### 一、安全与隔离：轻量透明模型（§12）

**评估结论**：沙箱/权限系统对本平台过度——核心风险是"用户主动加载不可信模块包"（信任决策在用户），故采用"**避免风险 + 透明化 + 基础护栏**"：

| 风险点 | 对策 |
|---|---|
| 加载模块包=执行代码（核心风险，无法轻量消除） | ①默认不自动加载（ADR-0020，显式=用户信任决策）；②加载前显示来源/签名状态（签名可选，未签名提示不阻止）；③Manifest 声明所需能力（网络/串口/文件）并**加载时提示**（透明不拦截） |
| 组合件被当作可执行载荷 | **本平台天然免疫** → 确立原则：**组合件永不自动执行任何代码**（加载只重建声明结构），写入文档 |
| 脚本模块逃逸（若技术栈含脚本） | 选型时评估（Gate）；顶层要求"不得引入更强执行权" |
| 恶意/缺陷模块破坏数据 | 文件操作限制在用户选择路径；保存原子写（ADR-0016）；不实现路径穿越 |
| 资源耗尽（循环/内存/风暴） | 框架轻量护栏（ADR-0012）+ 加载上限（文件大小/嵌套深度） |
| 组合件解析漏洞（畸形文本） | 受限解析器（白名单字段、深度/大小上限），拒绝而非猜测 |
| 依赖链混淆 | 依赖显式声明（ADR-0020）；缺失依赖 → Issue，不静默降级 |
| 数据泄露（模块联网） | 接受（用户自担）；能力声明透明化；不做网络拦截 |

**明确不做**（保留 Gate）：进程级沙箱、权限拦截系统、强制签名。

### 二、NFR 冻结范围（§13）

- **首要原则：数据实时性 > UI 呈现**——**数据面绝不被 UI 阻塞**（视图独立开关、丢帧不阻塞上游、框架统一承载活动）；
- **模块数量不设上限要求**（可增长）；**Core 不随模块数量线性膨胀**；
- 可扩展性/可维护性/稳定性目标不变（AC-1/AC-2）；
- **数值指标（UI 刷新率/端到端延迟/内存/吞吐/连续运行时长）→ Gate：技术选型后 + 原型测量**。

### 三、可观测性方案（§13）

| 层 | 内容 | 呈现 |
|---|---|---|
| L1 框架诊断 | 加载/注册/建网/绑定/增量重建/变更事件（结构化日志） | 诊断面板（可选开） |
| L2 Issue 中心 | 对象标注 + 汇总列表 + 过滤（ADR-0015） | 轻量计数 + 面板 |
| L3 模块日志/状态 | 模块自产日志经框架汇集（分级/来源/过滤）；业务状态呈现 | 模块视图 + 汇总视图 |
| L4 数据流诊断 | 网络/口流量速率、**丢弃计数**、最后数据时间 | 口上/网络详情 |
| L5 性能监视 | CPU/内存/模块活动统计 | Gate |

原则：默认轻量不打扰；L1/L4 为排障主力；录波/回放属未来能力（Gate）。

### 四、测试方案（§14）

| 层 | 内容 |
|---|---|
| T1 判据测试（AC-1~6） | 以**参考组合**（桩模块：数据发生器/记录器/断言器）自动化验证六项判据 |
| T2 契约/兼容测试 | 契约与兼容判定表驱动（合法/非法矩阵）；**建网规则 R0–R6** 各情形 |
| T3 核心机制测试 | Registry/生命周期状态机/ChangeSet 原子性/增量重建/资源释放（无泄漏） |
| T4 持久化测试 | 组合件 round-trip、版本迁移、缺失模块/损坏处理、未知字段保真 |
| T5 故障注入 | 异常不逸出边界；慢消费者丢帧；风暴护栏（自连/环） |
| T6 模块契约测试套件 | 供模块作者自检（接口/Schema/生命周期钩子/无跨模块引用），支撑 AC-1 |
| T7 UX 手工/原型验证 | 排版、网络标记、快速建网体验 |
| T8 UI 自动化 | Gate（技术选型后） |

原则：架构级测试优先（不依赖具体业务模块）；参考组合/桩模块为常备基础设施；判据可回归。

## 影响

- §12/§13/§14 更新；PQ-SEC-01~03、PQ-NFR-01~02、PQ-TE-01~04 关闭（数值指标与工具细节为 Gate）。
- 新增原则："组合件永不自动执行代码"；"数据实时性优先于 UI"。
