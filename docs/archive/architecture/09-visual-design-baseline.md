# 视觉设计基线（第 9 章 · 架构级视觉决定）

> 状态：**已冻结**（用户裁决 V1–V4 与 C9-1~C9-3）
> 来源：全面审查发现的缺失域（视觉/美术/配色/字体/图标此前只被推给 Gate C，无任何基线）
> 已裁决前提：**V1 工程工具风（紧凑）** · **V2 内置深浅两种、可切换、允许更换背景/色系、默认无背景（具体实现待定）** · **V3 冷色主色 + 语义色** · **V4 系统字体 + 开源图标库（须过许可门禁）**
> 与 Gate C 的边界：**本文件定"体系与机制"（颜色角色、主题 token、字体层级、图标来源、尺寸基准、状态语义）**；**具体数值的精调**（间距梯度、圆角、最终色值微调、动效）属 Gate C（M1 之后的 UX 原型）。
> 关联：`05-ui-architecture.md`（层模型/拼接/网络标签）+ `03-module-sdk.md`（预置元素目录）+ ADR-0031

## 1. 设计原则

| 原则 | 含义 | 依据 |
|---|---|---|
| **工程工具风** | 高信息密度、紧凑间距、清晰边框；一屏看更多数据 | V1 裁决 |
| **数据优先** | 视觉服务于数据可读性：波形、数值、表格的对比度优先于装饰 | §13.1 数据实时性 > UI 呈现 |
| **克制** | 无阴影/渐变/装饰性动效（除非表达状态）；颜色只用于**语义**与**选中** | 工程工具惯例 |
| **层级靠明度** | 用背景明度差与边框区分层级，而非投影 | 深色主题下投影不可见 |
| **状态可见** | 模块/网络/口的运行状态必须"一眼可见"（颜色 + 形状双重编码，不只靠颜色） | §10.4 状态呈现、无障碍残留考虑 |

## 2. 配色体系（冷色主色 + 语义色）

### 2.1 颜色角色（token 化，不直接写死色值）

所有颜色以**角色 token** 引用，主题切换时替换 token 值（V2 的可切换与"允许更换背景/色系"由此实现）：

| 角色 | 用途 |
|---|---|
| `bg.workspace` | 工作区层背景（**默认纯色、无背景图**，V2） |
| `bg.module` | 模块视图背景 |
| `bg.chrome` | 框架 UI（`FrameworkUi`）面板背景 |
| `border.default` / `border.strong` | 模块与面板边框 |
| `text.primary` / `text.secondary` / `text.muted` | 文本三级 |
| `accent.primary` | 主色（**冷色**，V3）：选中、聚焦、主按钮 |
| `accent.secondary` | 次强调（青，用于信息类层区分） |
| `direction.send` / `direction.receive` | **方向语义色**（发送 / 接收）——**【新增 · ADR-0044】**：与 `accent.*` **完全解耦**（主题色只表达框架性交互语义）。消费者：端口标记**箭头**、端口标记**边框**、**建网预览描边**、叠加信息层**流向箭头**；可在设置里单独改（空 = 跟随主题默认） |
| `semantic.ok` / `semantic.warn` / `semantic.error` / `semantic.idle` | 语义色：正常 / 告警 / 故障 / 空闲·停流 |
| `overlay.selection` / `overlay.highlight` | 选中与聚焦高亮的半透明叠加 |
| `overlay.scrim` / `overlay.ink` / `overlay.inkMuted` | 叠加层遮罩（"灰玻璃"浓度）/ 叠层主文字 / 叠层次文字 |
| `overlay.flow` | **模块内部处理顺序线**的中性低对比色（细实线、不流动；结构 ≠ 流量）——**【新增 · ADR-0052】** |
| `portMarker` 速率字号（`PortMarkerRateFontSize` = 10） | **叠加层里端口标记上的通路速率**字号（比名称 11 小一号）——**【新增 · ADR-0053】** |

## 3. 字体与排版（V4：系统字体）

| 用途 | 字体 | 说明 |
|---|---|---|
| UI 正文/标题 | **系统字体**（Windows：Segoe UI） | 零额外依赖、无体积成本 |

**行高**：1.35（紧凑）；数据区 1.25。

## 5. 尺寸基准（非强制"尺寸族约定"，承 C5-6）

| 项 | 值（v1 草案） |
|---|---|
| 基准单位 | **8 px 模数**（用于内置模块与框架 UI 的尺寸/间距**设计基准**；**不是网格吸附**——Q5-1 已排除网格吸附交互） |
| 间距梯度 | 4 / 8 / 12 / 16 / 24 |
| 模块标题栏 | **【修订 · ADR-0034】无标题栏**：模块窗口**完全无边框**，原"标题栏高 24 px"废止；模块名与状态改为**内容区顶部一行轻量文本**（12 px、弱化色，模块可声明省略） |
| 窗口交互带 | **6 px**（边框热区）：边中点/角点为缩放（手柄 12×12），其余为拖动；**锁定 / 隐藏 / 关闭** 按钮簇同处（建议右下、悬停或选中时出现） |
| 内置模块常用尺寸 | 宽 240 / 320 / 480；高 120 / 240 / 360（**仅内置模块遵循**；第三方模块尺寸自由，C5-6） |
| 端口锚点 | 沿模块边缘**按端口数等分**；固定锚点在拉伸时**按比例重排**（C5-7） |
| 网络标签块 | 高 20 px，**宽度随依附边缘长度拉伸**（C5-8）；端口在块内对齐 |
| 模块圆角/边框 | 圆角 2 px（克制）；边框 1 px（选中 / 悬停 / 锁定态差异化，Gate C 定） |

> **实现落点（M1-15）**：模块窗口默认尺寸 **260×140 DIP**（最小 150×70）；交互带 6 px、缩放手柄 12×12、按钮簇在**右下角**（悬停或选中时以 0.12 s 淡入）；模块名行 12 px 弱化色（状态点 8 px、状态文本 10 px）；口标记块高约 18 px、字号 10 px（`ModuleWindow.axaml` / `PortMarkerPanel` / `Tokens.axaml`）。以上数值**仍属 Gate C 可调**，最终由 **M1-16 UI 专项**统一定稿。
>
> **【定稿 · M1-16 批次 B1/B2 · ADR-0039】取代上一段的小尺寸取值**：
> · 模块窗口**无标题栏、无身份行**（**模块名不显示**）；**边框覆盖整个窗口周界**，整块窗口矩形 = 模块矩形；
> · 运行指示在**左下角**（状态点 7 px + 状态文本 10 px）；按钮簇在**右上角、纯图标**（20×20 图标按钮、12×12 填充几何，悬停或选中淡入）；**【修订 · 第十一轮 / ADR-0041 D1】按钮簇 = 还原 · 锁定/解锁 · 隐藏 · 关闭**（原"运行/停用"删除）；
> · 缩放手柄 **6×6**（原 12×12），**仅选中时可命中**（防抢端口标记的点击）；
> · 端口标记（标准件）：**20×114**（竖排）/ **114×20**（横排），**与外边框完全重合**；四段**固定槽位** = **类型窄色条（6）** / 名称（占剩余宽度）/ 方向箭头（20，字号 **16**）/ 状态灯（**8×8**，**Margin=0 贴到标记端部**）；名称字号 **11 px**、超长省略；箭头**按边取向外/向内**（数据流向恒为左→右）；
>   **【修订 · 第十三轮 / ADR-0043】**：① 标记上**不再显示连接状态文本**（删"（未连）"后缀——状态只由灯表达；`NetworkText` = 标签名 / `（直连）` / `无网络`，后两者是**网络名占位**不是状态提示）；② **不再显示数据包类型文本**（标签名通常很长放不下）⇒ 类型改由**窄色条**表达、**仅在悬停提示里**显式给出；③ **类型色条的颜色是可替换的占位**（`PacketTypePalette.Placeholder`，映射待用户给出，届时只改该类）；④ 悬停提示**剔除"上次操作"**（该字段整体删除，提交结果仍送状态栏）；⑤ 槽位顺序 = **读数顺序**（竖排内容旋转 −90° ⇒ 灯在上端、色条在下端）——**由无头测试钉住**；⑥ 标记编辑弹窗收窄为 **188**，多句提示改走 **`?` 帮助按钮 + Flyout**（与外壳各页同规则）；
> · 输入类控件统一高 **27 px**（token `ControlHeight`），圆角 3；
> · **叠加信息层**【**重设计 · 第十五轮 / ADR-0045 → 第二版 · 第三十三轮 / ADR-0052 → 第三版 · 第三十四轮 / ADR-0053**】：**默认关闭**（调试/观测层；快捷键 **L**）；开启时 = **半透明深色遮罩（"灰玻璃"，token `OverlayScrim`）** + 其上浅色信息（`OverlayInk`/`OverlayInkMuted`）；**层级在端口标记之下**（标记常显、可双击）；**现行内容（ADR-0052 + ADR-0053）** = **角色功能块**（一块 = 模块声明的一个功能分块：一个 `Id` + 一种数据类型 + 输入口/输出口）——
>   **方块**：**单列竖直堆叠、居中**（**宽度随文本自适应**，`RoleTextMetrics` 估算、夹在 [64,176]，块高 34；放不下 ⇒ 只画得下的 + 底部 `+K`）；**填充 = 类型色**（`PacketTypePalette` 按类型身份）；**左边缘 = 接收方向色（有输入口才画）· 右边缘 = 发送方向色（有输出口才画）**、**口数 > 1 才在该边画刻痕**；两行文字 = **功能名**（无则类型短名，11px）+ **`m/n`**（10px，无该侧口 ⇒ `--`、有口未连 ⇒ `0`）；**不带状态色**；
>   **角色自身的信息**（**角色维度**）：画在方块**上方**（放不下改下方）的**纯文字**、**左对齐**，**不画文本框**——①**速率大字**（15px）· ②`输入 m / 输出 n`（口数，10px）· ③`类型：<短标签>`（10px，**只取第一个语义标签并截断 8 字** —— 禁止外显过长描述）；数据取框架的**角色维度聚合**（产出侧优先）；
>   **线**：端点 = **两个角色方块的中心**；画出来的那段 = **本窗内 ∩ 本端方块之外**（视觉上从方块中心出发、不横穿方块）；**粗 2.5**、虚线 6/4、**共享时钟（60 Hz 时间相位）**推进 ⇒ **沿数据流方向**流动（发送向外 / 接收向内；`DashStyle.Offset` 的单位是**笔宽倍数** ⇒ 偏移 = 相位 ÷ 线宽，且**取模周期必须用真实周期 = `(6+4) × 线宽 = 25 DIP`**，否则会出现"平滑一段后突然跳一下"）+ **方向色渐变到中点色**（**本端色锚在方块那一端**，`GradientEnds`，与绘制方向无关 ⇒ 两端公共边颜色相接）+ 端部 6px 方向色箭头；**未拼接** ⇒ 终点画**竖杠断口 + 对端名**；**线上不写任何文字**；
>   **端口标记（网络标签）**（**通路维度**）：① **速率常驻**（10px，比名称小一号；未入网/无流量 `---`）——"**它不属于叠加层**"；② 叠加层开启时**不做任何调色**，而是靠**层级**沉下去：标记层排在**遮罩之前** ⇒ 被灰玻璃压暗（用户："网络标签不高亮 = **做减法**，把它埋入灰色玻璃下方"）；标记仍在交互带之上 ⇒ **照样可双击建网**；
>   **信息区**：左上 **`实例 · 模块名` 12px** + **必要的一句事实 10px**（`无数据口` / `未声明角色（N 个数据口）`）；
>   **模块内部顺序线**（多分块模块才可能有）：**细实线 + 中性色 token `OverlayFlow` + 不参与流动**（结构 ≠ 流量）；**零声明 ⇒ 不画**；
> · 取值集中在 `src/Ui/Styles/Tokens.axaml` 与 `src/Ui/Styles/Controls.axaml`——**改尺寸/配色只改这两处**（叠加层的几何常量在 `ConnectionOverlay` 顶部）。

## 6. 视觉表达（承第 5 章与 ADR-0034 的多窗口形态）

> **【修订 · ADR-0034】** 多窗口形态下不存在"叠在一张画布上的层"：原"工作区层 / 连线层 / 标记层 / 诊断层"的层序失效。

| 表达 | 视觉规则 |
|---|---|
| **模块窗口** | 无边框；`bg.module` + `border.default`；模块窗口内可含模块自身简易标记 |
| **背景** | **无任何框架背景**——桌面即背景（原 `bg.workspace` 仅用于弹窗内的预览区/空态占位，不再用于模块区） |
| **口上标记（标记）** | 边缘小矩形块：**类型窄色条 + 网络名（弱化）+ 方向箭头 + 连接状态灯**（`semantic.*`）——**【修订 · ADR-0043】标记上不写连接状态文本、不写类型文本**（类型只进悬停提示） |
| **选中 / 悬停高亮** | 主色边框 + `overlay.selection`；同网络成员一并提亮（其余降透明度，不隐藏） |
| **诊断提示（轻量）** | 图标 + 短文本，**低饱和度**（不打扰）；位于模块窗口内或诊断弹窗 |
| **叠加信息层（调试/观测）** | **默认关闭**；开启 = 模块被**灰玻璃**压暗（突出叠层信息），其上：**角色功能块（单列居中）+ 角色间数据线（方向色渐变 + 流动）+ 信息卡（速率/投递·丢弃/类型语义）**；**压在端口标记之下**（标记仍清晰可双击）。**【ADR-0045 立 · ADR-0052 现行形态】** |
| **跨窗口长连线** | **v1 不做**（需 Win32 互操作 + 全局 z-order + 跨显示器 DPI 三事同办；列后续可选增强，届时建议全屏覆盖窗）——**叠加层依旧只画"本窗内那半段"**，拼接线在公共边靠"中点色 + 边界点"自然相接 |

## 7. 状态语义映射（颜色 + 形状双重编码）

| 状态 | 颜色 | 形状/图标 | 含义 |
|---|---|---|---|
| 正常/Active | `semantic.ok` | 实心点 | 参与数据流 |
| Disabled | `semantic.idle` | 空心点 | 保留拓扑、暂停数据流 |
| 停流（上游无输入） | `semantic.idle` | 空心点 + 灰线 | **合法状态**，非错误（§8.2 类 a） |
| 无数据流（方向不匹配） | `semantic.warn` | 三角 | 连接存在但无数据（§5.4） |
| 悬空（口消失） | `semantic.warn` | 断续边框 | 保留声明 + Issue（§9.3） |
| 异常停机 | `semantic.error` | 叉/惊叹 | 模块活动体异常退出（§4.1） |
| Issue 标注 | `semantic.error` / `warn` | 角标 | 归属对象 + 汇总列表（§8.5） |

| 选中模块 | 主色边框 + `overlay.selection` 叠加 |
| **聚焦/高亮相关者**（§10.4） | 相关模块与连线提升不透明度；其余降透明度（不隐藏） |
| 拖动 | 被拖对象半透明；**吸附命中时显示对齐辅助线** |
| 拼接命中 | 端口标记**描边** = 该口的**方向色**、线宽 2（常态 1）——**【修订 · ADR-0044 D3b】**：颜色不再区分"预览 vs 常态"，而由**线宽**区分；颜色本身表达"这是发送端 / 接收端" |
| 端口锚点可拖动 | 悬停时锚点放大 + 光标变化；锁定状态显示锁图标（C5-7） |
| 禁用吸附（快捷键） | 状态栏/光标提示"吸附已关闭" |
