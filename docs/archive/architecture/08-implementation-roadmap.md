### M1-3 `Sdk` 最小面（规模：大）

| 项 | 内容 |
|---|---|
| 交付物 | `Sdk` 的公开类型（**只引 BCL，零框架依赖**）：① 模块特性（ID 三元组 / 显示名 / 描述 / 标签 / 能力 / 依赖 / 框架兼容范围）② 模块入口接口 + **6 个生命周期钩子**（`OnRegistered`/`OnActivated`/`OnDisabled`/`OnEnabled`/`OnConfigurationChanged`/`OnRemoved`）③ **上下文接口**（Issue/日志/业务状态上报、配置读写、停止信号、发送 API、订阅写入）④ **契约声明类型**（定长原语目录：`i8..i64`/`u8..u64`/`f32`/`f64`/`bool`/定长字节块 1–256/定长数组 1–256/结构组合 ≤4 层）⑤ 配置声明约定（C# 类型 + 源生成）⑥ **视图声明类型**（预置元素最小集：A1 数值 + A3 曲线；数据源声明）⑦ 口成员声明（名称/方向两态/契约类型/**是否参与自动建网**） |
| 验收判据 | 一个"最小可编译模块"能引用 `Sdk` 并实现接口（不依赖框架其他程序集）；`Sdk` 的引用集为空（仅 BCL） |
| 前置 | M1-1 |
| 备注 | XML 注释齐全（面向作者）；破坏性变更须 ADR |

### M1-4 `Hosting`：加载 → 注册 → 实例化 → 生命周期（规模：大）

| 项 | 内容 |
|---|---|
| 交付物 | ① 模块包物理形式（**M1 临时定**：目录 + manifest 文件 + 实现程序集；最终形式转 R 项）② manifest 解析与校验（必填字段、框架兼容范围、依赖存在性）③ **显式加载**（用户指定路径/来源目录）④ 注册表（结构三元组 ID + 版本维度，支持多版本共存）⑤ 实例化（按 Definition 创建实例与成员实例表）⑥ 生命周期状态机 `Registered → Active ⇄ Disabled → Removed` 与钩子触发 |
| 验收判据 | 用 M1-3 的最小模块：加载 → 注册 → 实例化 → 进入 `Active`（`OnRegistered`/`OnActivated` 各触发一次）；`Disable`/`Enable`/`Remove` 状态与钩子正确；缺依赖 → Issue 而不是静默降级 |
| 前置 | M1-3 |
| 备注 | 反射只在加载期读一次 → 不可变元数据缓存 |

### M1-5 `DataPlane` 基础设施（规模：大 · **依赖倒置修正**）

| 项 | 内容 |
|---|---|
| 交付物 | ① 每实例**专属线程**的创建/回收/停止协议（停止信号 + 有界等待 + 超时不强杀 → Issue + 孤儿标记）② **有界输入队列**（容量 1024 默认、可配置；丢旧默认、可选丢新；**不做背压**）③ **池化定长缓冲** + 契约**形状元数据（字段偏移表）** + **加载期生成的强类型访问器** + 归还协议与断言 ④ **投递原语**（写入目标队列 → 目标线程消费 → 调用模块接收回调）⑤ 模块活动体入口的**异常边界**（整体包裹 → Issue + 停机）⑥ 丢弃计数 / 最后数据时间等 L4 采集点 |
| 验收判据 | **独立测试夹具**（不依赖建网）：直接把单元写入某实例队列 → 该实例在自己的线程上收到回调并读到正确字段；队列打满 → 丢弃计数递增、发送方**不被阻塞**；模块抛异常 → 转 Issue 且不影响其他实例；停止超时路径可复现（T5） |
| 前置 | M1-3、M1-4 |
| 备注 | **原 M1-4 依赖"绑定"是不成立的**（绑定由建网产生）——本步以"队列 + 投递原语"独立验收，绑定在 M1-6 才出现 |

### M1-6 `Core` + `Core.Api`：ChangeSet / 建网 / 绑定 / 增量重建 / Issue（规模：大）

| 项 | 内容 |
|---|---|
| 交付物 | ① **ChangeSet 两阶段**（Prepare 可失败零副作用 / Commit 无失败点；变更入口串行化）② 组合操作集最小集（Add/Remove Module、Enable/Disable、建立/断开网络、配置更新）③ **快速建网 R0–R6** ④ **绑定对象**（源/目标列表/契约引用/诊断计数/状态）+ 不可变快照原子替换 ⑤ **增量重建**（声明集与绑定集 diff；单位 = 绑定及邻接数据面；**模块状态保留**）⑥ **Issue 中心**（归属对象 + 类别 + 来源；无锁并发队列）⑦ `Core.Api` 最小公开面（查询实例/网络/口状态/Issue；命令入口） |
| 验收判据 | 手工建网后数据真实流动（发送模块 → 接收模块）；删除连接不重置模块（业务状态保留）；Prepare 失败时**零副作用**（连线程都不建）；契约不兼容 → 拒绝连接 + Issue；`Core.Api` 公开签名不含 `Core` 内部类型（AR-16） |
| 前置 | M1-5 |
| 备注 | T2（兼容矩阵 / R0–R6 表驱动）与本步同步落地 |

### M1-7 应用级设置最小实现（规模：中）

| 项 | 内容 |
|---|---|
| 交付物 | ① Settings 模型（应用目录 `settings.json`、`schemaVersion`、原子写、未知字段片段保留、缺失/损坏 → 默认值 + Issue 不阻断启动）② v1 四项参数：**停止超时（默认 5 s）**、**输入队列容量（默认 1024）**、**UI 刷新率（默认 60 Hz）**、**诊断提示阈值** ③ 变更经 L4 变更入口即时生效 ④ **多实例并发写 = 直接覆写（最后写入获胜）** |
| 验收判据 | 改设置即时生效；删除/损坏 `settings.json` → 用默认值启动且记 Issue；未知字段往返保留 |
| 前置 | M1-6 |
| 备注 | 本步是为了让 M1-5/M1-6 中的"可配置"参数有确定归属（原大纲缺此步） |

### M1-8 持久化：组合件保存 / 加载（规模：中）

| 项 | 内容 |
|---|---|
| 交付物 | ① 组合件文本 JSON（`System.Text.Json` 源生成 + `schemaVersion`）② 保存内容：实例（ID 三元组 + 版本 + 配置）+ 网络（`实例ID.口名` 成员 + 名称 + 匿名/命名）+ 布局 + 活动面 + **端口几何**（归属与模块参数同层）③ 原子写（临时文件 + `File.Replace`）④ 加载流程：解析 → 迁移/校验 → 实例化 → 恢复配置 → 重建成员 → **按 `实例ID.口名` 重锚** ⑤ 异常加载：缺失 Definition → 占位 + Issue；损坏 → 部分恢复；不可解析 → 拒绝并保护原文件 |
| 验收判据 | round-trip：保存 → 加载 → 运行 → 再保存，内容逐字段等价（含**未知字段保真**）；删掉一个模块包后加载 → 占位 + Issue 且其余照常运行 |
| 前置 | M1-6、M1-7 |

### M1-9 `Ui` 最小（规模：大）

| 项 | 内容 |
|---|---|
| 交付物 | ① **工作区层**：绝对定位的模块视图容器（自由画布）② 模块视图渲染最小集：**A1 数值** + **A3 曲线**（按声明渲染，模块不提供 View）③ **订阅缓冲读取**（最新值槽 / 环形缓冲；UI 按刷新率抽样）④ **连线层**：默认隐藏 + 热键切换 + 有向样式 ⑤ **标记层**：网络标签块（边缘小矩形、端口对齐）⑥ **几何吸附最小实现**：模块边缘贴合（容差初值 8 px）+ 整体拖动 + 快捷键独立拖动/停用吸附 |
| 验收判据 | 用户可见：模块出现、数据在数值/曲线上跳动、连线可切换显示、两个模块能吸附拼接并整体拖动；**UI 卡顿不影响数据面**（模块线程继续计数） |
| 前置 | M1-6（数据）、M1-5（订阅缓冲） |
| 备注 | 视觉取值按 `09-visual-design-baseline.md`；细节精调属 Gate C。**【现状 · M1-15】**本步交付的"自由画布 + 工作区层 + 连线层/标记层"**已被 M1-15 的拼图式多窗口取代**（多层模型与连线层撤销；连线表达改为"口上标记 + 高亮 + 只读拓扑诊断"）——本行按历史记录保留，当前形态见 `11` 与 `05` §5.14 |
