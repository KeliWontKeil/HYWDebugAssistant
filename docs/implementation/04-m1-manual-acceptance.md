## 0. 怎么跑起来（最小步骤）

1. **关闭正在运行的应用**（否则构建写不进 App 输出）。
2. 在工程根 `D:\project\c# project\HYWDebugAssistant\` 执行：

```powershell
.\build.ps1                    # 完整门禁：还原 → 构建 → 许可审计 → 全部测试（应全绿）
.\tools\dev.ps1 -Mode Run      # 启动应用（会先停掉 VS 的设计器宿主，避免文件锁）
```

**预期**：外壳窗口出现；**四个正式模块包已自动装入**（内置目录 `modules\`；包名 `text-sender` / `hex-sender` / `data-monitor` / `hex-string-converter`），无需手工选路径。

### 0.1 可视化自检（可不开应用，先看图）

```powershell
dotnet test tests\HYWDebugAssistant.VisualSnapshots\HYWDebugAssistant.VisualSnapshots.csproj
```

打开 `%TEMP%\hyw-overlay-snapshot\*.png`：叠加层用例留下的**四张窗口快照**（发送器 / 两个显示器 / 一个未连接模块）+ 调色板窗口快照，就是**真实渲染结果**；可先逐条对照「四、叠加层与视觉」的几何条目，再启动应用确认交互与手感。
