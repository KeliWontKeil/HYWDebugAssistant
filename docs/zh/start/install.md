# 安装与首次启动

本页回答“拿到产品后怎么启动、目录里有什么、数据放在哪”。

## 安装

当前发布物是**自包含目录**，不是安装器、也不是压缩包：

1. 把 `HYWDebugAssistant-<版本>-win-x64` 整个目录放到任意位置；
2. 双击目录里的 `HYWDebugAssistant.App.exe` 启动。

不需要另装 .NET 运行时；目录可以整体搬走。首次启动会在程序目录按需建立 `settings/`、`workspace/` 等数据目录。

本页的“产品”就是**主应用**，也是模块宿主；模块导入发生在这个进程里，没有第二个外部挂载程序。

> 当前只有 `win-x64` 是承诺目标。其他 RID 的产物可以尝试发布，但机制可能退化或不可用，不承诺可编译/可运行。

## 目录

| 路径 | 内容 | 能否删除 |
|---|---|---|
| 程序文件与依赖 | 应用入口、框架程序集、自包含运行时 | 否 |
| `modules/` | 内置模块包 | 否；删掉对应模块即消失 |
| `modules/external/` | 外部导入的模块包 | 可以；该模块随之消失 |
| `resources/` | 文本表、图标、出厂种子 | 否；缺了界面显示键名/图标缺失 |
| `settings/` | 设置文件与外观主题 | 可以；回到内置默认值 |
| `workspace/` | 工作区快照与资产 | 可以；下次启动从空现场开始 |
| `composites/` | 组合文件 | 可以；自定义组合丢失 |
| `logs/` | 日志目录（日志能力尚未落地，路径先预留） | 可以 |

产品里**没有**模块开发 SDK、源码或样例。需要开发模块时另行获取独立的 `HYWDebugAssistant.Sdk-<版本>/`，见[模块开发](../module-dev/index.md)。

## 第一次启动

启动后看到主窗口与活动栏；模块清单、连接与保存的用法见[使用指南](../guides/index.md)。如果启动失败，检查目录是否完整、是否有杀毒软件拦截，并把现象记录到 Issue/日志目录。
