# 使用指南

本层是功能目录：应用里每个可操作的功能一页，说明入口、结果与出错时的提示。

| 项 | 内容 |
|---|---|
| 读者 | 已安装产品、要完成一项具体操作的人 |
| 回答 | 这个功能在哪、怎么点、点完看到什么、不对时看哪里 |
| 不写 | 实现机制（→ 深入理解）、怎么写模块（→ 模块开发）、仓库怎么构建（→ 项目开发） |

## 按任务找

| 我想… | 看 |
|---|---|
| 知道有哪些模块、每个模块能做什么 | [模块](modules/index.md)（每个模块一册） |
| 把模块放进现场、导入外部模块包、移除 | [模块管理](manage-modules.md) |
| 移动、缩放、锁定、隐藏、换壁纸、关掉窗口 | [窗口操作](windows.md) |
| 把两个窗口拼在一起、让它们吸住 | [吸附与拼接](puzzle.md) |
| 把两个模块连起来、断开、改网络名 | [连接与组网](connect.md) |
| 看到模块内部的角色、连线与速率 | [叠加层](overlay.md) |
| 换主题、字体、壁纸、类型颜色 | [外观](appearance.md) |
| 改语言、队列容量、日志、快捷键 | [设置](settings.md) |
| 看错误、看流量、查为什么没有数据 | [诊断与排障](diagnostics.md) |
| 保存一套组合、下次接着用、退出时保存 | [组合件与工作区](workspace.md) |
