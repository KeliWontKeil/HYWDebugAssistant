# 使用指南

本层面向日常使用者，按任务组织：连接设备、收发数据、组织网络、调整界面、管理模块与排查问题。

!!! note "本层内容将在发布前完成"
    任务指南需要配合最终界面与安装形态设计，属于发布前工作。本层当前只提供层框架；发布前按下列任务补齐。

## 适合谁

- 已安装产品，需要完成一项具体任务。
- 需要快速查到某个操作的入口与结果。

## 当前可读

- [模块清单](../reference/modules.md)：各模块的标识与用途。
- [端口与数据类型](../reference/ports-and-types.md)：数据流的基本概念。

## 发布前计划包含

| 任务 | 说明 |
|---|---|
| 连接串口设备 | 选择端口、参数与打开方式 |
| 连接 TCP 服务端 / 客户端 | 地址、端口与连接状态 |
| 使用 UDP | 本地绑定、目标地址与广播 |
| 发送与接收数据 | 文本、十六进制与监视器 |
| 组织网络与组合 | 端口连接、命名网络与保存组合件 |
| 界面与外观 | 主题、语言、壁纸与快捷键 |
| 管理模块 | 内置模块、外部模块包的导入与移除 |
| 故障排查 | 常见状态提示与处理方式 |
