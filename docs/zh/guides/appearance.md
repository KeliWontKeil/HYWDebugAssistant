# 外观

主题方案、壁纸、色板、字体与数据类型颜色。所有改动都先暂存，点「应用」或「确认」后生效。

## 打开

活动栏「设置」→ 外观页。页内按「主题方案 / 当前主题壁纸 / 色板 / 字体」分组。

## 主题方案

| 操作 | 说明 |
|---|---|
| 选择方案 | 内置浅色、内置深色、跟随系统，或已有自定义方案 |
| 跟随系统 | 分别指定系统为浅色 / 深色时使用哪一套方案 |
| 新建方案 | 以当前颜色为基础新建自定义方案，可命名 |
| 保存方案 | 把当前草稿写入该主题文件夹 |
| 删除方案 | 删除当前自定义方案 |
| 恢复方案默认 | 把当前方案的改动恢复为默认色 |

改动任一颜色会自动把内置方案转为自定义方案；内置方案本身只读。

## 壁纸

- 「选择壁纸…」为当前主题选一张主窗口壁纸，「清除」移除。
- 「壁纸遮罩浓度」控制主题色遮罩，0% 无遮罩、90% 几乎看不见壁纸。
- 只影响主窗口；模块窗口的壁纸在模块窗口按钮簇的「壁纸」里单独设置。

## 色板

- 色板是全部界面颜色的来源，按分组列出可改的 token（背景、表面、边框、文字层级、主色与辅色、方向语义色、语义状态色、叠加层等）。
- 点任一色块打开「编辑颜色」：可选推荐色、恢复默认、直接取色。
- 「控件表面不透明度」控制面板、侧栏、按钮与开关轨道的背景透明度；文字、图标与边框保持不透明。
- 改色只影响呈现，不参与建网与兼容判定。

## 字体

- 分界面中文、界面西文、数据中文、数据西文四项，西文默认等宽、中文默认宋体。
- 可从系统字体列表选择，也可手工填写字体名；下方有示例文本。
- 字体是全局显示偏好，不随主题方案切换。

## 数据类型颜色

在「交互」页的「数据结构 · 颜色」里管理：同一种数据类型在所有窗口中使用同一种颜色，这是全局身份映射。

- 点色块修改该类型的颜色，或「恢复自动色」按类型标识重新计算。
- 颜色只用于呈现，不影响建网与兼容判定；没有在用的类型不会出现在列表里。

## 生效时机

- 主题、壁纸、色板、字体：点「应用」或「确认」后套用到整个应用；「取消」丢弃草稿。
- 主题方案的新建 / 保存 / 删除写的是主题文件夹，与设置文件一起生效。
- 「恢复默认设置」只恢复当前页的默认值，仍需应用。
