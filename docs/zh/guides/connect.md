# 连接与组网

端口标记是建网的唯一入口：给端口起网络名，或者让两个模块贴合对齐。

## 端口标记

端口标记是窗口边缘上的小方块，内容自左向右依次是：

| 槽位 | 含义 |
|---|---|
| 窄颜色条 | 该端口的数据类型（颜色与类型身份一一对应） |
| 网络名 | 当前网络名；没有名字时显示「无网络」，按几何自动连上的显示「（直连）」 |
| 通路速率 | 这个口参与的通路当前的有效载荷速率，未入网或无流量时显示占位符 |
| 方向箭头 | 发送口与接收口用不同颜色，箭头指向数据流方向 |
| 连接指示灯 | 已连接 / 未连接 / 停流，用颜色与形状区分 |

默认发送口在右边缘或下边缘、接收口在左边缘或上边缘；模块可以声明别的默认边，用户拖动优先。

鼠标悬停在标记上可看到类型、网络名、对端、流量、投递与丢弃数，以及该口队列的深度与是否饱和。

## 用网络名建网

1. 双击端口标记，弹出网络名输入框。
2. 填一个名字后点「确定」；留空点「清除」即退出网络。
3. 同名的发送口与接收口自动连成一条网络：一个名字可以有多个发送端，接收端会把它们合成一路。

网络名按字面比较（区分大小写），不能包含空白字符，长度有上限；名字只用于建网与显示，不参与类型判定。

## 用贴合建网

两个模块靠近、端口标记相互对齐、且两个端口都没打网络名时，拖动松手后会按几何关系自动建网。

- 两个模块必须**相邻且不重合**；重合时不算接触，不会建网。
- 拖动过程中状态行会提示「即将自动建网：N 条连接」。
- 需要开启「设置 → 常规 → 对齐自动建网」；关闭后只认命名网络。
- 建成的网络在标记上显示「（直连）」，不落盘；组合件加载后按位置重新推导。

## 断开

| 网络类型 | 断开方式 |
|---|---|
| 命名网络 | 双击标记，清除网络名 |
| 几何直连 | 把两个模块拖开，端口不再接触或不再对齐 |

断开只断连接，不删除模块、不清空配置。

## 调整端口位置

- 拖动标记可沿当前边移动，也可以拖到另一条边；位置随组合件保存。
- 标记悬停时出现的锁形按钮用于固定 / 解锁该锚点；锁定的锚点不能再拖。
- 快捷键 Ctrl+P（默认）一次固定或解锁全部端口锚点。

## 连不上的原因

建网要求两侧的方向、数据类型与形状完全一致；不兼容时不会建立连接，原因记录在 **Issue 面板**。状态栏提示标签设置成功，只表示标签已写入，不代表连接成功；以网络成员和端口指示灯为准。

- 两侧类型标识不同、或形状不同：属于两种数据类型，需要让两侧声明同一类型。
- 需要转换时插入一个转换模块（例如 HEX ↔ 文本转换器），由它承担两侧不同的类型。
