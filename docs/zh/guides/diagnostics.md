# 诊断与排障

三个入口：Issue 面板、拓扑诊断、状态栏。建网失败原因以 Issue 面板为准；状态栏右侧只是临时操作提示，标签设置成功不代表连接成功。

## 入口

| 入口 | 位置 | 用途 |
|---|---|---|
| Issue 面板 | 活动栏 Issue 图标，图标上的红色角标只计错误级 | 框架与模块上报的问题，带对象归属 |
| 拓扑诊断 | 活动栏拓扑图标 | 只读地看每条网络的源、宿、链路与队列 |
| 状态栏 | 主窗口底部 | 模块数、Issue 数、叠加层与吸附状态、刷新率；右侧显示临时提示 |

## Issue 面板

列表按时间排列，每行显示严重度、类别、来源与对象；未读项有标记。

| 操作 | 说明 |
|---|---|
| 筛选 | 按类别、按来源（框架判定 / 模块报告）、只看未读 |
| 搜索 | 按对象或消息文本过滤 |
| 详情 | 选中一行，右侧显示完整消息与对象路径 |
| 标记已读 / 未读、全部已读 | 只影响未读标记，本次运行有效 |
| 复制消息 / 复制详情 | 复制到系统剪贴板 |
| 删除、清空全部 | 删除单条或全部；清空前需要确认 |

类别分为配置、组合、接口、模块、通信、运行时、呈现；严重度为错误、警告、信息。错误表示框架故障或契约错误，警告多为外部环境与对端状态。

## 拓扑诊断

左侧是网络列表（正常 / 停流 / 悬空），右侧是选中网络的诊断结论、链路与源指标。

- 状态：正常、停流（所有发送端都未接入）、悬空（有成员重新接入失败）。
- 源指标：投递数、丢弃数、速率与最后一次数据时间，按源显示。
- 队列：每个接收口的深度与容量，饱和时标注「饱和」；丢弃按原因分列（挤旧、拒新、过期、无承载、停流等）。
- 「复制诊断」把该网络的完整信息复制为文本，含成员原始标识。
- 占位实例可在此处「指定替代」，用模块清单里选中的模块替换。

本页只读：建网请在工作区进行，成员原始标识悬停可见。

## 状态栏与状态行

- 状态栏摘要：模块数、Issue 数、叠加层开关、吸附开关、刷新率；右侧临时提示会自动过期。
- 模块状态行在窗口左下角，文字由模块给出（例如说明当前打开的端口或连接状态）。
- 运行中与「跟不上」相关的事实（积压、丢弃）按设置里「状态显示」的深度与滞回出现和消退；端口标记悬停可看到队列深度与丢弃计数。

## 常见现象

| 现象 | 先看 | 处置 |
|---|---|---|
| 连上了但没有数据 | 端口标记的指示灯与速率、拓扑诊断的停流 / 悬空 | 检查网络名是否一致、发送端是否在运行、端口是否被停用 |
| 数据断续 | 拓扑诊断里的队列深度与饱和、模块状态行的丢弃句 | 降低发送频率或缩短帧长；必要时调整队列容量与满时策略 |
| 连不上 | Issue 面板里的网络/契约原因；状态栏只显示标签提交结果 | 让两侧类型一致，或插入转换模块 |
| 模块没有出现在现场 | 模块清单的来源、Issue 面板的导入失败 | 检查包目录与清单，同标识冲突时先移除旧包 |
| 改动模块代码后没生效 | 模块清单是否提示需重启 | 点「重新扫描」，在重启确认框里确认（或直接重启应用） |
| 串口首次打开卡顿 | 已知问题与极端工况 | 降低连续发送频率或缩短帧长 |
