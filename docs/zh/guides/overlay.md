# 叠加层

叠加信息层把窗口内容压暗，露出模块内部的功能分块与连接关系，用于判断数据在哪一段、以多快的速度流动。

## 开关

| 入口 | 说明 |
|---|---|
| 快捷键 L（默认） | 快速切换 |
| 设置 → 窗口与交互 → 显示叠加信息层 | 与快捷键共用同一状态 |
| 交互页「叠加信息层」开关 | 同上 |

状态栏显示「叠加层：开 / 关」。默认关闭，状态随工作区保存。

## 看什么

开启后窗口里的内容被一层半透明深色遮住，其上显示：

- **角色方块**：模块声明的功能分块，方块内两行是功能名与 `m/n`。`m`、`n` 分别是输入侧与输出侧已连接的对端角色数。
- **连线**：两个角色方块之间的连接线，虚线沿数据流方向流动，箭头指向本模块。两端模块各画自己那一半，拼接处严丝合缝；拉伸窗口后按新窗口尺寸重算，线会画到新的窗口边缘。
- **角色信息文字**：恒在方块上方的纯文字，给出该功能的速率、口数与类型语义；每个角色按信息行数预留上方槽位，不会压住相邻角色方块。
- **排布**：角色优先竖向排列；高度不足时自动改为横向并排；宽度也不足时使用网格。只有所有排布都放不下全部角色时才显示 `+K`。
- **模块身份**：展示名与现场编号（不是内部实例标识）。

端口标记会沉到遮罩之下，但仍可双击修改网络名；标记上的通路速率常驻显示，与叠加层开关无关。

## 用法

| 想看 | 看哪里 |
|---|---|
| 某个模块内部有没有在动 | 角色方块周围文字的速率与投递数 |
| 数据从哪个功能流到哪个功能 | 方块之间的连线与流向 |
| 这条连接是否成立 | 连线是否画到窗口边界、断口处是否显示对端名 |
| 哪一段在丢数据 | 角色信息里的丢弃数，配合[拓扑诊断](diagnostics.md)看队列 |
