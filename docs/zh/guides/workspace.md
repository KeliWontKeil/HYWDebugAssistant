# 组合件与工作区

组合件保存“一套模块与连法”，工作区保存“当前这一现场”，两者都在退出与重启时起作用。

## 组合页

活动栏第二项「组合」在侧栏打开本页，分「可用组合」与「已选模块」两部分。

### 加载组合

1. 在列表里搜索或选中一个组合（双击可直接加载）。
2. 点「加载」，组合会**追加**到当前现场，不会替换现有模块。
3. 缺失的模块包在列表行上标注缺少数量；加载后对应位置出现占位实例。

### 保存组合

1. 在模块窗口里点选要保存的模块，或点「全选现场」把所有模块（含隐藏与占位）加入保存范围。
2. 点「保存组合」写入默认目录 `composites\`；重名时先确认是否覆盖。
3. 点「另存为…」可保存到任意位置；外部文件要再次出现在列表里，需要先「导入组合…」。

「已选模块」显示本次保存的范围。如果某条网络只有部分成员被选中，底部会提示该网络关系不会保存。

### 管理组合

| 操作 | 说明 |
|---|---|
| 导入组合… | 选择一个组合文件夹（含 `composite.json`），校验后复制到默认目录 |
| 拖入文件夹 | 含 `composite.json` 的文件夹按组合导入；含 `module.json` 的按模块包导入；外层文件夹可一次导入 2–3 层内的多个组合/模块，结果显示在页面底部 |
| 压缩包 | 本轮不支持 `.zip`；先解压成文件夹再导入 |
| 重命名 | 修改选中组合的名称 |
| 删除 | 删除组合文件，需确认 |
| 更换封面 | 选一张图片作为列表封面 |
| 重新扫描 | 重新扫描默认目录中的组合文件 |

### 随产品提供的示例

首次启动会投放三个示例组合件：**经典串口助手**、**可视化功能演示**、**串口示波器**。

- 只在默认目录里没有该组合时才投放；投放过一次就记在设置里，删掉之后不会再出现。
- 投放后就是普通组合件：可以加载、改名、覆盖、删除。想保留自己的改动先用「另存为…」存成另一份。

## 工作区与退出

关闭主窗口时按「设置 → 窗口与交互 → 关闭主窗口」执行：

| 选择 | 结果 |
|---|---|
| 每次询问 | 弹出保存询问，可选择保存并退出、不保存并退出、取消，并可勾选「下次不再提醒」 |
| 保存并退出 | 直接保存工作区后退出 |
| 不保存退出 | 丢弃本次未保存的修改 |

保存后，下次启动会恢复全部模块、配置、输入内容、窗口位置、壁纸与外壳位置。取消退出时子窗口都不关，应用继续运行。

## 重新扫描与重启

模块清单里的「重新扫描」会重新扫描模块目录并加载新增包；如果扫描发现包内容变化、需要新程序集生效，会弹一次重启确认，确认后先保存当前工作区再重启应用。没有单独的「重新加载」按钮；取消确认只更新列表、不重启。
