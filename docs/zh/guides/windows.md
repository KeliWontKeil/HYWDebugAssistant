# 窗口操作

移动、缩放、锁定、隐藏、还原、换壁纸与关闭模块窗口。

## 窗口形态

- 模块窗口没有标题栏，整块矩形就是模块本身；边框覆盖整个周界。
- 左下角是运行指示：一个状态点加一句状态文本（运行中 / 已停用 / 占位 / 定义缺失 / 已移除）。
- 鼠标移到窗口上或窗口被选中时，右上角淡入按钮簇：壁纸、还原、锁定、隐藏、关闭。
- 窗口不占任务栏，任务栏只有主窗口一项。

## 选中

- 点击窗口的边框区域选中它；选中态是主色边框加一圈选择框。
- 点窗口内容不选中，但会取消已有选中。
- 同一拼接组会一起选中（见[吸附与拼接](puzzle.md)）。
- 点击/拖动会把整组抬到更前；如果它压住更低窗口，层会提升，只有同层窗口还能吸附。层号由叠放顺序自动决定，不需要用户设置。
- 主窗口是跨层锚点：任意层模块都能贴主窗口；移动主窗口会带走所有贴壳组，但选中/抬升只在本层。

## 移动与缩放

| 操作 | 做法 |
|---|---|
| 移动 | 拖窗口的边框带（四周约 6 像素） |
| 只移动自己 | 按住 Ctrl 拖动，脱离拼接组单独移动 |
| 暂停吸附 | 按住 Alt 拖动，本次不吸附、不对齐 |
| 缩放 | 选中后拖边中点或角点；未选中时点角点会先选中 |
| 内容放不下 | 内容区出现滚动，窗口不自动长高 |

窗口尺寸有下限（由端口标记所需的空间决定）；用户在界面上拖出的尺寸随组合件保存。

## 按钮簇

| 按钮 | 作用 | 说明 |
|---|---|---|
| 壁纸 | 选择或清除该模块的壁纸 | 只影响这个模块；遮罩浓度跟随当前主题 |
| 还原 | 弹出选择：只还原默认尺寸 / 还原尺寸和配置 | 默认尺寸会覆盖拖过的尺寸；配置指模块自带默认参数 |
| 锁定 | 锁定后不能移动或缩放，仍可选中、可被组合保存 | 再点解锁；「交互」页可全部锁定 / 全部解锁 |
| 隐藏 | 窗口消失，模块继续运行 | 「交互」页「显示全部」恢复 |
| 关闭 | 移除该模块实例 | 与「隐藏」不同：实例被移除，网络随之断开 |

「交互」页还提供「全部置前」与「召回」（把屏幕外的窗口移回最近的屏幕），并显示隐藏数、屏幕外数等概览。
