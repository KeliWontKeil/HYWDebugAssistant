# TCP 客户端

主动连接一个远端 TCP 服务端，把连接上的字节接进数据流。地址/端口校验由文本框编辑事件驱动（不在每拍轮询）：空、通配或非法 IP/主机名只标红字段并禁用「连接」，不会用旧地址尝试连接；连接拒绝、超时、DNS 失败属于运行时状态，保持可重试。

## 界面

| 区域 | 内容 |
|---|---|
| 目标地址 | 主机名或 IP；默认预填本机回环地址，便于自测 |
| 目标端口 | 远端服务端口（1–65535） |
| 超时（秒） | 连接超时（1–60） |
| 禁用 Nagle | 开：小数据立即发送；关：允许内核合并小包 |
| 连接 / 断开 | 建立或断开连接；连接后参数不可编辑 |
| 状态灯 | 已连接、未连接与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数 |

## 连接

1. 填写目标地址与端口，必要时调整超时与 Nagle 选项。
2. 点「连接」；状态行说明正在连接并显示端点，成功后说明已连接。
3. 点「断开」结束连接；连接期间参数不可改。

同一实例不允许连接到自己正在监听的地址端口。

## 参数错误

| 现象 | 处置 |
|---|---|
| 目标地址为空、通配或格式不正确 | 字段红框 + 悬停原因；「连接」禁用 |
| 目标端口不在 1–65535 | 字段红框；「连接」禁用 |
| 超时不在 1–60 秒 | 字段红框；「连接」禁用 |

参数未就绪时状态行说明参数未就绪、连接被禁用；具体原因看字段悬停。这类问题不会以连接失败出现，也不会拿旧地址去连接。

## 失败原因

| 现象 | 处置 |
|---|---|
| 超时 | 检查网络与对端是否在监听 |
| 连接被拒绝 | 确认对端服务与端口 |
| 对端关闭连接 | 视需要重新连接 |
| 传输层读写失败 | 看 Issue 详情后重连 |

失败不自动重试：修复原因后手动点「连接」。

## 收发

- 收到 → 发送口：连接上的字节切成数据包发出。
- 接收口 → 连接：数据包按有效长度写给对端；连接未打开时被拒绝并计数。
