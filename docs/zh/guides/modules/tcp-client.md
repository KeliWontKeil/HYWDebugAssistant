# TCP 客户端

主动连接一个远端 TCP 服务端，把连接上的字节接进数据流。

## 界面

| 区域 | 内容 |
|---|---|
| 目标地址 | 主机名或 IP；默认预填本机回环地址，便于自测 |
| 目标端口 | 远端服务端口 |
| 超时（秒） | 连接超时 |
| 禁用 Nagle | 开：小数据立即发送；关：允许内核合并小包 |
| 连接 / 断开 | 建立或断开连接；连接后参数不可编辑 |
| 状态灯 | 已连接、未连接与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数 |

## 连接

1. 填写目标地址与端口，必要时调整超时与 Nagle 选项。
2. 点「连接」；状态行显示「正在连接… 地址:端口」，成功后显示「已连接 地址:端口」。
3. 点「断开」结束连接；连接期间参数不可改。

同一实例不允许连接到自己正在监听的地址端口。

## 失败原因

| 状态句 | 含义 | 处置 |
|---|---|---|
| 目标地址为空 | 没填地址 | 填写主机名或 IP |
| 目标端口超出范围 | 端口不在 1–65535 | 修正端口 |
| 目标地址不能是通配地址 | 填了 0.0.0.0 之类的监听地址 | 填对端实际地址 |
| 连接超时 | 超时时间内没有连上 | 检查网络与对端是否在监听 |
| 对方拒绝连接 | 对端没有监听该端口 | 确认对端服务与端口 |
| 对端已关闭连接 | 连接中途被对端关闭 | 视需要重新连接 |
| 接收读取失败 / 发送失败 | 传输层错误 | 看 Issue 详情后重连 |

失败不自动重试：修复原因后手动点「连接」。

## 收发

- 收到 → 发送口：连接上的字节切成数据包发出。
- 接收口 → 连接：数据包按有效长度写给对端；连接未打开时被拒绝并计数。
