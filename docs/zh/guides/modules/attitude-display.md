# 三轴姿态仪

把波形帧里某一组的三个通道当作横滚、俯仰、偏航，显示物体的三维姿态；渲染物可在坐标轴、方块、无人机之间切换。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · R 0 · P 1 · Y 2"（组 0 显示"自动"） |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口 |
| 姿态区 | 地面网格固定不动，机体按三个角度旋转 |
| 三轴读数 | 当前横滚、俯仰、偏航角（度） |
| 悬停提示 | 鼠标停在模块上可看到当前状态，不占版面 |

组号与三个通道号在设置面板里编辑，可提前填好并随模块保存；通道不存在时按"没有数据"处理并给出提示。

## 设置

面板标题行右侧两个图标：刷新 = 恢复默认，叉 = 关闭。

| 设置项 | 作用 |
|---|---|
| 组 | 组号；`0` = 自动跟随第一个出现的组 |
| 横滚/俯仰/偏航通道 | 三个通道号（从 `0` 开始），默认 `0 / 1 / 2` |
| 渲染物 | 坐标轴（只看三轴指向）、方块（半透明面 + 棱）、无人机（机身、四臂、桨盘、机头标记） |
| 角度单位 | 数据通道里角度的单位：度 / 弧度。只影响输入解释，读数始终显示为度 |
| 平滑 / 平滑时长(ms) | 姿态是否平滑追随、响应快慢 |
| 缩放 | 机体的显示大小；模型始终居中 |
| 地面网格 / 轴标签 | 是否画参考地面、是否在轴端画 X / Y / Z |
| 反转横滚 / 俯仰 / 偏航 | 适配不同安装方向（只翻符号，不改单位） |
| 失联归零 / 归零延时(ms) | 三个通道停止更新后是否回到单位姿态、多久算失联 |

## 显示口径

- 旋转顺序：先绕机体前后轴滚转（横滚），再绕左右轴俯仰，最后绕竖直轴偏航。
- **失联判定与单通道显示同一条规则**：三个通道的最新目标角度由同一套"新鲜 / 过期"判定给出；开「失联归零」时过期回到单位姿态（0, 0, 0），关时保持最后一帧姿态。
- 某一轴的通道在帧里被标为无效时，该轴保持最后一个有效角度，悬停提示"通道 N 无效"。
- 组/通道是用户输入的持久化值，重启后仍按配置的编号取数。

## 典型用法

- 波形发生器 → 三轴姿态仪：用三路正弦验证姿态动作是否连续。
- 原始 → 波形转换器 → 三轴姿态仪：设备上报的欧拉角转成波形帧后显示。
