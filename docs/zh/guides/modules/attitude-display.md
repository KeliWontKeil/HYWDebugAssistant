# 三轴姿态仪

把波形帧里某一组的三个通道当作横滚、俯仰、偏航，显示物体的三维姿态；渲染物可在坐标轴、方块、无人机之间切换，视角可拖动或用七视角预设调整。三轴通道不能重复；平滑、视角、失联延时越界时红框并保留上一份有效值，不静默夹紧。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · R 1 · P 2 · Y 3" |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口 |
| 姿态区 | 世界网格固定不动，机体按三个角度旋转；默认等轴测；左键拖动可旋转视角；左上角按钮/空格打开七视角面板；左下角有地面坐标系参考轴 |
| 三轴读数 | 当前横滚、俯仰、偏航角，每个轴同时显示角度与弧度；底栏右侧的“数据单位”徽标标明数据通道当前使用度还是弧度 |
| 悬停提示 | 鼠标停在模块上可看到当前状态，不占版面 |

组号与三个通道号在设置面板里编辑，可提前填好并随模块保存；通道不存在时按"没有数据"处理并给出提示。

## 设置

面板标题行右侧两个图标：刷新 = 恢复默认，叉 = 关闭。

| 设置项 | 作用 |
|---|---|
| 组 | 组号，必须是正整数（从 `1` 开始）；没有“0 = 自动”语义 |
| 横滚/俯仰/偏航通道 | 三个通道号（从 `1` 开始，最大 64），默认 `1 / 2 / 3` |
| 渲染物 | 坐标轴（只看三轴指向）、方块（半透明面 + 棱）、无人机（机身、四臂、桨盘、机头标记） |
| 角度单位 | 数据通道里角度的单位：度 / 弧度。只影响输入解释；读数始终同时显示角度与弧度，底栏右侧会标明当前数据单位 |
| 平滑 / 平滑时长(ms) | 姿态是否平滑追随、响应快慢 |
| 缩放 | 机体的显示大小；模型始终居中 |
| 地面网格 / 轴标签 | 是否画参考地面、是否在机体轴与左下地面参考轴的轴端画 X / Y / Z |
| 反转横滚 / 俯仰 / 偏航 | 适配不同安装方向（只翻符号，不改单位） |
| 失联归零 / 归零延时(ms) | 三个通道停止更新后是否回到单位姿态、多久算失联 |

## 显示口径

- 旋转顺序：先绕机体前后轴滚转（横滚），再绕左右轴俯仰，最后绕竖直轴偏航。
- **失联判定与单通道显示同一条规则**：三个通道的最新目标角度由同一套"新鲜 / 过期"判定给出；开「失联归零」时过期回到单位姿态（0, 0, 0），关时保持最后一帧姿态。
- 某一轴的通道在帧里被标为无效时，该轴保持最后一个有效角度，悬停提示"通道 N 无效"。
- **底栏同时显示两种角度**：每个轴给出“度 / 弧度”；右侧“数据单位”徽标显示数据通道当前用度还是弧度，改设置后立即跟随，不需要打开面板确认。读数超出列宽时用省略号，悬停可看全文。
- **机体轴按深度绘制**：朝向相机的外段画在机体前面，背离相机的外段按机体遮挡处理，机体内部那一段不画；轴标签始终在机体之后绘制，避免被半透明面盖住。
- 组/通道是用户输入的持久化值，重启后仍按配置的编号取数。

## 视角操作

- **默认等轴测**：新建或重新打开模块时，相机在等轴测方向；前/后/左/右/上/下仍在面板里。
- **左键拖动**：在姿态区任意位置（按钮/面板本身除外）按住左键拖动可连续旋转视角；只改变相机，不改变 R/P/Y 读数、机体姿态或模块窗口位置。
- **七视角面板**：点左上角立方体按钮，或先点一下姿态区再按空格，打开前/后/左/右/上/下/等轴测七个视角；点一个立即应用并关闭面板。`Esc`、再点按钮或点面板外也能收起。
- **面板布局**：接近 SW 的 4 列 × 3 行；等轴测在顶部一行、上视右侧，不单独放到最右边。每个图标是透明线框立方体，只高亮目标面；当前视角有选中底色。
- **地面参考轴**：左下角的三轴是世界坐标系（X/Y/Z 与机体轴同色），随视角旋转；上视/下视时指向屏幕的轴显示为圆点或圆环。
- **不持久化**：视角只在该模块实例存续期间保持；重开模块回到等轴测。设置里的“恢复默认”只重置设置，不重置视角；需要复位时点面板里的“等轴测”或“前视”。

## 典型用法

- 波形发生器 → 三轴姿态仪：用三路正弦验证姿态动作是否连续。
- 原始 → 波形转换器 → 三轴姿态仪：设备上报的欧拉角转成波形帧后显示。
