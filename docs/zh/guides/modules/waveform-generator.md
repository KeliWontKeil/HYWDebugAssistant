# 波形发生器

按组/通道生成波形帧并从发送口发出；支持连续发送与按 N 个基波周期一次性发送。字段格式错误只标红字段，状态行说明有字段未通过校验；组/通道编号重复、Nyquist、总帧率超限或无启用通道时，状态行说明具体原因，连续发送与发送一次按钮禁用；修正后红框、状态和按钮一起恢复。发送进行中开始类按钮禁用、「停止」可用；空闲时「停止」不可用。切换组/通道时若上一个设置项存在未应用错误，状态行说明旧错误值未被采用、已恢复已保存值。线上格式见[波形帧约定](../../concepts/waveform-frame.md)。

## 界面

| 区域 | 内容 |
|---|---|
| 预览 | 左侧 2 个基波周期；含网格与 1 周期参考线；无标题/轴标题；绘图区左/下为坐标轴，上/右补齐外框，底部只留 x 刻度文字窄带 |
| 组/通道行 | 组行：`通道组` + 组 chips（按组号升序，显示组号 + 组名）+ 加组/删组；通道行：`通道` + 通道 chips（按通道编号升序，显示编号 + 名称）+ 加通道/删通道；两行同一控件/行高/按钮样式，无减号 |
| 组属性（常显） | 组名、组编号、组启用、**组频率/周期、每周期点数**、采样率；组频率和每周期点数为该组所有通道共享的唯一来源 |
| 通道属性 | 通道编号、通道名/启用/波形选择常显；通道编号是 1–64 的正整数，对应波形帧槽位 `编号-1`，组内唯一；波形参数三列排布：基波行（偏移/幅值/相位）、方波行（占空比）、载波行（载波频率/调制比/载波相位）。每格 180×24，内部 72 宽右对齐标签 + 64 宽等宽输入框 + 44 宽单位。运行期按波形隐藏不适用行/单元；无选中通道时参数块隐藏、通道结构禁用 |
| 波形类型 | 正弦、方波、三角、马鞍波、SPWM、SVPWM、噪声（统一 20×20 线条图标 + 文字标签） |
| 发送 | 发送周期数、活动组/全部组预计帧数与字节、连续发送/发送一次/停止三个按钮 |
| 状态行 | 当前状态、载波 Nyquist 警告、发送失败丢弃、结构变化停止 |

## 发送

- **一次性发送**按 N 个基波周期计算帧数；每组独立完成，全部组完成即结束。
- **连续发送**是按钮：点击启动，持续产生帧，直到“停止”或组/通道结构变化；不再使用开关。
- **发送按钮闸门**：空闲时「连续发送」「发送一次」可用、「停止」置灰；发送中前两者置灰、「停止」可用；一次性完成、手动停止、结构变化停止后回到空闲态。
- 组停用或通道停用不产生对应帧；预计帧数只统计启用组。
- 高频组按 1 ms 时间片批量发送，状态行说明不保证逐帧时序。

## 马鞍波

- 连续调制波：标准三次谐波注入 `s = (2/√3)·(sinθ + sin(3θ)/6)`，峰值归一为 1；界面的「幅值」就是复合波峰值（基波为 `2/√3` 倍）。
- 相位/幅值/偏移有效；不使用占空比与载波参数，参数区只显示基波行。
- 与 SPWM/SVPWM 的开关波形不同：马鞍波是连续值，适合作为调制参考/观察形状。

## SPWM / SVPWM

- 载波固定为对称三角波；所有参数都可在界面修改：载波频率、调制比、载波相位、**组基波频率/周期、组每周期点数**、通道相位/幅值/偏移。
- `2 × 载波频率` 必须不超过组采样率（`组每周期点数 × 组频率`）；不满足时拒绝发送并说明，不会静默降频或改用其它载波。
- SVPWM 按通道相位计算；需要三相时把三个通道相位设为 0/120/240。
- 预览固定 2 个基波周期；横轴单位是**数据点序号**（与显示器的索引模式一致），不是时间/周期。载波细节受预览范围限制时，到波形显示器里放大查看。

## 持久化与独立参数

- 组、通道、组名/编号、组频率/周期/每周期点数、通道名/启用、波形及每个通道自己的相位/偏移/幅值/占空比/载波参数、发送周期数，都由模块配置持久化；关闭再打开工作区后恢复。
- 输入框是当前选中组/通道的**编辑镜像**，不是共享变量：切换组/通道时输入框回填该对象的配置；编辑某一格只更新当前对象，不会把值套到其他组或通道。
- 当前选中的组/通道是界面状态，随配置保存用于恢复现场；组/通道结构属于用户创建的对象，不是数据帧派生的临时物，因此与波形显示器的通道组不同，必须持久化。

## 注意

- 视图尺寸由 XAML 根声明：`InitialWidth/InitialHeight = 960×300` 是实例化默认窗口尺寸（含外框），`MinWidth/MinHeight = 960×300` 是运行期下限；内容区由框架扣除固定 chrome。预览横轴是**数据点序号**，不是周期。
- 参数块在 XAML 中默认全显，预览器不刷新也能看到三列完整表单并调整位置；运行期第一次 `Refresh` 才按波形隐藏不适用行/单元。因此预览里这些本会隐藏的行/单元仍占位，可能与相邻控件重叠或遮挡——这是有意为之，用于定位全部控件，不是布局缺陷。所有通道参数输入框同宽，左缘按 180 DIP 列网格对齐；每周期点数在组属性区。
- 图表 `PlotInset` 为 `40,4,4,20`；预览期图表槽位显示外框，框架同时给标签与容器附加范围框，运行期都不出现、不参与布局或 PNG 捕获。
- 噪声没有周期相位语义，运行期隐藏相位单元；偏移/幅值仍有效；每周期点数属于组，始终在组属性区可编辑。切换波形时隐藏行折叠，不留空行。
- 增删组/通道会先停止发送；删除通道后自动选中同位置（末尾则前一个）的残余通道，不会跳回组属性。
- 重复一次性发送从相位 0 重新开始；帧序号继续递增，便于完整性统计。
- 组名/组编号/组频率/组周期/每周期点数在组属性区编辑；通道编号/通道名在通道属性区编辑；显示器端可改显示名，但不改通道编号。旧配置里通道上的每周期点数会在归一化时迁移到组（取最大合法值）；旧配置缺少通道编号时按列表位置补 1 基编号，显式 0/重复标记为非法。
- 组名、组编号、通道编号、通道名和波形参数逐键生效，不需要 Enter 或失焦；非法值保持原配置并给输入框红框。通道编号 0/重复/越界不会自动改写。
- 删除操作只有组行/通道行的垃圾桶；没有减号，避免与垃圾桶重复。
