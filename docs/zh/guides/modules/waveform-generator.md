# 波形发生器

按组/通道生成波形帧并从发送口发出；支持连续发送与按 N 个基波周期一次性发送。

## 界面

| 区域 | 内容 |
|---|---|
| 预览 | 左侧 2 个基波周期；含网格与 1 周期参考线；无标题/轴标题 |
| 组/通道行 | 组行：`通道组` + 组 chips + 加组/删组；通道行：`通道` + 通道 chips + 加通道/删通道；两行同一控件/行高/按钮样式，无减号 |
| 组属性（常显） | 组名、组编号、组启用、**组频率/周期**、采样率；组频率为该组所有通道共享的唯一来源 |
| 通道属性（常显） | 通道名、通道启用、波形类型、相位/偏移、幅值/每周期点数、方波占空比、SPWM/SVPWM 载波频率/调制比/载波相位；无选中通道时整段禁用但位置不变 |
| 波形类型 | 正弦、方波、三角、SPWM、SVPWM、噪声（图标 + 文字标签） |
| 发送 | 发送周期数、活动组/全部组预计帧数与字节、连续发送/发送一次/停止三个按钮 |
| 状态行 | 当前状态、载波 Nyquist 警告、发送失败丢弃、结构变化停止 |

## 发送

- **一次性发送**按 N 个基波周期计算帧数；每组独立完成，全部组完成即结束。
- **连续发送**是按钮：点击启动，持续产生帧，直到“停止”或组/通道结构变化；不再使用开关。
- 组停用或通道停用不产生对应帧；预计帧数只统计启用组。
- 高频组按 1 ms 时间片批量发送，状态行提示“不保证逐帧时序”。

## SPWM / SVPWM

- 载波固定为对称三角波；所有参数都可在界面修改：载波频率、调制比、载波相位、**组基波频率/周期**、通道相位/幅值/偏移、每周期点数。
- `2 × 载波频率` 必须不超过组采样率（`每周期点数 × 组频率`）；不满足时拒绝发送并说明，不会静默降频或改用其它载波。
- SVPWM 按通道相位计算；需要三相时把三个通道相位设为 0/120/240。
- 预览固定 2 个基波周期；横轴单位是**数据点序号**（与显示器的索引模式一致），不是时间/周期。载波细节受预览范围限制时，到波形显示器里放大查看。

## 注意

- 视图内容尺寸由 XAML 根声明：`InitialWidth/InitialHeight = 960×360` 是实例化默认，`MinWidth/MinHeight = 960×360` 是运行期下限；外框 chrome 由框架加。预览横轴是**数据点序号**，不是周期。
- 参数区控件常显，坐标只写在 XAML `Canvas`；预览器不刷新也能看到完整表单，只靠 `IsEnabled` 表达“无选中通道”。
- 增删组/通道会先停止发送；删除通道后自动选中同位置（末尾则前一个）的残余通道，不会跳回组属性。
- 重复一次性发送从相位 0 重新开始；帧序号继续递增，便于完整性统计。
- 组名/组编号/组频率/组周期在组属性区编辑；通道名在通道属性区编辑；显示器端可改显示名。
- 组名、组编号、通道名和波形参数逐键生效，不需要 Enter 或失焦；非法值保持原配置并给输入框红框。
- 删除操作只有组行/通道行的垃圾桶；没有减号，避免与垃圾桶重复。
