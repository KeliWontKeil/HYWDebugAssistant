# TCP 服务端

在本机监听一个端口，把多个客户端的连接合并成一路字节流接进数据流。

## 界面

| 区域 | 内容 |
|---|---|
| 本地地址 | 监听地址的**下拉**（`0.0.0.0`、回环与本机网卡地址）；选 `0.0.0.0` 监听全部网卡 |
| 本地端口 | 监听端口 |
| 最大连接 | 同时接受的客户端数量上限 |
| 禁用 Nagle | 开：小数据立即发送；关：允许内核合并小包 |
| 启动 / 停止 | 开始或停止监听；监听期间参数不可编辑 |
| 状态灯 | 已监听、未监听与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 已连接 | 当前连接路数（单位「路」） |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数，不清连接数 |

## 启动

1. 填写本地地址与端口，必要时限制最大连接数。
2. 点「启动」；状态行显示「正在启动… 地址:端口」，成功后显示「已监听 地址:端口（当前连接 N 路）」。
3. 点「停止」结束监听，已有连接随之关闭。

## 多客户端

所有客户端的字节合并成一路流，按到达顺序进入发送口；接收口收到的数据会写给当前全部连接。

- 当前连接数在「已连接」读数与状态行里显示。
- 达到最大连接数后新的连接会被拒绝，不挤掉已有连接。

## 失败原因

| 状态句 | 含义 | 处置 |
|---|---|---|
| 端口已被占用 | 本机已有程序监听该端口 | 换端口或先关闭占用程序 |
| 监听地址不合法 | 地址格式不对 | 填写本机地址或 `0.0.0.0` |
| 监听端口超出范围 | 端口不在 1–65535 | 修正端口 |
| 监听失败 / 接受连接失败 | 传输层错误 | 看 Issue 详情后重试 |

失败不自动重试：修复原因后手动点「启动」。
