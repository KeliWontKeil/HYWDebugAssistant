# TCP 服务端

在本机监听一个端口，把多个客户端的连接合并成一路字节流接进数据流。本地地址下拉严格同步本机当前可用地址；当前地址消失时选择清空、启动禁用。本地地址非法、端口越界或最大连接数越界时字段标红、「启动」禁用；端口占用、监听失败属于运行时状态，保持可重试。

## 界面

| 区域 | 内容 |
|---|---|
| 本地地址 | 监听地址的**下拉**（`0.0.0.0`、回环与本机网卡地址）；列表严格同步本机当前可用地址，当前地址消失时选择清空、启动禁用；选 `0.0.0.0` 监听全部网卡 |
| 本地端口 | 监听端口；`0` 表示由系统分配可用端口 |
| 最大连接 | 同时接受的客户端数量上限（1–256） |
| 禁用 Nagle | 开：小数据立即发送；关：允许内核合并小包 |
| 启动 / 停止 | 开始或停止监听；监听期间参数不可编辑 |
| 状态灯 | 已监听、未监听与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 已连接 | 当前连接路数（单位「路」） |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数，不清连接数 |

## 启动

1. 填写本地地址与端口，必要时限制最大连接数。
2. 点「启动」；状态行说明正在启动并显示端点，成功后说明已监听与当前连接路数。
3. 点「停止」结束监听，已有连接随之关闭。

## 多客户端

所有客户端的字节合并成一路流，按到达顺序进入发送口；接收口收到的数据会写给当前全部连接。

- 当前连接数在「已连接」读数与状态行里显示。
- 达到最大连接数后新的连接会被拒绝，不挤掉已有连接。

## 参数错误

| 现象 | 处置 |
|---|---|
| 本地地址未选择或不是合法 IP | 空选择只给状态、不标红；非法值字段红框；「启动」禁用 |
| 本地端口不在 0–65535 | 字段红框；「启动」禁用 |
| 最大连接数不在 1–256 | 字段红框；「启动」禁用 |

参数未就绪时状态行说明参数未就绪、启动被禁用；具体原因看字段悬停。

## 失败原因

| 现象 | 处置 |
|---|---|
| 端口已被占用 | 换端口或先关闭占用程序 |
| 监听失败 / 接受连接失败 | 看 Issue 详情后重试 |

失败不自动重试：修复原因后手动点「启动」。
