# HEX / 文本转换器

在本机把文本与十六进制互相转换，用来核对字节内容或准备要发送的数据。不参与数据流，只是一个转换工具。

## 界面

窗口上下两半，各是一组页签：

| 区域 | 内容 |
|---|---|
| 上半「文本 → HEX」 | 页签 1–5，每个页签上方是文本输入，下方是转换结果（只读） |
| 下半「HEX → 文本」 | 页签 1–5，每个页签上方是十六进制输入，下方是转换结果（只读） |

输入变化时结果立即刷新，没有「转换」按钮。结果区只读，可直接选中复制。

## 文本 → HEX

- 文本按 UTF-8 编码成字节，每字节写成两位大写十六进制、空格分隔，例如「你好」得到 `E4 BD A0 E5 A5 BD`。
- 输入为空时结果为空。

## HEX → 文本

- 空白（空格、换行、制表）只作排版，一律忽略；每段必须是两位十六进制。
- 解析出的字节按 UTF-8 解码成文本；不是合法 UTF-8 时给出错误提示，不猜测内容。
- 常见错误：
  - 「「GG」不是合法的十六进制字符」；
  - 「「A」是 1 位；每段必须恰好两位」；
  - 「不是合法的 UTF-8 字节序列」。

## 用法

- 把监视器里看到的字节贴到下半页，确认对应的文本是什么。
- 把要发送的文本放到上半页，复制结果到 HEX 发送器。
