# HEX / 文本转换器

在本机把文本与十六进制互相转换，用来核对字节内容或准备要发送的数据。不参与数据流，只是一个转换工具。

## 界面

窗口上下两半，各是一组页签：

| 区域 | 内容 |
|---|---|
| 上半「文本 → HEX」 | 页签 1–5，每个页签上方是文本输入，下方是转换结果（只读） |
| 下半「HEX → 文本」 | 页签 1–5，每个页签上方是十六进制输入，下方是转换结果（只读） |

输入变化时结果立即刷新，没有「转换」按钮。结果区只读，可直接选中复制。

## 文本 → HEX

- 文本按 UTF-8 编码成字节，每字节写成两位大写十六进制、空格分隔，例如「你好」得到 `E4 BD A0 E5 A5 BD`。
- 顶部三个勾选框与文本发送器同义：`转义`只作用于文本→HEX；`CR`/`LF` 只决定**文本输入与文本→HEX** 的换行档，不再改写 HEX→文本的结果。切换勾选时，文本输入框里已有的全部换行会被替换成同一档；两者都不勾则移除换行。
- Enter 默认写入当前换行档（默认 CRLF）；输入框不解释 C 转义，`\x` 等字面量要等转义开关打开后才在转换时解释。
- 输入为空时结果为空。

## HEX → 文本

- 空白（空格、换行、制表）只作排版，一律忽略；每段必须是两位十六进制。
- 解析出的字节按 UTF-8 解码成文本；不是合法 UTF-8 时给出错误提示，不猜测内容。
- 解码结果**按字节原样保留**：`0A` 是 LF、`0D` 是 CR、`0D0A` 是 CRLF；顶部 CR/LF 勾选不会改写这里的结果。十六进制输入框自己的换行只是分隔符，不做替换。
- 常见错误：
  - 「「GG」不是合法的十六进制字符」；
  - 「「A」是 1 位；每段必须恰好两位」；
  - 「不是合法的 UTF-8 字节序列」。

## 用法

- 把监视器里看到的字节贴到下半页，确认对应的文本是什么。
- 把要发送的文本放到上半页，复制结果到 HEX 发送器。
