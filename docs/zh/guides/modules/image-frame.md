# 图片显示器

在工作区展示一张本地图片或 GIF 动图，像壁纸一样铺满模块内容区。模块本身没有按钮：图片区域右键「更换图片...」或「清除图片」。它不参与数据流，没有端口，也不显示状态行。

## 界面

| 区域 | 内容 |
|---|---|
| 图片区域 | 空态显示「右键选择图片」；有图时等比铺满，比例不匹配时裁掉超出部分 |
| 右键菜单 | 更换图片... / 清除图片（空态时清除不可用） |
| 窗口 | 默认 360×240，最小 160×120；可像其他模块窗口一样自由缩放 |

更换图片时依次打开系统文件选择器和统一的裁切窗口。裁切框的比例取**点击更换图片时模块内容区的长宽比**；确认后只显示所选区域。裁切比例不会在窗口缩放时重新计算，缩放后由铺满规则继续裁掉多余边缘。

图片和裁切是**图片控件自己的持久化状态**，随组合件/工作区保存；源文件之后被移动或删除，已保存的组合件仍能显示图片。它不占用、不修改模块壁纸，清除壁纸也不会清除图片。

## 支持格式

- 静态：PNG、JPEG、BMP、WebP。
- 动图：GIF（GIF87a/89a，支持透明、帧延迟、循环次数）；裁切应用到每一帧。
- 动图 WebP/APNG 按静态首帧显示。

单文件不超过 32 MB；单边不超过 20,000 像素；静态图总像素不超过 3200 万；GIF 最多 512 帧，所有帧总像素不超过 3200 万。超出限制时显示错误提示，不阻塞界面。

## 使用

1. 在模块清单中加入「图片显示器」。
2. 图片区域右键 →「更换图片...」。
3. 选择本地图片或 GIF；在裁切窗口拖动/滚轮调整区域，确认。
4. 拖动窗口边缘调整大小；图片始终铺满，不留白。
5. 右键「清除图片」回到空态；再次右键更换。
6. 保存工作区或组合件；重开后按保存的控件图片状态与裁切恢复，不再依赖原文件路径。

> 组合件包会把图片放在包内 `assets/`，文件名按内容哈希 + **真实扩展名**（如 `<sha256>.jpg`、`<sha256>.gif`），与模块壁纸共用同一个 `assets/` 目录；同一份图既作壁纸又作图片时只落一个文件。移动或分享组合件时请带上整个包目录；只复制 `composite.json` 不包含图片字节。
