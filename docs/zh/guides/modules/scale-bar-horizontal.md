# 横向进度条

把波形帧里某一组的某一个通道显示成横向长条进度条：矩形细条（Windows 进度条观感）、带刻度、默认跟随主题成功色（绿），填充平滑追随数据；颜色可以用框架取色器改成任意颜色。零延时、平滑、小数位越界时红框并保留上一份有效值，不静默夹紧。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · 通道 3" |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口 |
| 进度条 | 矩形轨道 + 填充 + 主/次刻度与数字；标题、读数、单位是条外的独立标签（条本身只在中间，可以压到很矮） |
| 悬停提示 | 鼠标停在模块上可看到当前状态，不占版面 |

组号与通道号在设置面板里编辑，可提前填好并随模块保存；通道不存在时按"没有数据"处理并给出提示。

## 设置

面板标题行右侧两个图标：刷新 = 恢复默认，叉 = 关闭。

| 设置项 | 作用 |
|---|---|
| 组 / 通道 | 组号、通道号都必须是正整数（从 `1` 开始，通道最大 64；内部槽位 = 通道号 - 1）；没有“0 = 自动”语义 |
| 下限 / 上限 | 刻度范围，默认 `0`–`100`；写反时保留上一份有效设置并提示 |
| 颜色 | 点色块打开框架取色器，可选任意颜色；空 = 主题默认（绿）。取色窗的「恢复默认色」清空覆盖 |
| 从零开始填充 | 开：填充从零点向两侧生长（适合正负双向数据）；关：从量程下限开始 |
| 自动回 0 / 回 0 延时(ms) | 数据停止后是否回到 0、多久算停止 |
| 标题 / 单位 | 条上的标题与单位（都可空） |
| 平滑 / 平滑时长(ms) | 是否平滑、响应快慢 |
| 小数位 | 读数保留的小数位 |

「刷新」只把设置恢复默认；组号与通道号保留。

## 显示口径

- **目标值只有一条规则**：样本新鲜就显示样本；超过「回 0 延时」没有新样本时，开「自动回 0」就回到 0，关就保持最后一个值；从未收到数据时显示 0。
- 超出量程时填充停在边界、读数改用警示色；数值本身不被裁剪。
- 组/通道是用户输入的持久化值，重启后仍按配置的编号取数。
- 控件留白为 0：轨道外沿贴住内容边框，文字在条上方；控件只报"条 + 刻度带"的高度，范围框紧贴条与刻度数字。窗口最小高度取框架高度地板 160（更矮的"短窗"还不在框架能力里）。刻度线与数字的间距是 2 DIP。

## 典型用法

- 波形发生器 → 横向进度条：把某一个通道做成一条水平量条。
- 原始 → 波形转换器 → 横向进度条。
