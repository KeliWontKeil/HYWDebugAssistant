# 波形→文本转换器

把波形帧按所选协议编码成原始字节流：接在波形发生器后面，把波形数据变成文本帧或 VOFA+ 帧，交给数据显示器、串口或网络模块发出去。

## 界面

内容宽 360、高 144（窗口 402×194，含外框），固定尺寸。顶行是协议、组号（短标签）与小数位数，说明两行紧随其后；帧信息（帧头帧尾、前缀）纵向堆叠、按协议折叠；统计只有一行（通道数量 / 已转换 / 丢弃 + 清空图标），状态句单独贴底。

| 区域 | 内容 |
|---|---|
| 协议 | 自定义文本帧 / VOFA+ FireWater / VOFA+ JustFloat（设置项，选中即生效）；下方两行随协议切换 |
| 协议说明 | 第一行是该协议的抽象定义，第二行是一个帧示例；只在主应用里随选择变化，预览器显示文本帧的默认内容 |
| 输入写回 | 组号、小数位、帧头、帧尾、前缀都是**输入源**：逐键写入、模块下一拍读取并应用，不需要回车或失焦；非法值保持上一次的有效值 |
| 通道组编号 | 本模块负责的组号（默认 1，必须 ≥1）；**只转换这一组**，其它组直接跳过，没有"转换全部组"的开关；0 非法，不解析、不发送 |
| 小数位数 | 0 表示最短往返表示，1–9 表示固定小数位 |
| 文本帧参数 | 帧头、帧尾是**十六进制字节串**（空白分隔、每段两位，如 `61 62`），两段都不得为空，只在该协议下显示 |
| FireWater 前缀 | 行前缀（例如 `samples`），只在该协议下显示；为空则不写前缀 |
| 统计行 | 一行放三组：通道数量（只读）、已转换、丢弃；右侧 16×16 图标按钮清空统计（悬停提示"清空统计"） |
| 状态 | 最下方单独一行：就绪 / 转换中 / 帧头帧尾十六进制错误 / 已跳过其他通道组 |

## 协议

| 协议 | 输出 | 说明 |
|---|---|---|
| 自定义文本帧 | `61 62 1.20 4.35 3.60 63 64`（线上字节即 `ab 1.20 4.35 3.60 cd`） | 按小数位格式化；帧头帧尾可含不可输入字节 |
| VOFA+ FireWater | `samples:1.0,2.5\n` | 一行一帧；前缀可空 |
| VOFA+ JustFloat | 小端 f32 数组 + 帧尾 `00 00 80 7F` | 二进制；只写到 `channelCount` 个样本 |

一帧超过单包容量时按上限切块发送（流语义允许跨单元续帧）。

## 状态句

| 状态句 | 意思 |
|---|---|
| 就绪 | 已登记协议，等待波形帧 |
| 转换中 | 正在持续编码并发送 |
| 帧头/帧尾必须是两位一组的十六进制（如 0A FF） | 两段没有可用的有效字节，不会编码 | 按两位一组填写 |
| 帧头/帧尾格式无效，仍使用上一次有效值 | 当前文本非法（空、位数不对、非十六进制） | 改正后自动恢复；输入框同时标红 |
| 组号必须是未占用的正整数（从 1 开始） | 组号输入为 0、非数字或越界；不解析、不编码，也不兜底成 1 | 改成 ≥1 的整数 |
| 已跳过其他通道组 | 开了「仅转换该组」，当前帧不属于该组 |

## 旧值迁移

旧版本把帧头/帧尾当文本保存（UTF-8 字节）。第一次激活时，模块会把旧文本按 UTF-8 转成**大写两位、空格分隔**的十六进制写入新值（`ab` → `61 62`，`cd` → `63 64`），随后清空旧值，迁移只发生一次。迁移按文本字节解释，**不会**把 `ab` 当成 `0xAB`。新模块默认 `61 62` / `63 64`。

## 典型用法

- 波形发生器 → 波形 → 原始 → 数据显示器：把波形帧还原成文本行，核对通道值与小数位。
- 波形发生器 → 波形 → 原始 → 串口 / TCP / UDP：把波形数据按 VOFA+ 协议发给下位机或其他上位机。
- 与「原始 → 波形」背靠背：核对编码与解析是否可逆。
