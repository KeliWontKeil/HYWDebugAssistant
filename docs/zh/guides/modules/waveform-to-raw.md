# 波形→文本转换器

把波形帧按所选协议编码成原始字节流：接在波形发生器后面，把波形数据变成文本帧或 VOFA+ 帧，交给数据显示器、串口或网络模块发出去。

## 界面

内容宽 360、高 144，固定尺寸。顶行是协议、组号（短标签）与小数位数，说明两行紧随其后；帧信息（帧头帧尾、前缀）纵向堆叠、按协议折叠；统计只有一行（通道数量 / 已转换 / 丢弃 + 清空图标），状态句单独贴底。

| 区域 | 内容 |
|---|---|
| 协议 | 自定义文本帧 / VOFA+ FireWater / VOFA+ JustFloat（设置项，选中即生效）；下方两行随协议切换 |
| 协议说明 | 第一行是该协议的抽象定义，第二行是一个帧示例；只在主应用里随选择变化，预览器显示文本帧的默认内容 |
| 输入写回 | 组号、小数位、帧头、帧尾、前缀都是**输入源**：逐键写入、模块下一拍读取并应用，不需要回车或失焦；非法值保持上一次的有效值 |
| 通道组编号 | 本模块负责的组号（默认 1）；**只转换这一组**，其它组直接跳过，没有"转换全部组"的开关 |
| 小数位数 | 0 表示最短往返表示，1–9 表示固定小数位 |
| 文本帧参数 | 帧头、帧尾（两段都不得为空），只在该协议下显示 |
| FireWater 前缀 | 行前缀（例如 `samples`），只在该协议下显示；为空则不写前缀 |
| 统计行 | 一行放三组：通道数量（只读）、已转换、丢弃；右侧 16×16 图标按钮清空统计（悬停提示"清空统计"） |
| 状态 | 最下方单独一行：就绪 / 转换中 / 配置错误 / 已跳过其他通道组 |

## 协议

| 协议 | 输出 | 说明 |
|---|---|---|
| 自定义文本帧 | `ab 1.20 4.35 3.60 cd` | 按小数位格式化；帧头帧尾可改 |
| VOFA+ FireWater | `samples:1.0,2.5\n` | 一行一帧；前缀可空 |
| VOFA+ JustFloat | 小端 f32 数组 + 帧尾 `00 00 80 7F` | 二进制；只写到 `channelCount` 个样本 |

一帧超过单包容量时按上限切块发送（流语义允许跨单元续帧）。

## 状态句

| 状态句 | 意思 |
|---|---|
| 就绪 | 已登记协议，等待波形帧 |
| 转换中 | 正在持续编码并发送 |
| 帧头与帧尾不能为空 | 自定义文本帧的两段参数为空，不会编码 |
| 已跳过其他通道组 | 开了「仅转换该组」，当前帧不属于该组 |

## 典型用法

- 波形发生器 → 波形 → 原始 → 数据显示器：把波形帧还原成文本行，核对通道值与小数位。
- 波形发生器 → 波形 → 原始 → 串口 / TCP / UDP：把波形数据按 VOFA+ 协议发给下位机或其他上位机。
- 与「原始 → 波形」背靠背：核对编码与解析是否可逆。
