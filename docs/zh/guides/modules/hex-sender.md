# HEX 发送器

把十六进制字符串解析成字节发到一条数据流。适合发指令帧、寄存器值等二进制内容。当前页 HEX 语法非法时发送按钮禁用；间隔为空或非法时字段标红并禁用连续开关；间隔为 `0` 时字段不红，但状态行说明 0 只能单次发送、连续发送需大于 0。空页点击发送会说明当前页为空、没有发送。

## 界面

| 区域 | 内容 |
|---|---|
| 页签 1–5 | 五个独立输入页，各自保存内容；当前选中的页签就是发送源 |
| 发送 | 立即解析并发送当前页签；右侧小箭头切换输入框的提交键 |
| 连续发送 | 勾选后按间隔重复发送 |
| 间隔 | 连续发送的周期（毫秒，1 毫秒到 24 小时） |
| 已发送 | 累计发出的数据包数（条） |
| 状态行 | 最近一次操作的结果或错误句 |

## 输入格式

- 每段两位十六进制，用空格分隔，例如 `0D 0A` 或 `AA 55 01`。
- 数字可大写可小写，只接受 `0-9`、`A-F`、`a-f`。
- 每段必须恰好两位：写成 `0D0A` 或 `A 55` 都会被拒绝，并指出是哪一段。

解析失败时不发送，状态行说明 HEX 转换失败，并指出具体字符或段长问题。

## 发送

1. 在页签里输入十六进制字符串。
2. 点「发送」解析并发出一次；解析失败则一个字节都不发。
3. 勾选「连续发送」并填好间隔，按周期重复发送当前页签。

发送按钮的小箭头切换输入框提交键：`Enter`（回车提交/Shift+Enter 换行）或 `Ctrl+Enter`（回车换行/Ctrl+Enter 提交）。这是本模块实例自己的持久化值，首次打开沿用设置里的默认档位。点箭头只打开菜单，不发送；主体和箭头段各自响应悬停，`F4` / `Alt+Down` 也能打开菜单。

## 拆包

单个数据包的有效内容上限是 1472 字节。字节数超过上限时拆成多个包依次发送，接收侧会看到同样数量的数据包。

## 典型用法

- **发指令**：HEX 发送器 → 串口模块 → 设备，发送固定指令帧。
- **验证解析**：HEX 发送器 → 数据监视器（开启「十六进制」），逐字节核对。
