# 指针仪表盘

把波形帧里某一组的某一个通道显示成方形指针表盘，指针平滑追随数据，数据停下后按设置回零或保持。零延时、平滑、小数位越界时红框并保留上一份有效值，不静默夹紧。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · 通道 3"；悬停可看更多说明 |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口（不挤占模块画面） |
| 表盘 | 弧线刻度、红色指针；标题、读数、单位都画在圆内（标题在上部、读数在圆心下方、单位紧贴读数） |
| 悬停提示 | 鼠标停在模块上可看到当前状态（等待数据 / 接收中 / 已回零 / 通道无效等），不占版面 |

组号与通道号在设置面板里编辑，可以直接**提前填好**（数据还没来也能配），并随模块保存；通道不存在时按"没有数据"处理并给出提示。

## 设置

设置立即生效并随模块保存。面板标题行右侧两个图标：刷新 = 恢复默认，叉 = 关闭（`Esc` 同效）。

| 设置项 | 作用 |
|---|---|
| 组 | 组号，必须是正整数（从 `1` 开始）；没有“0 = 自动”语义 |
| 通道 | 通道号，必须是正整数（从 `1` 开始，最大 64；内部槽位 = 通道号 - 1） |
| 下限 / 上限 | 刻度范围，默认 `0`–`100`。上限必须大于下限；写反时保留上一份有效设置并提示 |
| 从零开始填充 | 打开时填充弧从 0 开始（零在量程外时夹到端点），关闭时从下限开始；默认打开 |
| 自动回 0 / 回 0 延时(ms) | 数据停止后是否回到 0、超过多久算停止（0 = 下一拍就回零） |
| 表盘文字 | 表盘上部的一行标题，画在圆内（可空） |
| 单位 | 读数下方的单位，画在圆内，例如 `V`（可空） |
| 平滑 / 平滑时长(ms) | 指针是否平滑追随、响应快慢 |
| 小数位 | 读数保留的小数位 |

「刷新」只把上面这些设置恢复默认；组号与通道号保留。

## 显示口径

- **目标值只有一条规则**：样本新鲜就显示样本；超过「回 0 延时」没有新样本时，开「自动回 0」就回到 0，关就保持最后一个值；从未收到过数据时显示 0。
- 三种情况（新鲜、过期回零、过期保持）都由同一条判定给出，控件只画收到的目标值，不另设"无数据"外观。
- 超出量程时指针停在边界、读数改用警示色；数值本身不被裁剪。
- 圆心固定在控件中心；控件报方形尺寸（圆的直径），**虚线范围框是方形控件边界**。外沿始终在控件内，任意宽高比都不会被裁；模块里把控件留白设为 0，环外沿贴住框。标题/读数/单位都画在圆内，**文字不参与尺寸计算**，改标题或单位不会改变表盘大小；超宽文本按内圆弦长省略。量程端点数字用自己的精度（例如 `200.12`），并与邻近主刻度标签避让；端点恰好落在主刻度上时只画一次。

## 典型用法

- 波形发生器 → 指针仪表盘：把某个通道的瞬时值做成一块表盘。
- 原始 → 波形转换器 → 指针仪表盘：设备原始字节转成波形帧后显示。
