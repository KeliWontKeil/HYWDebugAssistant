# 数据监视器

把一条数据流上到达的字节显示成文本或十六进制，可暂停、清空并保存为文本文件。

## 界面

| 区域 | 内容 |
|---|---|
| 显示区 | 到达的内容；行宽由窗口宽度决定，自动折行 |
| 提示行 | 只在缓冲满等情况下出现，占固定高度，不改变布局 |
| 清空 | 清空显示区（不影响接收与计数） |
| 保存 | 把当前显示内容保存为 `.txt` |
| 暂停显示 | 暂停后到达的数据不再写入显示区，接收与计数继续 |
| 数据包换行 | 每个数据包单独占一行 |
| 十六进制 | 以十六进制显示每个字节 |
| 时间戳 | 每个数据包前加 `时:分:秒.毫秒` 前缀；开启后必然每包一行 |
| 状态行 | 保存结果、缓冲满等提示 |

## 显示口径

- **文本方向**：按 UTF-8 解码。没有可见形状的字符与非法字节写成 `⟨XX⟩`（两位大写十六进制），不静默替换、不按 `0x00` 截断；数据里真实的换行保留为换行。`⟨XX⟩` 标记用警示色显示，便于和正文区分。
- **换行标记**：数据里真实换行在只读文本区按种类画灰色箭头：`\r\n`=`↵`、单独 `\r`=`←`、单独 `\n`=`↓`。标记只是显示层装饰，复制与保存的文本里没有它；保存前也会剥离内部哨兵。
- **十六进制方向**：每个字节两位大写十六进制、空格分隔，永不丢字节。
- **行**：只有「数据包换行」或「时间戳」开启时，才由框架在每个包后换行；两者都关时数据直接接在后面，行的划分只由文本框宽度与数据里的换行决定。
- 一包显示多少字节不由模块规定，数据一个字节都不丢。

## 保存

1. 点「保存」，在系统对话框里选择位置与文件名（默认类型为文本文件）。
2. 保存成功后状态行显示路径与行数；未选位置或写入失败时有对应提示。

## 缓冲

显示缓冲有行数与字符上限（见[设置](../settings.md)的高级页），满了丢最旧的内容并提示「缓冲区已满，较早的内容已丢弃」，接收不受影响。

收到短于端口约定的数据报时，该包被丢弃并只提示一次（通常是发送方版本较旧）。

## 典型用法

- 串口 / TCP / UDP 模块 → 数据监视器：观察设备发来的内容。
- 文本发送器 → 数据监视器：验证一条通路是否打通。
- 开启「十六进制」核对字节；开着「时间戳」观察到达节奏。
