# 纵向进度条

把波形帧里某一组的某一个通道显示成竖向长条进度条：矩形细条、带刻度、默认绿色，填充平滑追随数据。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · 通道 3"（窄窗口里与齿轮同排） |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口（比模块宽，不挤占条身） |
| 进度条 | 矩形轨道 + 填充（默认跟随主题成功色）+ 主/次刻度与数字（在文字列右侧；**数字竖着写**，旋转 −90°、自下而上） |
| 文字列 | 标题 / 读数 / 单位在条的**左侧**竖排（沿条的长轴），与横向条"文字在条上方"同构；条拿满剩余高度 |
| 悬停提示 | 鼠标停在模块上可看到当前状态，不占版面 |

窗口默认 130×420，最小宽 96（= 框架宽度地板）：数字竖排后标签带只需约 14 DIP，条只占轨道 + 标签带，所以可以收窄。窄到摘要放不下时摘要按省略号截断（悬停看全文，设置面板里也有完整值）。

设置项与[横向进度条](scale-bar-horizontal.md)一致（组/通道、下限/上限、颜色、从零开始填充、自动回 0、回 0 延时、标题/单位、平滑、小数位；标题行刷新 = 恢复默认）。

## 显示口径

- **目标值只有一条规则**：样本新鲜就显示样本；超过「回 0 延时」没有新样本时，开「自动回 0」就回到 0，关就保持最后一个值；从未收到数据时显示 0。
- 超出量程时填充停在边界、读数改用警示色；数值本身不被裁剪。
- 组/通道是用户输入的持久化值，重启后仍按配置的编号取数。
- 控件留白为 0：轨道从内容边框开始，刻度数字在轨道右侧；控件只报"条 + 标签带"的宽度，范围框紧贴条与数字。
- 端口标记尺寸固定（20×150）：窗口窄到上下边放不下时，标记自动换到左右边（忽略锚点的固定状态）。

## 典型用法

- 波形发生器 → 纵向进度条：窄窗口里放一条竖向量条。
- 原始 → 波形转换器 → 纵向进度条。
