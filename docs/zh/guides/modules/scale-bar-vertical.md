# 纵向刻度条

把波形帧里某一组的某一个通道显示成竖向长条进度条：矩形细条、带刻度、默认绿色，填充平滑追随数据。

## 界面

| 区域 | 内容 |
|---|---|
| 摘要 | 一行小字，例如"组 2 · 通道 3"（窄窗口里与齿轮同排） |
| 设置 | 齿轮按钮：在模块**旁边**弹出独立设置窗口（比模块宽，不挤占条身） |
| 刻度条 | 矩形轨道 + 绿色填充 + 刻度与数字；标题、读数、单位是条上方的独立标签（条只占下面部分，可以压窄） |
| 悬停提示 | 鼠标停在模块上可看到当前状态，不占版面 |

设置项与[横向刻度条](scale-bar-horizontal.md)一致（组/通道、下限/上限、颜色、从零开始填充、自动回 0、回 0 延时、标题/单位、平滑、小数位；标题行刷新 = 恢复默认）。

## 显示口径

- **目标值只有一条规则**：样本新鲜就显示样本；超过「回 0 延时」没有新样本时，开「自动回 0」就回到 0，关就保持最后一个值；从未收到数据时显示 0。
- 超出量程时填充停在边界、读数改用警示色；数值本身不被裁剪。
- 组/通道是用户输入的持久化值，重启后仍按配置的编号取数。

## 典型用法

- 波形发生器 → 纵向刻度条：窄窗口里放一条竖向量条。
- 原始 → 波形转换器 → 纵向刻度条。
