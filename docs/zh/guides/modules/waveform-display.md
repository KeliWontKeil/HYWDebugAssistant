# 波形显示器

接收波形帧，按通道组保存历史，并把**当前选择的 X 范围**绘制成波形。X/Y 起止互逆时两个相关字段同时红框并说明顺序；没有可保存数据时保存按钮禁用。线上格式见[波形帧约定](../../concepts/waveform-frame.md)。

## 界面

| 区域 | 内容 |
|---|---|---|
| 图表 | 当前活动组的波形、网格、x/y 刻度、X 游标 A/B、Y 游标 m/n；绘图区左/下为坐标轴，上/右补齐外框，只框曲线；游标标签在绘图区外，允许覆盖刻度文字；Δ 为第二游标减第一游标（`B−A`、`n−m`），可为正/为负；底部只留 x 刻度文字所需窄带 |
| 数据轴 | 当前组的整个历史范围；轨道占满自身控件宽度（不复制图表 `PlotInset.Left` 的 Y 轴预留，左侧无空白）；主题色近白/深色轨道、深色主/次刻度与数字、1 px 选择边界；可拖两端/中间；边缘/块内指针形状不同；**初始/无数据也有常驻选择带** |
| 组标题栏 | 编号、可编辑名称、数据个数、实际/声明帧率、展开箭头；同时只展开活动组 |
| 通道行 | 通道编号（1 基、对应帧槽位+1）、颜色、可编辑名称、当前 X 窗口内该通道的 `最小值~最大值`、隐藏切换按钮、Y 自适应切换按钮、删除按钮；范围来自通道自身样本，不随游标位置变化 |
| X 起 / X 止 | 精确输入当前显示范围；单位随 X 轴模式；无数据也可编辑 |
| Y 最小 / Y 最大 | 精确输入 Y 范围；编辑时自动关闭 Y 自动；无数据也可编辑 |
| 功能栏 | 固定 `Canvas` 三行：X 行（X 轴模式、X 刻度、X 起/止、跟踪范围、自定义频率开关+输入、自动按钮、暂停开关）、Y 行（Y 自动、Y 最小/最大、Y 刻度、跟随、游标、保存按钮）、第三行（复位/清空/游标、历史开关与上限）；坐标只写在 XAML，窗口变宽只让图表变宽 |
| 状态行 | 当前状态；右侧显示点数与显示范围；点数始终是样本个数，时间模式不换算成秒 |

## 输入与刻度

- 通道名称是可编辑显示名，通道编号是帧槽位号 +1；改名不会改变编号，编号也不由名称推断。
- 组标题栏的组编号来自帧头，必须非 0；组名是可编辑显示名。
- 数值输入框逐键回读（与 HEX 转换器同一模型），内容一变就解析/应用，不需要 Enter 或失焦。
- 非法数值保持原配置并给输入框红框；合法后自动清除。
- X/Y 刻度由用户输入；当刻度过密、标签会重叠时，输入框标红，图表/数据轴自动回退到按实际尺寸算出的可读刻度，范围缩小或窗口变宽后自动恢复。
- 图表与数据轴字号不同，因此两者的可读刻度上限分别按各自的实际宽高和文本测量计算。

## 范围

- **X 范围**同时决定图表窗口、数据轴范围带、X 起止输入和**局部保存**。
- 范围操作按意图统一处理：拖左端、输入 X 起、修改跟踪范围只改宽度，保持当前跟踪状态；整体平移、拖右端、重新框选、输入 X 止关闭跟踪。跟踪开关是独立的显式设置；数据自动推进不改变状态。曲线区左键平移实际改 X 时关闭跟踪；横向缩放时若跟踪开启则保持并更新宽度。任何实际改变范围的操作都会把跨度写回跟踪宽度，重新打开跟踪沿用最后跨度；只点一下范围带（不移动）不算操作，不改变跟踪状态。跟踪推进时 X 起止框跟着刷新，那只是显示回显，不算用户编辑。
- X 轴相关输入的单位只由 X 轴模式决定：`数据个数` 为样本，`时间(s)` 为秒；不再显示独立的“个”单位标签。跟踪范围内部仍按样本保存，时间模式显示/输入秒。
- **单位只影响显示与输入，不改变选择事实**：X 范围、数据轴选择、快照和保存始终以样本为底层事实；同一个手势在 `数据个数` 与 `时间(s)` 下得到同一组样本范围。视图只负责把控件值交给模块，换算由模块统一做一次。
- 无数据时仍可调 X/Y 范围、Y 自动、跟踪范围；X 轴初始宽度为 256 个样本。
- **自定义频率**是模块全局开关：打开后用输入框的 Hz 值作为时间轴，忽略数据帧声明速率；关闭时回落当前活动组帧头速率。它不改变数据帧本身，也不改变组卡里的实际/声明帧率。
- **Y 范围**只影响图表与 Y 游标，不影响 CSV/PNG 保存内容。
- Y 自动在每组内**只增不减**：数据变小不自动缩回；点“Y 轴适应此曲线”、复位或清空才缩小。
- **自动**按钮：按当前数据量把跟踪窗口设为“数据量的一半”（至少 256 个样本），并打开跟踪与 Y 自动。它只设置一次，之后仍按下面的范围操作规则走，不会被反复拉回；无数据时设置为默认窗口。

## 滚轮缩放

曲线区滚轮缩放以鼠标位置为锚点：**有无 Ctrl 都同时缩放 X/Y**。任意一轴触界（例如 X 已到数据最左/最右）时整次滚轮都不生效，不会出现只剩 Y 在缩的情况。滚轮视为手动视口操作，会关闭「跟随」；Y 改变也会关闭 Y 自动。每格的缩放系数由设置页「滚轮缩放系数」决定（默认 1.20，范围 1.05–2.00）。右键拖动缩放仍遵守原有的跟踪规则。
- 选择范围内有多少个点就绘制多少个点；不抽稀。范围很大时状态行显示点数与更新节奏。

## 通道缺失与删除

- 通道行显示的是该通道在当前 X 窗口内的 `最小值~最大值`，与图表游标 A/B 无关；拖动游标不会改变行内读数。当前帧没有有效样本的通道显示“缺失”，从未出现过有效样本的空洞不建行。
- 首次发现一个组时，只为 `validMask` 置位的通道建行：例如首次帧通道数为 3、有效位是通道 1/3，列表只有通道 1、3，不会凭空出现通道 2。后续某个空洞首次变成有效通道时才补行。
- 数据帧的通道数变少时，已有通道不会被删除：多出的通道保留名称、颜色和历史，曲线暂时消失，通道行显示“缺失”；`validMask` 为 0 的当前帧同样显示“缺失”。恢复有效后曲线按原索引接回，缺失期间为空/断线。
- 通道数变多时，已有通道历史不变；新通道从它第一次出现的有效样本位置开始，出现之前为空。
- 组标题栏的“通道数”只统计已出现过且未删除的通道，不统计从未有效的空洞。
- 通道行第三个按钮是“删除通道（清空数据）”；删除只清该通道数据并从本次显示中移除。如果下一帧仍报告该通道，通道会自动恢复，槽位/帧内位置映射保持不变；要长期不显示，用“隐藏”而不是删除。
- 删除最后一个通道会自动移除该通道组和相关数据；如果数据源继续发送同一 `groupId`，下一帧会按新组重新发现并建立新通道。
- 缺失通道仍可通过删除按钮手动移除；隐藏和 Y 自适应在缺失期间禁用。CSV 保留未删除通道的列（缺失区间为空），PNG/曲线不包含缺失或已删除通道。

## 鼠标操作

- **左键拖动曲线区**：平移视口，曲线跟手。水平拖动改 X 范围并关闭跟踪，垂直拖动改 Y 范围并关闭 Y 自动；只在一个方向拖动时，另一方向的自动状态保持。拖到数据边界时范围**停住**，宽度不缩小（不会看起来像缩放）。
- **右键拖动曲线区**：以当前视口中心缩放。水平只改 X 跨度、垂直只改 Y 跨度；向右/向上放大，向左/向下缩小。X 缩放时若正在跟踪，保持跟踪并更新跟踪宽度；否则按目标范围精确应用。
- 左键靠近游标线或游标标签时优先拖动游标，不会触发平移；右键不拖动游标。
- 曲线区拖动的平移/缩放在无数据时也生效：改写会话默认视口，首个数据帧到达后由该视口接管；数据轴范围选择同样可在无数据时调。发生器曲线图没有订阅这些操作，不受影响。
- Y 游标标签显示在绘图区**右侧**（外边距内），不遮挡 Y 轴刻度文字；X 游标标签仍在绘图区上沿。

## 暂停

- 打开功能栏的“暂停”开关后，模块继续排空输入端口，但**不解析、不建组、不写入任何通道组的历史**；已显示的波形、范围、游标和数据轴保持静止。
- 暂停期间仍可缩放、平移、切换组、清空/复位和保存；这些操作只基于已有历史，不会因为数据源仍在发送而改变波形。
- 关闭暂停后从下一帧继续，不补发暂停期间的数据；暂停造成的序号缺口不计入丢帧，恢复后重新开始测实际帧率。
- 暂停是持久化开关；清空/显示复位不会自动恢复接收，需用户显式关闭暂停。

## 保存

- **局部保存**：当前 X 范围，CSV 宽表（样本索引、时间、各通道）。
- **全部保存**：活动组全部历史。
- **保存 PNG**：只捕获图表本身。

## 持久化

- **设置由值持久化**：X 轴模式、X/Y 刻度、跟踪开关与范围、游标开关、暂停开关、自定义频率开关/值、非活动组历史开关与上限，都是持久化值；关闭再打开工作区后恢复。
- **数据帧派生的组/通道不持久化**：组 ID、通道数、名称、颜色、显隐、删除标记、Y 自动/范围、当前 X 范围、历史样本、活动组/活动通道都只存在于本次运行的运行期状态。重启后没有组，下一帧按数据帧重新发现；不会出现“配置里有组、右栏却隐身”的中间态。
- **删除是瞬时的**：删除通道只影响当前显示/清空历史；下一帧仍报告该通道时自动恢复。长期隐藏用“隐藏”开关（同样只保持本次会话）。
- 组名/通道名/颜色/显隐的修改只影响当前运行期，不进入组合件配置；这是“数据驱动对象不持久化”的直接结果。

## 注意

- 视图尺寸由 XAML 根声明：`InitialWidth/InitialHeight = 960×600` 是实例化默认窗口尺寸（含外框），`MinWidth/MinHeight = 960×600` 是运行期下限；内容区由框架扣除固定 chrome。
- 图表/数据轴/右栏随窗口伸缩；底部输入、按钮、状态行是固定坐标 `Canvas`，预览器与运行期使用同一组坐标。预览器不调用运行期 `Refresh`，XAML 默认全显；运行期会隐藏的控件在预览里仍占位，可能遮挡相邻控件，这是有意为之。
- 图表 `PlotInset` 是唯一绘图区边距：显示器为 `50,20,4,20`；预览期图表槽位显示外框，框架同时给标签与容器附加范围框，运行期都不出现、不参与布局或 PNG 捕获。
- 组名/通道名可改；颜色点击色块打开框架调色窗口。自动色只在通道首次出现数据时分配一次，固定为 7 档归一化 RGB（`#0073BD`、`#D9541A`、`#EDB021`、`#7D2E8F`、`#78AB30`、`#4DBFED`、`#A3142E`）；点“恢复自动色”后重新分配。游标线使用独立的洋红色 `ChartCursor` token，不与任何自动色重复。
- 隐藏、Y 自适应、删除是通道行右侧的三个行内按钮；一个组首次出现时默认全部通道可见，隐藏后可恢复。手动改过 Y 范围或右键竖向缩放后，点一次通道的 Y 自适应即选中该通道并显示开启态，再点一次回到全部通道。
- “清空数据”会清历史并同时执行一次轻量显示复位；“显示复位”只执行轻量显示复位并保留历史。两者都恢复 X/Y 默认视口与显示设置，但保留组名、通道名、颜色、显隐和非活动组历史设置。
- 非活动组默认保留历史，可关闭；历史上限仍按样本个数计（不随 X 轴模式切换为秒），指非活动组保留的样本帧合计，0 表示不限；活动组不受该上限影响，界面显示“已用 / 上限”。达到上限时丢弃最旧样本、继续写入新样本，不停止接收。
- CSV 的 `time_seconds`、图表时间轴、数据轴和 X 起止都使用同一个有效速率（自定义频率或帧声明速率）。
