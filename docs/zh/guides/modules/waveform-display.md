# 波形显示器

接收波形帧，按通道组保存历史，并把**当前选择的 X 范围**绘制成波形。

## 界面

| 区域 | 内容 |
|---|---|---|
| 图表 | 当前活动组的波形、网格、x/y 刻度、X 游标 A/B、Y 游标 m/n；绘图区左/下为坐标轴，上/右补齐外框，只框曲线；游标标签在绘图区外，允许覆盖刻度文字；Δ 为第二游标减第一游标（`B−A`、`n−m`），可为正/为负；底部只留 x 刻度文字所需窄带 |
| 数据轴 | 当前组的整个历史范围；轨道占满自身控件宽度（不复制图表 `PlotInset.Left` 的 Y 轴预留，左侧无空白）；主题色近白/深色轨道、深色主/次刻度与数字、1 px 选择边界；可拖两端/中间；边缘/块内指针形状不同；**初始/无数据也有常驻选择带** |
| 组标题栏 | 编号、可编辑名称、数据个数、实际/声明帧率、展开箭头；同时只展开活动组 |
| 通道行 | 颜色、可编辑名称、A/B 读数、隐藏切换按钮、Y 自适应切换按钮 |
| X 起 / X 止 | 精确输入当前显示范围；单位随 X 轴模式；无数据也可编辑 |
| Y 最小 / Y 最大 | 精确输入 Y 范围；编辑时自动关闭 Y 自动；无数据也可编辑 |
| 功能栏 | 固定 `Canvas` 三行：X 行（X 轴模式、X 刻度、X 起/止、跟踪范围、自定义频率开关+输入）、Y 行（Y 自动、Y 最小/最大、Y 刻度、跟随、游标、保存按钮）、第三行（复位/清空/游标、历史开关与上限）；坐标只写在 XAML，窗口变宽只让图表变宽 |
| 状态行 | 当前状态；右侧显示点数与显示范围 |

## 输入与刻度

- 所有数值框逐键回读（与 HEX 转换器同一模型），内容一变就解析/应用，不需要 Enter 或失焦。
- 非法数值保持原配置并给输入框红框；合法后自动清除。
- X/Y 刻度由用户输入；当刻度过密、标签会重叠时，输入框标红，图表/数据轴自动回退到按实际尺寸算出的可读刻度，范围缩小或窗口变宽后自动恢复。
- 图表与数据轴字号不同，因此两者的可读刻度上限分别按各自的实际宽高和文本测量计算。

## 范围

- **X 范围**同时决定图表窗口、数据轴范围带、X 起止输入和**局部保存**。
- 范围操作按意图统一处理：拖左端、输入 X 起、修改跟踪范围只改宽度，保持当前跟踪状态；整体平移、拖右端、重新框选、输入 X 止关闭跟踪。跟踪开关是唯一显式设置；数据自动推进不改变状态。任何实际改变范围的操作都会把跨度写回跟踪宽度，重新打开跟踪沿用最后跨度；只点一下范围带（不移动）不算操作，不改变跟踪状态。跟踪推进时 X 起止框跟着刷新，那只是显示回显，不算用户编辑。
- X 轴相关输入的单位只由 X 轴模式决定：`数据个数` 为样本，`时间(s)` 为秒；不再显示独立的“个”单位标签。跟踪范围内部仍按样本保存，时间模式显示/输入秒。
- 无数据时仍可调 X/Y 范围、Y 自动、跟踪范围；X 轴初始宽度为 256 个样本。
- **自定义频率**是模块全局开关：打开后用输入框的 Hz 值作为时间轴，忽略数据帧声明速率；关闭时回落当前活动组帧头速率。它不改变数据帧本身，也不改变组卡里的实际/声明帧率。
- **Y 范围**只影响图表与 Y 游标，不影响 CSV/PNG 保存内容。
- Y 自动在每组内**只增不减**：数据变小不自动缩回；点“Y 轴适应此曲线”、复位或清空才缩小。
- 选择范围内有多少个点就绘制多少个点；不抽稀。范围很大时状态行显示点数与更新节奏。

## 保存

- **局部保存**：当前 X 范围，CSV 宽表（样本索引、时间、各通道）。
- **全部保存**：活动组全部历史。
- **保存 PNG**：只捕获图表本身。

## 注意

- 视图内容尺寸由 XAML 根声明：`InitialWidth/InitialHeight = 960×580` 是实例化默认，`MinWidth/MinHeight = 960×580` 是运行期下限；外框 chrome 由框架加。
- 图表/数据轴/右栏随窗口伸缩；底部输入、按钮、状态行是固定坐标 `Canvas`，预览器与运行期使用同一组坐标。
- 图表 `PlotInset` 是唯一绘图区边距：显示器为 `50,20,4,20`；预览期图表槽位显示外框，框架同时给标签与容器附加范围框，运行期都不出现、不参与布局或 PNG 捕获。
- 组名/通道名可改；颜色点击色块打开框架调色窗口。自动色只在通道首次出现数据时分配一次；点“恢复自动色”后重新分配。
- 隐藏是切换按钮；一个组首次出现时默认全部通道可见，隐藏后可恢复。
- 清空会清历史、X 范围与 Y 自动锁存；复位恢复显示默认并保留历史。
- 非活动组默认保留历史，可关闭；历史上限仍按样本个数计（不随 X 轴模式切换为秒），指非活动组保留的样本帧合计，0 表示不限；活动组不受该上限影响，界面显示“已用 / 上限”。
- CSV 的 `time_seconds`、图表时间轴、数据轴和 X 起止都使用同一个有效速率（自定义频率或帧声明速率）。
