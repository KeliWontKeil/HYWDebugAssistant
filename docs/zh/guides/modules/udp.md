# UDP

绑定一个本地 UDP 端口收发数据报，把收到的数据报接进数据流。本地地址下拉严格同步本机当前可用地址；当前地址消失时选择清空、绑定禁用。本地地址/端口非法时字段标红、「绑定」禁用；目标地址/端口非法时标红但不阻止绑定；绑定失败、端口占用属于运行时状态，保持可重试。

## 界面

| 区域 | 内容 |
|---|---|
| 本地地址 | 绑定地址的**下拉**（`0.0.0.0`、回环与本机网卡地址）；列表严格同步本机当前可用地址，当前地址消失时选择清空、绑定禁用；选 `0.0.0.0` 绑定全部网卡 |
| 本地端口 | 绑定端口（0–65535）；`0` 表示由系统分配可用端口 |
| 目标地址 | 默认收件人地址；留空表示只接收、不发送 |
| 目标端口 | 默认收件人端口（0–65535）；目标地址非空时须为 1–65535 |
| 允许广播 | 向广播地址发送时必须开启 |
| 绑定 / 解绑 | 开始或停止绑定；绑定期间参数不可编辑 |
| 状态灯 | 已绑定、未绑定与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数 |

## 绑定

1. 填写本地地址与端口，需要发送时再填目标地址与端口。
2. 点「绑定」；状态行说明正在绑定并显示端点，成功后说明已绑定。
3. 点「解绑」停止。

## 一次一报

UDP 保留数据报边界：每收到一个数据报就是一个数据单元，不合并、不拆分。

- 超过单包上限的数据报被丢弃并计入超长丢弃。
- 发送时接收口的数据单元写成一个个数据报发给目标地址。
- 目标地址留空时只收不发。

## 广播

向 `255.255.255.255` 或网段广播地址发送前，必须先打开「允许广播」；否则发送失败。

## 参数错误

| 现象 | 处置 |
|---|---|
| 本地地址未选择或不是合法 IP | 空选择只给状态、不标红；非法值字段红框；「绑定」禁用 |
| 本地端口不在 0–65535 | 字段红框；「绑定」禁用 |
| 目标地址非法或填了通配地址 | 字段红框，但**不阻止绑定**（只收仍可用） |
| 目标端口不在 0–65535，或目标地址非空时填 0 | 字段红框，但**不阻止绑定** |

参数未就绪时状态行说明参数未就绪、绑定被禁用；具体原因看字段悬停；目标字段的错误不影响只收。

## 失败原因

| 现象 | 处置 |
|---|---|
| 端口已被占用 | 换端口或先关闭占用程序 |
| 绑定失败 | 看 Issue 详情后重试 |
