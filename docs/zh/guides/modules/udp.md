# UDP

绑定一个本地 UDP 端口收发数据报，把收到的数据报接进数据流。

## 界面

| 区域 | 内容 |
|---|---|
| 本地地址 | 绑定地址的**下拉**（`0.0.0.0`、回环与本机网卡地址）；选 `0.0.0.0` 绑定全部网卡 |
| 本地端口 | 绑定端口 |
| 目标地址 | 默认收件人地址；留空表示只接收、不发送 |
| 目标端口 | 默认收件人端口 |
| 允许广播 | 向广播地址发送时必须开启 |
| 绑定 / 解绑 | 开始或停止绑定；绑定期间参数不可编辑 |
| 状态灯 | 已绑定、未绑定与故障 |
| 已接收 / 已发送 / 已丢弃 | 累计字节数 |
| 状态行 | 当前状态或失败原因 |
| 清空计数 | 只清计数 |

## 绑定

1. 填写本地地址与端口，需要发送时再填目标地址与端口。
2. 点「绑定」；状态行显示「正在绑定… 地址:端口」，成功后显示「已绑定 地址:端口」。
3. 点「解绑」停止。

## 一次一报

UDP 保留数据报边界：每收到一个数据报就是一个数据单元，不合并、不拆分。

- 超过单包上限的数据报被丢弃并计入超长丢弃。
- 发送时接收口的数据单元写成一个个数据报发给目标地址。
- 目标地址留空时只收不发。

## 广播

向 `255.255.255.255` 或网段广播地址发送前，必须先打开「允许广播」；否则发送失败。

## 失败原因

| 状态句 | 含义 | 处置 |
|---|---|---|
| 端口已被占用 | 本机已有程序绑定该端口 | 换端口或先关闭占用程序 |
| 地址不合法 / 本地端口超出范围 | 地址或端口格式不对 | 修正后重试 |
| 目标地址不能是通配地址 | 把 `0.0.0.0` 填进了目标 | 填实际收件人地址 |
| 绑定失败 | 传输层错误 | 看 Issue 详情后重试 |
