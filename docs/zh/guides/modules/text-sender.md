# 文本发送器

把文本按 UTF-8 编码发到一条数据流。可以手动发一次，也可以按间隔连续发送。

## 界面

| 区域 | 内容 |
|---|---|
| 页签 1–5 | 五个独立输入页，各自保存内容；当前选中的页签就是发送源 |
| 发送 | 立即发送当前页签的内容 |
| 连续发送 | 勾选后按间隔重复发送当前页签 |
| 间隔 | 连续发送的周期（毫秒，1 毫秒到 24 小时）；单位 `ms` 是旁边的普通文本 |
| 已发送 | 累计发出的数据包数（条） |
| 状态行 | 最近一次操作的结果或错误句 |

## 发送

1. 在页签里输入文本，点击页签切换输入页。
2. 点「发送」发出一次；空内容不会发送，状态行给出提示。
3. 勾选「连续发送」并填好间隔，每个周期把当前页签发一次；取消勾选停止。中途切换页签不重启计时，但下一拍发的是新页签的内容。

## 拆包

单个数据包的有效内容上限是 1472 字节。文本超过上限时按字符边界拆成多个包依次发送，接收侧会看到同样数量的数据包；拆包数量写进状态行。

中文等多字节字符不会被拆到两个包里。

## 状态句

| 状态句 | 意思 | 处置 |
|---|---|---|
| 输入内容为空，无法发送 | 当前页签没有内容 | 输入内容或换页签 |
| 未设置发送间隔，连续发送启动失败 | 勾了连续发送但间隔为空 | 填写间隔 |
| 发送间隔必须是 1–86400000 的整数（毫秒） | 间隔格式或范围不对 | 改成整数毫秒 |
| 内容超过单包上限（1472 字节），已拆成 N 个数据包发送 | 已按字符边界拆包 | 无需处理；对端会收到 N 条 |

## 典型用法

- **验证通路**：文本发送器 → 数据监视器，发送后观察监视器里的文本。
- **发给设备**：文本发送器 → 串口 / TCP / UDP 模块，由接入模块把内容写给设备。
