# 文本发送器

把文本按 UTF-8 编码发到一条数据流。可以手动发一次，也可以按间隔连续发送。

## 界面

| 区域 | 内容 |
|---|---|
| 页签 1–5 | 五个独立输入页，各自保存内容；当前选中的页签就是发送源 |
| 发送 | 立即发送当前页签的内容；右侧小箭头切换输入框的提交键（见下） |
| 连续发送 | 勾选后按间隔重复发送当前页签 |
| 间隔 | 连续发送的周期（毫秒，1 毫秒到 24 小时）；单位 `ms` 是旁边的普通文本 |
| 已发送 | 累计发出的数据包数（条） |
| 转义字符 | 勾选框：打开后把字面 `\...` 按 C 字符串语法解释（见下）；关闭时反斜杠原样 |
| 换行 | 决定按 Enter 写入的换行，并把当前输入框已有换行统一成 `\r\n` / `\r` / `\n` / 无 |
| 状态行 | 最近一次操作的结果或错误句 |

## 发送

1. 在页签里输入文本，点击页签切换输入页。
2. 点「发送」发出一次；空内容不会发送，状态行给出提示。
3. 勾选「连续发送」并填好间隔，每个周期把当前页签发一次；取消勾选停止。中途切换页签不重启计时，但下一拍发的是新页签的内容。

## 输入提交键

发送按钮的小箭头打开一个两项菜单：`Enter` 或 `Ctrl+Enter`。

- `Enter`：回车提交、Shift+Enter 换行。
- `Ctrl+Enter`：回车换行、Ctrl+Enter 提交。

点箭头只打开菜单，不发送；发送按钮主体和箭头段各自响应悬停，`F4` / `Alt+Down` 也能打开菜单。

这是本模块实例自己的值（持久化）：首次打开时沿用设置页「多行输入提交键」的默认值，之后改它只影响这个模块。它同时对五个输入页签生效；空值或未知档位按 `Ctrl+Enter` 处理。行内按这个键提交后，等同点一次「发送」。

## 转义与换行

这三项用**勾选框**表达；它们各管各的：

- 「转义字符」把字面 `\...` 按 C 字符串语法解释：`\\ \' \" \? \a \b \f \n \r \t \v`、`\xH`/`\xHH`、`\ooo`（1–3 位八进制）。未知转义保留字面反斜杠。`\x`/八进制按字符码位解释（`\x41` = `A`）；需要任意原始字节请用 HEX 发送器。
- 「换行」决定**按 Enter 写入什么**，同时会**把当前输入框里已有的全部换行**统一成勾选档：两个都勾写 `\r\n`，只勾 `CR` 写 `\r`，只勾 `LF` 写 `\n`；两者都不勾则不写换行，并移除已有换行。切换勾选时立刻归一当前页；其他页在切过去时归一。
- 真实换行发送时原样保留；转义写出的 `\r` / `\n` 是显式字符，和「换行」开关无关。文本发送器不再在发送时按 CR/LF 裁剪真实换行。

默认：转义关闭，`CR` 与 `LF` 都勾选（Enter 写 `\r\n`）。

## 拆包

单个数据包的有效内容上限是 1472 字节。文本超过上限时按字符边界拆成多个包依次发送，接收侧会看到同样数量的数据包；拆包数量写进状态行。

中文等多字节字符不会被拆到两个包里。

## 状态句

| 状态句 | 意思 | 处置 |
|---|---|---|
| 输入内容为空，无法发送 | 当前页签没有内容 | 输入内容或换页签 |
| 未设置发送间隔，连续发送启动失败 | 勾了连续发送但间隔为空 | 填写间隔 |
| 发送间隔必须是 1–86400000 的整数（毫秒） | 间隔格式或范围不对 | 改成整数毫秒 |
| 内容超过单包上限（1472 字节），已拆成 N 个数据包发送 | 已按字符边界拆包 | 无需处理；对端会收到 N 条 |

## 典型用法

- **验证通路**：文本发送器 → 数据监视器，发送后观察监视器里的文本。
- **发给设备**：文本发送器 → 串口 / TCP / UDP 模块，由接入模块把内容写给设备。
