# 设置

活动栏「设置」打开设置弹窗，按用途分为七个页签。改动先暂存，点「应用」或「确认」后生效；「取消」丢弃本次修改，「恢复默认设置」只恢复当前页。

## 常规

| 项 | 说明 |
|---|---|
| 语言 | 当前跟随系统；更多语言随后续版本提供 |
| 日志级别 | 诊断日志的记录级别 |
| 刷新率（Hz） | 界面刷新频率；越高占用 CPU 越多 |
| 显示性能监视 | 在活动栏底部显示 CPU、内存、线程与 GC 计数，约 1 秒采样 |
| 不可显示字符 | 打开时显示为警示色 `⟨XX⟩`，关闭时显示为方框 `□`；只影响显示，复制/保存/发送仍用原始字符；换行箭头不受影响 |
| 对齐自动建网 | 打开后，靠近且端口对齐的模块在松手时自动建网 |

## 外观

主题方案、壁纸、色板与字体，详见[外观](appearance.md)。

## 窗口与交互

| 分组 | 项 |
|---|---|
| 主窗口 | 窗口比例（默认 9:19.5）、尺寸固定 |
| 显示与交互 | 应用整体置顶、显示叠加信息层、吸附距离（2–8 像素） |
| 关闭主窗口 | 每次询问 / 保存并退出 / 不保存退出 |
| 多行输入提交键 | 新模块实例的默认提交键：Ctrl+Enter 提交、Enter 提交，或只能用模块按钮提交；实例可用发送按钮的小箭头覆盖 |
| 滚轮缩放系数 | 波形曲线区每格滚轮的缩放比例（1.05–2.00，默认 1.20） |

## 快捷键

- 列出全部应用内动作与当前绑定，默认绑定为：模块清单 M、Issue I、设置 S、拓扑诊断 T、叠加层 L、吸附 G、全部锁定 Ctrl+L、固定锚点 Ctrl+P、应用置顶 Ctrl+T、全部置前 Ctrl+R、显示全部 Ctrl+W。
- 选中某一项的输入框后按下新组合键即可修改；「默认」恢复该项，「全部恢复默认」恢复全部。
- 同一个组合键被两项使用时给出冲突提示，只有前一项生效。
- 作用域为应用内：本应用任一窗口聚焦时生效；不支持窗口失焦后仍响应的系统级热键。

## 存储

显示五个功能根的只读路径，并可点「打开」在文件管理器中定位：设置、模块、组合、工作区、日志。

这些目录都在程序目录下，按功能分根；保存组合时也可以另选位置，工作区快照随退出行为写入。

## 高级

集中放置通常不需要调整的机制参数，误调会影响所有模块。按分组组织：

| 分组 | 内容 |
|---|---|
| 队列与缓冲 | 每口队列容量、缓冲满时策略、饱和判定深度与持续、最大滞留时间 |
| 外部接入 | 外部写超时、探活节拍、发送积压容量、适配件暂存、关闭等待、设备丢失判定 |
| 状态显示 | 积压显示进入 / 退出深度、状态滞回、丢弃显示保持；只影响状态行，不改丢弃与计数 |
| 文本与内存 | 每个模块文本显示缓冲的行数上限与字符预算；修改后立即裁剪已有缓冲 |
| 运行与生命周期 | 停止等待上限 |

生效时机：队列容量与满时策略对新建队列生效；写超时、暂存容量、关闭等待对新建或重新打开的会话生效；其余立即生效。当前生效值可在拓扑诊断与模块状态行里核对。
