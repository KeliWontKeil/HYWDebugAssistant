# 吸附与拼接

拖动或缩放窗口时吸附到参照线，把窗口拼在一起，并让同一组一起移动。

## 吸附

- 拖动窗口时，窗口的边、中线与端口位置会吸附到其它窗口的边、中线与端口位置：**对齐**只认同层窗口，**贴合**跨层都算；主窗口的四条边都作**对齐**参照。
- 缩放窗口时，只有正在移动的边参与吸附：它会吸到同层其它窗口的外框边、主窗口的边，或另一个窗口的宽/高（尺寸相等）。缩放不吸中线与端口。
- 优先级统一为：**贴合 > 边对齐 > 尺寸相等**。端口/中心只用于拖动。边对齐用吸附距离；贴合与尺寸相等用它的两倍。
- 尺寸相等命中时窗口停在相同的宽/高，状态栏会说明参照窗口；它没有共享边，不画对齐虚线。尺寸目标低于最小或高于最大时直接忽略。
- 只有模块左边缘贴主窗口右边缘才算**拼上/成组**；主窗口左/上/下边缘只用于吸齐，不成组。贴壳件与主窗口构成**接地整体**：拖动其中任何一个，整块（主窗口 + 全部贴壳件）一起移动，贴壳边不会被撕开；未贴壳的组留在原处。按住 Ctrl 拖主窗口则把主窗口从拼组里拖开（本次拖动内不重新粘回），未贴上的模块留在原处。
- 模块层由窗口的叠放顺序与正面积重合自动决定：同层窗口不会重合；压住下方窗口的窗口会升到更高层。层只决定谁压在谁上面，**不参与"能不能拼"**——两块只要边缘贴合且互不遮挡，就在同一组里，层号差多少都一样。
- 新模块默认落在中央放置区：正常以主窗口右侧为左边界、约占工作区 75%，四周留边；区内按“自上而下、从左到右”铺开。第一层排满后第二层仍在同一区域按行列铺开，层间有坐标偏移，不是直接叠一个点；层数不设固定上限。已有布局和手动拖动不受限制。
- 点击、拖动或抬升窗口会改变叠放顺序，层随之变化；用户不需要设置层号。
- 主窗口是唯一的跨层锚点：任意层模块都能贴主窗口。抬升只按拼接组——点哪个模块，只有它所在那一组排到最前，主窗口与其它组的位置不动。
- 吸附发生时出现对齐标线，状态行给出对齐提示；尺寸相等只给状态提示，不画虚假的共享边虚线。
- 吸附距离是设置项（2–8 像素，默认 4）；相邻边贴合与尺寸相等按它的两倍判定。
- 按住 Alt 拖动或缩放可临时暂停吸附。

## 拼接与成组

- 两个窗口的边缘贴合（间隙在容差内）且**互不遮挡**，就成了一个拼接组——跨层也成立；吸附本身不改变归属，位置才决定是否成组。
- 吸附只在**目标层放得下**时发生：候选位置若压住同一层或更高层的窗口就不采用，改试下一个候选；压住更低的窗口是允许的，模块落在它们之上。所以密集区域里也能把模块拼到另一块的悬空边上。
- 组拖动时组内每个成员的边都参与吸附；两个组贴边后可以在下一次拖动时合并为一组。
- 组在拖动开始时冻结；拖动中整组刚体移动，落手后按当前几何重新分层/分组。
- 模块或组重合时不算拼接，也不会自动建网；拖开到刚好相接即可重新拼接。
- 组不是容器：没有布局树、没有停靠槽位，只保存每个窗口的位置。
- 拖动组内任一窗口，整组一起移动；按住 Ctrl 拖动只移动当前窗口。
- 把窗口拖开即拆开，不需要「取消分组」。
- 点窗口选中时，同一组会一起选中。

## 开关

| 入口 | 作用 |
|---|---|
| 设置 → 窗口与交互 → 吸附距离 | 调整吸附半径 |
| 交互页「几何吸附」开关 | 全局开关吸附 |
| 快捷键 G（默认） | 快速切换吸附，状态栏说明吸附是开还是关 |
