# 吸附与拼接

拖动时吸附到参照线，把窗口拼在一起，并让同一组一起移动。

## 吸附

- 拖动窗口时，窗口的边、中线与端口位置会吸附到同层其它窗口的边、中线与端口位置，以及主窗口右边缘的那条竖线。
- 贴主窗口只认模块左边缘；贴壳组拖动时主窗口随组一起移动，未贴上的模块留在原处。
- 模块层由窗口的叠放顺序与重合关系自动决定：同层窗口不会重合；压住下方窗口的窗口会升到更高层，只有同层才能吸附。
- 点击、拖动或抬升窗口会改变叠放顺序，层随之变化；用户不需要设置层号。
- 主窗口是跨层锚点：任意层模块都能贴主窗口；选中/抬升只在本层，移动主窗口会带走所有贴壳组。
- 吸附发生时出现对齐标线，状态行给出提示（例如「已与模块中线对齐」）。
- 吸附距离是设置项（2–8 像素，默认 4）；相邻边贴合时按它的两倍判定。
- 按住 Alt 拖动可临时暂停吸附。

## 拼接与成组

- 两个窗口的边缘贴合（间隙在容差内）且**不重合**，就成了一个拼接组；吸附本身不改变归属，位置才决定是否成组。
- 组拖动时组内每个成员的边都参与吸附；两个组贴边后可以在下一次拖动时合并为一组。
- 模块或组重合时不算拼接，也不会自动建网；拖开到刚好相接即可重新拼接。
- 组不是容器：没有布局树、没有停靠槽位，只保存每个窗口的位置。
- 拖动组内任一窗口，整组一起移动；按住 Ctrl 拖动只移动当前窗口。
- 把窗口拖开即拆开，不需要「取消分组」。
- 点窗口选中时，同一组会一起选中。

## 开关

| 入口 | 作用 |
|---|---|
| 设置 → 窗口与交互 → 吸附距离 | 调整吸附半径 |
| 交互页「几何吸附」开关 | 全局开关吸附 |
| 快捷键 G（默认） | 快速切换吸附，状态栏显示「吸附：开 / 关」 |
