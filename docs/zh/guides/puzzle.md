# 吸附与拼接

拖动时吸附到参照线，把窗口拼在一起，并让同一组一起移动。

## 吸附

- 拖动窗口时，窗口的边、中线与端口位置会吸附到其它窗口的边、中线与端口位置，以及主窗口右边缘的那条竖线。
- 吸附发生时出现对齐标线，状态行给出提示（例如「已与模块中线对齐」）。
- 吸附距离是设置项（2–8 像素，默认 4）；相邻边贴合时按它的两倍判定。
- 按住 Alt 拖动可临时暂停吸附。

## 拼接与成组

- 两个窗口的边缘贴合（间隙在容差内）就成了一个拼接组；吸附本身不改变归属，位置才决定是否成组。
- 组不是容器：没有布局树、没有停靠槽位，只保存每个窗口的位置。
- 拖动组内任一窗口，整组一起移动；按住 Ctrl 拖动只移动当前窗口。
- 把窗口拖开即拆开，不需要「取消分组」。
- 点窗口选中时，同一组会一起选中。

## 开关

| 入口 | 作用 |
|---|---|
| 设置 → 窗口与交互 → 吸附距离 | 调整吸附半径 |
| 交互页「几何吸附」开关 | 全局开关吸附 |
| 快捷键 G（默认） | 快速切换吸附，状态栏显示「吸附：开 / 关」 |
