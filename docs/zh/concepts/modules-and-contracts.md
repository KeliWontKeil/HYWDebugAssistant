# 模块与契约

## 模块是什么

模块是用户可感知的功能单元。实现上一个模块只有三样东西：

- **入口接口**：框架按接口调用，模块不继承框架基类。
- **注册钩子**：在注册时通过上下文声明数据类型、端口、角色与内部处理顺序。
- **可选活动接口**：声明需要自发活动以及活动形式（周期或事件驱动），实现体在实例专属线程上被调用。

模块不持有框架对象引用，只能通过上下文上报状态、读写自身配置、登记活动；也不能反向查询其它模块是否存在。

## 声明面

| 项 | 内容 |
|---|---|
| 身份 | 作者与模块名两段，例如 `hyw/udp`；不含版本 |
| 元数据 | 显示名与说明，可指向模块自己的文本表 |
| 端口 | 方向、形状、传递语义 |
| 配置 | 配置类型与字段标注 |
| 视图 | 模块自己的 XAML 视图 |
| 外部接入 | 具名接入与标准标识；框架解析适配器、持有会话，数据只有原始字节（见[外部接入](external-access.md)） |
| 生命周期能力 | 是否需要自发活动、活动形式 |

内置模块与外部模块同形：同一份声明面、同一条加载路径。

## 模块标识

标识是两段字面量 `作者/模块名`：各段小写、不得为空、不得以连字符开头。标识不含版本；同一个标识只有一个注册项，"新旧"由包内容决定。

## 包与加载

- 一个包一个模块，`module.json` 是包清单。
- 只扫描程序目录下的 `modules/`（内置）与 `modules/external/`（外部导入），每个根只扫直接子目录。
- 导入外部包时先校验清单与同标识冲突，再复制进 `modules/external/`；同标识已存在时拒绝导入，不静默覆盖。
- 已载入的程序集不可替换：改动模块代码的语义是重新构建并重启应用，不提供热重载。
- 内置模块是预装的包，没有任何结构特权，与外部包走同一条发现与加载路径。

## 生命周期

| 钩子 | 时机 | 语义 |
|---|---|---|
| `OnRegistered` | 实例创建、成员实例化完成 | 声明端口、类型、角色与内部流；此时数据尚未流动 |
| `OnActivated` | 进入活动态 | 开始业务活动 |
| `OnDisabled` | 进入停用态 | 暂停数据流，内部处置由模块决定 |
| `OnEnabled` | 从停用恢复 | 恢复业务活动 |
| `OnConfigurationChanged` | 配置更新 | 热生效或请求重建由模块决定 |
| `OnRemoved` | 移除前 | 释放模块内部资源 |

钩子在实例专属线程上调用；异常不得逸出边界，由框架捕获并转为诊断。模块不得自建线程或定时器，周期与等待一律经上下文提供的计时面。

## 端口与角色

- 端口是网络的端点，也是唯一的接口与建网单位；方向只有发送与接收两态。
- 端口名在模块内唯一且稳定，连接锚定为 `实例ID.口名`。
- 端口可以引用本模块声明的数据类型；不声明时按形状判定兼容。
- 角色是模块声明的功能分块，包含功能名、类型、输入端口集合与输出端口集合；一个角色的输入与输出承载同一种类型。
- 一个端口最多属于一个角色；内部处理顺序只表达"角色到角色"的先后，零声明即零连线。

## SDK 兼容纪律

- 契约只增不改；新增可选声明一律用 `init` 属性或新类型，不用构造器可选参数。
- 改动 SDK 后必须重编全部模块。
- 没有版本门禁：按旧 SDK 编译的模块在加载或实例化失败时报错，文案带上它编译时引用的 SDK 版本，框架不比较版本区间、不提供兼容层。

## 自检

契约自检套件随**作者包** `HYWDebugAssistant.Sdk.Testing` 提供（不随宿主发布，也不得进模块包）：只依赖契约层，模块可以在自己的测试项目里引用它检查声明面。自检把"建议"与"问题"分成两条通道：建议不会让门禁失败。
