# 界面外壳与叠加层

## 多窗口外壳

- 一个模块一个窗口是默认形态：模块窗口无边框、不占任务栏，桌面即背景，没有工作区背景；外壳是拼图的起点。
- 窗口分两带：**浮动带**是外壳、模块窗口与功能面板（模块清单、诊断、设置、拓扑），最近激活者在上；**顶部固定带**是模态弹窗，永远在最上，打开时禁用低带窗口。
- 本应用内部换窗只更新 MRU；只有从**其它应用**回到本应用时，才把所有窗口按最近激活顺序做一次整组前置。关闭一个模块前先激活保留窗口，关闭后不再补激活/补抬升；多模块创建、批量关闭和最小化恢复都在一个同步事务里只应用一次层级。`ModuleLayerPlanner` 的层号只表示几何上被压住多少层，不是第二套 z 序来源。
- 任务栏与切换器只出现外壳一项。
- 相对其它应用有两种整体状态：普通与全体置顶，由应用级开关切换，不允许混合。

## 外壳结构

- 活动栏：竖向图标按钮（模块清单、组合、交互、拓扑诊断、Issue、设置、帮助与关于），选中态用可变色滑块。
- 侧边界面：模块清单、组合与交互三页常驻；设置、拓扑诊断、诊断面板、帮助与关于是弹窗。
- 底部状态栏显示模块数、Issue 数与刷新率，右侧是自动过期的临时提示；活动栏 Issue 徽标只显示错误级诊断总数，交互入口右上角另有一个**主题色模块数徽标**（贴角显示、数量为 0 时隐藏，不遮住入口图标）。
- 外壳尺寸由设置驱动，比例档位与"固定尺寸"开关决定；设置弹窗按内容自适应。

## 模块窗口

- 整块窗口矩形即模块矩形，与建网判定的几何基准一致。
- 边框覆盖整个周界；选中态叠加半透明选择框。
- 边中点与角点用于缩放，其余区域用于拖动；缩放手柄只属于锚点窗口。
- 按钮簇**贴右上角**（只留极窄边距），悬停或选中时淡入，动作为壁纸、还原、锁定、隐藏、关闭；窄窗竖排时按钮落在最右列、继续贴右缘，**不改变模块内容布局**；不存在暂停或启用按钮，生命周期由框架判定。
- 状态点与状态文本在左下角。
- 窗口不显示常驻标题；**选中时**左上角显示主题色模块名称（半透明底、不命中），便于辨认。
- 最小化/恢复主窗口时模块窗口一起跟随。
- 模块尺寸与端口位置来自**视图 XAML 声明**（尺寸在视图根，端口在 `ModuleView.Ports`）；用户拖动覆盖优先，旧模块的 C# 声明仅作兼容回退。框架地板是最小宽 96 / 最小高 160；端口标记尺寸固定，当前边放不下时**换到放得下的边**（忽略锚点固定）；窗口**实际宽度** < 200 时按钮簇与选中标题自动竖排（判定只看窗口 `Bounds`，预览器改设计尺寸同样生效）。

## 吸附与拼接

- 吸附采用参照线模型：把被拖模块外框的锚点吸到某条参照线上；锚点包括四边、中心线以及每个端口的归一化位置。
- 参照线来自**同层**其它模块的外框与端口；外壳是跨层锚点，任意层都可贴它。
- 外壳右边缘是**拼合边**：只有模块左边缘贴外壳右边缘才算吸附/成组；外壳的左/上/下边缘只作**对齐**参照，模块任一侧边都可吸齐，但不参与成组。
- 贴壳组拖动时，外壳与该组按同一物理位移整体移动；**不按 Ctrl 拖动外壳会带着全部贴壳组一起走**，按住 Ctrl 才把外壳从拼组里拖开（本次拖动内不重新粘回）。主窗口最右侧有一条细的强调色边，提示这一侧是可拼合边。
- 主窗口自身被拖动时不做主动磁吸/辅助线（系统标题栏拖动没有指针流）；磁吸由拖动模块时发生。
- **模块层由叠放顺序与重合关系派生**：同一层实体两两不重合；一个实体压在更低实体上时，层号 = 下方重叠实体的最大层号 + 1。点击/拖动/抬升改变叠放顺序，层自动重算，不保存层号。
- 只有**同层**模块/组可以吸附、成组；重合必然分层，因此不会发生跨层拼接。共享外壳不会把不同层合并：选中/抬升按本层，移动外壳带走所有层的贴壳组。
- 候选级别由线类别与交叉轴条件派生，同轴去重后只保留最高级别。
- 拖动中实时吸附；不做松手吸附，不做网格吸附。
- 组拖动时吸附候选来自**组内每个成员**的边、中心与端口，整组共用一个位移；因此两组贴边时能合并。
- 两个模块/组存在正面积重合时不算贴合、不算接触：不拼接、不自动建网；边缘恰好相接仍算贴合。
- 拼接是由位置派生的关系：只保存位置，"是否成组"由边缘贴合派生为连通分量；组不是容器，没有布局树与停靠槽位。
- 命名网络可跨层；层只约束吸附/成组，不改变数据网络语义。
- 几何单位是 DIP，每个窗口另有自己的缩放；吸附、成组、建网接触与连线都在物理像素空间比较。

## 端口标记

- 尺寸与固定槽位的唯一来源是几何度量类型；标记与外边框完全重合。
- 内容为五个固定槽位：类型窄色条、网络名、通路速率、方向箭头、连接指示灯。
- 标记上不写连接状态文本与类型文本：连接状态由指示灯的颜色与形状双重编码，类型只在悬停提示里给出。
- 标记常驻显示通路速率，与叠加层开关解耦。
- 标记可沿所在边拖动或拖到另一条边；锚点可以固定，固定后不可拖动，位置随组合件保存。
- 双击标记打开网络名编辑；留空即退出该网络。

## 叠加层

叠加信息层是调试与观测层，不是编辑层。

- 默认关闭，用快捷键 `L` 切换；设置页与快捷键入口共用同一状态源。
- 外观是灰玻璃：半透明深色遮罩压住模块内容，遮罩之上统一使用浅色墨水；不做背景模糊。
- 遮罩不参与命中，叠加层不自绘文字控件。
- 层级自下而上为：内容、遮罩、端口标记、连线层、运行指示与按钮簇；端口标记沉到遮罩之下。
- 虚线相位由一个共享时钟驱动，叠加层关闭时退订。
- 身份使用展示名与现场编号，不显示实例标识。

### 信息维度

| 维度 | 画在哪 | 内容 |
|---|---|---|
| 角色维度 | 角色方块及其周围文字 | 这块功能自己在跑多快 |
| 通路维度 | 端口标记 | 这条网络在跑多快 |

### 角色方块

- 方块数量等于实例声明的角色数量；同类型的发送角色与接收角色各一个方块。
- 方块内两行：功能名与 `m/n`；`m`、`n` 分别是输入侧与输出侧连接的对端角色数，由框架从网络成员关系派生。
- 填充取类型色，左右接口边分别取接收与发送方向色。
- 方块优先竖向堆叠；高度不足时改为横向并排，再不足时使用网格；只有所有排布都放不下时才只画得下的并标注未画数量。
- 角色自身的速率、投递与丢弃、类型语义画在方块**上方**的纯文字里；每个角色预留“信息带 + 方块”的槽位，信息块与相邻方块保持净空。
- 自回环画成外侧环线加标记。

### 连线

- 一条线是两角色方块中心的连线，每个窗口只画这条线段与自己窗口矩形的交集，且落在本端方块之外。
- 两侧严格共线：两端使用同一套角色布局与同一个线段函数。
- 虚线沿数据流方向流动；箭头画在指向本模块的一端。
- 未拼接时在窗口边界画断口与对端名；线上不写任何文字。
- 对端不可用时按对端角色、对端窗口、接口边方向三级回退，不猜测。

## 视觉基线

- 类型颜色是全局身份映射：用户覆盖色优先，否则按标识稳定哈希自动配色；改色只影响呈现，不参与建网与兼容判定。
- 方向语义色与主题色解耦；主题色只表达选中、聚焦、活动等框架语义。
- 视觉 token 是唯一来源：主题切换只替换 token 值，界面取色方式不变。
- 字号、尺寸、圆角等数值落在视觉 token 与几何度量类型里，页面与代码注释都不抄具体数值。
- 文字墨色分三档：值、字段标题、说明与提示；单位是普通文本，没有单位槽。
- 图标是显式 SVG，经图标目录取用；界面里不出现路径图形或硬编码字形。
