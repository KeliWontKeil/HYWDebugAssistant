# 数据面

## 数据单元

一个数据单元是一个定长数据报，长度等于发送端口契约的尺寸。

- 数据包不自描述：不带类型标签，框架按声明路由。需要自描述的模块在自己的契约里带字段。
- 当前只支持定长：不提供变长载荷，也不分片。
- 批量就是定长数组 `T[N]`；框架不做自动合并，那会改变时序语义。
- 负载缓冲是池化的定长扁平缓冲，只含契约字段，不含框架元信息。
- 接收侧要求到达长度不小于本端口契约尺寸；长度不足时读取返回失败而不抛异常。

## 解析三段式

| 阶段 | 谁做 | 内容 |
|---|---|---|
| 声明期读取 | 框架必做 | 注册与实例化时一次性读取端口、类型引用、视图声明、计量块与解码器；运行期不重读 |
| 传输期解析 | 框架禁止 | 框架不读数据内容，投递只按绑定走，外加长度校验 |
| 呈现期解码 | 模块负责 | 解码器由模块提供并随类型注册，框架只回调 |

## 端口

- 端口属于模块声明，是数据流的端点；一个端口只有一个方向：发送或接收。
- 方向严格单向；双向通信由两个端口与两条单向网络表达。
- 两个发送端口相接不会产生数据流：连接可以存在，但没有数据可投递。
- 一个接收端口可以接受多条网络的输入；若需要区分来源，模块应自带字段或改用多个端口。
- 端口是否参与自动建网只由是否带有网络标签决定，没有端口级开关。

## 类型声明

一条类型声明包含：标识、形状、传递语义、计量块、可选解码器与语义元数据。

- 类型身份归模块，框架只持机械镜像（标识、尺寸、语义、兼容声明），不解释"这是什么量"。
- 类型按标识索引；跨模块同名即同一类型。
- 传递语义取流、消息、事件之一；跨语义不判兼容。
- 解码器是纯函数：同字节同结果、不抛异常、不分配；未提供解码器时呈现层显示字节数，不猜测内容。
- 语义元数据（单位、量程、精度）只用于展示，不参与任何框架判定。
- 引用未声明的类型、重复声明同一标识时记录诊断并回退。
- **端口的形状必须与它所引用类型的形状完全相同**：传输按口形状算布局、计量块按类型形状算偏移，不一致在加载期报错。
- **同一标识必须是同一种形状**：两个模块声明了同标识不同形状时，加载期报一条冲突；改形状就是破坏性变更（类型没有版本）。

## 在用的约定

| 约定 | 标识 | 形状 | 尺寸 |
|---|---|---|---|
| 原始字节 | `RawBytes` | `{ len: u16, data: bytes[1472] }` | 1474 B |

`RawBytes` 的语义：

- `len` 是**有效字节数**（0–1472）；`data` 尾部补零只是定长填充，`0x00` 是合法数据、不是终止符；
- 接收方按 `len` 取有效内容，**不得按 NUL 截断**；
- 计量块声明 `PayloadLengthField = "len"` ⇒ 有效字节速率按真实有效数据计算；
- 使用者：文本发送器、HEX 发送器、数据监视器、四个外部接入模块——它们**各自声明**同一条约定，才能开箱即连。

## 形状

| 形态 | 说明 |
|---|---|
| 原语 | 有符号与无符号整数、单双精度浮点、布尔 |
| 定长字节块 | 长度有上限，上限只在 SDK 形状类型的校验里 |
| 定长数组 | 元素必须是原语 |
| 结构组合 | 字段为名称加形状，字段名唯一，顺序即签名顺序；嵌套深度有上限 |

可读描述形如 `f32`、`u64`、`f32[N]`、`bytes[N]`、`{seq:u64, value:f32}`。

## 兼容判定

判定逐（源，宿）对进行，不是整条网络：

1. 传递语义必须一致。
2. 形状必须完全一致：字段名称、原语种类、数组与字节块长度、字段顺序与数量全同。
3. 双方都声明类型时再比较标识：同标识兼容，不同标识不兼容。
4. 任一方未声明类型时只按第 2 条判定。

没有强制连接的放行路径；需要连接时把两侧声明成同一类型，或插入转换模块。框架不做自动转换。

## 命名

- 建议加作者前缀（如 `vendor/…`），跨模块同名即视为同一类型。
- 未加前缀的名字（如 `RawBytes`）是历史约定，新类型不要照抄这种命名。

## 计量块

计量块随类型声明，字段全部可选，每项都有默认语义：

| 字段 | 默认语义 |
|---|---|
| 有效载荷字节数 | 未声明即按契约尺寸计算 |
| 有效长度字段名 | 未声明即不逐单元读取，按静态尺寸计算 |
| 每单元样本数 | 未声明即按单元计，不换算样本 |
| 每样本通道数 | 未声明即不区分通道 |
| 标称速率 | 未声明即无标称值 |

速率按口径分档：单元速率按源计，搬运字节速率按宿计，有效载荷与样本速率由声明换算。计量块只用于观测与呈现，不参与建网与兼容判定。
