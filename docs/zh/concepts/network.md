# 网络模型

## 数据面语义

数据面采用 UDP 式数据报加发布订阅的模型：

| 性质 | 取值 |
|---|---|
| 连接 | 无连接：按声明建立绑定后即投递，无握手、无会话 |
| 可靠性 | 尽力而为：有界队列满即丢并计数，不做背压 |
| 顺序 | 同一（源，宿）对保持先进先出；跨源只按到达顺序，不提供跨源时间序 |
| 数据单元 | 一个定长数据报 |
| 拓扑 | 单播、多播与多发布者组合均支持 |
| 端点 | 端口；数据包不带每包地址，拓扑全部由声明派生 |
| 长度校验 | 到达长度不小于契约尺寸 |

数据面不暴露来源：需要来源的模块在自己的契约里带字段。框架不读数据也能在观测面显示多源。

## 网络

网络由源集合、宿集合、契约引用、诊断计数与状态组成。多源是一等组合，框架不隐式仲裁：接收按到达顺序投递，不做优先级、时刻排序或去重；合并与仲裁由模块承担。

端口方向严格单向，两个发送端口相接时连接存在但没有数据流。一个接收端口可以接受多条网络输入，多条网络交织为一条流，要求逐对契约兼容。

## 建网

建网有一条权威推导：每次变更提交、载入组合件或解析占位时重算，但按差量落地——身份与在场成员都相同的网络原地保留，只移除真正消失的、只新增真正出现的。全拆重建会留下"网络还在、绑定已空"的窗口，模块恰好在此刻发送就会静默丢单元。

候选来源有两条：

1. 端口网络标签同名（发送端口与接收端口逐对）。
2. 双方都未打标签、模块接触且标记对齐。

判定只有一个入口：方向（发送到接收）加契约（类型标识与形状）。预览与落地共用同一判定，因此不会出现"预告能连、松手不连"。

成员是被接受的对：端口出现在网络的源集合或宿集合里，就意味着它至少有一条被接受的配对。被拒绝的对记录具体原因（形状或标识）；几何不成立的根本不是候选，不报。

**反馈在哪看**：契约拒绝原因写入 **Issue 面板**（对象是网络名或端口对），不是端口悬停或状态栏。状态栏的“网络已设置”只表示端口标签写入成功，**不代表已经连上**；以网络成员、端口指示灯与拓扑诊断判断是否真的建网。标签内容本身非法（例如含空白）时，状态栏/编辑框会显示标签校验失败，那是另一类错误。

对齐判定共用同一实现：接触（相邻边间隙在容差内）、接触面重叠、标记对齐、双方均未打标签。容差数值只在建网判定类型里定义。

自动建网是应用级开关；关闭后只做命名网络。端口是否参与自动建网只由是否带标签决定，没有端口级开关。

## 源集合与停流

| 概念 | 定义 |
|---|---|
| 在场的源 | 已锚定、可投递的来源 |
| 悬空的源声明 | 已声明但未锚定的来源 |
| 声明的源 | 上述两者的并集，是持久化与展示的事实源 |

停流是派生量：当且仅当在场源数为零。部分源未锚定不算停流，其余源照常投递，只为该源记一条诊断。全部源未锚定即停流；无源或无宿则是未建网。

## 多源与逐对判定

投递逐（源，宿）对进行。兼容性也逐对判定：只排除不兼容的那一对并记录诊断，其余源照常投递，网络不会整条拒绝。同一宿侧存在多条网络时，按对端实例分别呈现。

## 持久化

网络记录持久化声明的源列表，而不是单个源。文件不内嵌格式版本，旧组合件不迁移，结构不合法时逐条拒绝并告警。只有命名网络落盘；按几何对齐的网络在加载后重新推导。

## 呈现

网络标签即网络名，显示在端口标记上。端口标记常驻显示该端口参与通路的有效载荷速率：未入网显示占位符，已连接但上一秒没有数据显示零值，两者可区分。速率按源计，多宿不放大；投递与搬运字节按宿计。

队列压力与丢弃的呈现带滞回：队列深度达到进入阈值并持续一段时间才显示积压，降到退出阈值以下并持续同样时间才取消；丢弃事实消失后还会保持一段时间，避免高频闪烁。阈值与时长属于「高级 → 状态显示」，只影响呈现，不改变丢弃与计数。
