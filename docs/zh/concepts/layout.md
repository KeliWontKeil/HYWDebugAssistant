## 功能根

三类持久化对象与运行期目录都在程序目录下，路径只在路径解析器里定义：

| 对象 | 位置 | 内容 |
|---|---|---|
| 应用设置 | `settings/settings.json` | 语言、外观、窗口行为、存储路径、快捷键等 |
| 组合件 | `composites/<组合名>/composite.json` | 一次保存的模块组合：模块集合、连接、配置、位置、活动面 |
| 工作区 | `workspace/workspace.json` | 当前工作区快照，用于退出保存与重启恢复 |

```
<程序目录>/modules/            内置模块包
<程序目录>/modules/external/   外部导入模块包
<程序目录>/composites/         组合件包
<程序目录>/settings/           应用设置与主题
<程序目录>/workspace/          工作区快照与资产
<程序目录>/logs/               日志
<程序目录>/resources/seeds/    出厂种子
```

应用设置与组合件完全分离：设置不随组合件保存，组合件也不写进设置目录。

## 出厂种子

只读的出厂内容放在 `resources/seeds/`，与目标目录同构：投放就是按相对路径合并进程序目录。

- 单文件在目标不存在时才复制；叶子目录作为一个投放单元整体复制。
- 已投放过的单元记录在设置里，用户删除后不会复活。
- 只做整单元投放，不改写已存在的内容；失败记录警告并撤掉本次半成品。
- 出厂设置基线不写入仓库：发布时由程序自身的命令从代码默认值生成。
