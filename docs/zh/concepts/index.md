# 深入理解

本层解释使用指南里的功能在底层怎么成立：数据怎么流动、文件长什么样、哪些地方可以手工改。

| 项 | 内容 |
|---|---|
| 读者 | 需要判断"能不能这样做"、要手工改文件、或在扩展前确认边界的人 |
| 回答 | 机制如何成立、事实存在哪个文件、改动会影响什么 |
| 不写 | 怎么操作（→ 使用指南）、怎么写模块（→ 模块开发）、仓库怎么构建（→ 项目开发） |
