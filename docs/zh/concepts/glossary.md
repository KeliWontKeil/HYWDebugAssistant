# 术语表

| 术语 | 含义 |
|---|---|
| 主应用（产品） | 发布目录中的 `HYWDebugAssistant.App.exe` 进程；它是组合根、模块宿主与窗口呈现者。模块包导入这个进程，不存在第二个外部挂载程序 |
| 宿主 | 承载模块实例的运行时组合根；当前就是主应用。`Hosting` 是它使用的库，不是第二个可执行程序 |
| 宿主程序集 | 主应用提供给模块的框架程序集（`Sdk*`、`Access*`、Avalonia 等）；模块包不得携带 |
| 预览宿主 | 只给 Avalonia 设计器提供 `Application`、主题与程序集加载目标的开发期可执行工程；不创建模块实例，不是交付物 |
| 独立宿主 | 仓库内 `tools/StandaloneModuleHost`：门禁按真实加载路径装入包并校验声明；不随产品/SDK 发布 |
| 框架 | 主应用内的库层（`Sdk`、`Hosting`、`DataPlane`、`Core`、`Ui` 等），向模块提供上下文与运行时服务；不是独立进程 |
| 模块 | 独立的业务单元，以包的形式加载，向框架声明端口、数据类型、命令与界面 |
| 模块包 | 模块的分发单位，包含模块自身程序集、清单与自有资源，不含宿主提供的程序集 |
| 端口 | 模块的数据流端点，方向为发送或接收 |
| 端口标记 | 画在窗口边缘的口标签：类型色条、网络名、通路速率、方向箭头与连接指示灯 |
| 数据类型 | 模块声明的定长数据结构，包含标识、形状、传递语义与计量口径 |
| 形状 | 类型的布局：原语、定长字节块、定长数组或结构组合 |
| 契约 | 端口声明的类型引用与方向，是建网与兼容判定的依据 |
| 数据单元 | 一个定长数据报，长度等于发送端口契约的尺寸 |
| 网络 | 一条从源集合到宿集合的通路，分为命名网络与按几何对齐的直连网络 |
| 绑定 | 网络落地后，源端口到宿端口的投递关系 |
| 停流 | 网络没有在场源的状态；它是派生量，不单独保存 |
| 悬空 | 网络的成员重新接入失败、暂时不参与传输的状态 |
| 计量块 | 类型声明中描述有效载荷、样本、通道与速率的可选字段 |
| 角色 | 模块声明的功能块，用于叠加层呈现与信息维度 |
| 叠加层 | 覆盖在窗口之上的诊断呈现层，显示端口、网络与角色信息 |
| 显示源 | 模块声明给界面读取的一条数据通道（值、序列、文本等） |
| 命令 | 模块声明的动作名，由界面按钮触发 |
| 收件箱 | 框架投递给模块的命令与输入队列，模块在实例线程上消费 |
| 定时器 | 模块经上下文创建的周期触发器，由框架调度，Tick 在实例线程执行 |
| 状态行 | 模块窗口左下角的一句状态文本，由模块提供 |
| 外部接入 | 框架托管的一路设备连接（串口 / TCP / UDP）；模块只声明标准并读写字节 |
| 会话 | 一个外部接入的运行时状态：未打开、正在打开、已打开、正在关闭、故障 |
| 适配器 | 实现某个外部标准的框架侧实现件，对上只交原始字节 |
| 组合件 | 保存窗口布局、连接关系与模块配置的文件夹 |
| 工作区 | 当前现场的自动快照，用于退出保存与重启恢复 |
| 诊断条目 | 框架或模块上报的一条问题，带归属对象、类别、来源与时间 |
