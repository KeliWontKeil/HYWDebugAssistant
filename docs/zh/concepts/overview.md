# 系统概览

## 定位

本产品是一个面向工程人员的模块化数据处理、通信与可视化工作台。用户的操作模型是：选择模块、放入工作区、配置、拼接，随后即可使用。

用户不需要理解消息、通道、队列、订阅、路由、线程或运行时绑定等底层概念；这些属于框架内部机制。

## 系统由什么组成

| 部分 | 作用 |
|---|---|
| 模块 | 功能单元，以包的形式加载；声明端口、数据类型、命令与界面 |
| 框架 | 负责模块加载、组合校验、建网、数据投递、诊断与界面外壳 |
| 组合件 | 保存窗口布局、连接关系与模块配置的文件 |
| 资源 | 文本表、图标、主题与模块自有资源，与程序分离 |

## 数据如何流动

数据以定长数据报的形式在进程内投递：模块声明发送与接收端口，网络把发送端口与接收端口连接起来，框架按绑定直接投递，核心管理面不中转数据。外部设备通信由模块承担，框架的数据面只负责模块之间的通路。

## 能力边界

- 数据面是进程内的数据报模型，不替代真实网络协议；跨进程与跨机通信不在当前能力内。
- 不提供脚本化扩展接口；扩展以模块为单位。
- 版本处于开发期，允许破坏性变更，规则见[版本与兼容](../reference/versioning.md)。
- 界面、交互与观感仍在迭代，截图与教程在发布前补齐。
