# 项目开发

本层面向本仓库的维护者：代码在哪、怎么构建与验证、版本怎么走、文档怎么写。

| 项 | 内容 |
|---|---|
| 读者 | 修改仓库代码或文档的人 |
| 回答 | 目录与程序集怎么分、构建与门禁怎么跑、版本与文档规则是什么 |
| 不写 | 产品功能怎么用（→ 使用指南）、机制为什么这样（→ 深入理解） |
