# 关于

何译位调试助手是一个桌面端数据调试工具：把串口、TCP、UDP 等外部连接接入统一的数据流环境，用于收发数据、观察流量，并把多个连接组合成一条数据流。

## 产品形态

- Windows 桌面应用，采用多窗口拼图式界面；模块以独立包分发，可增删。
- 内置模块覆盖串口、TCP、UDP 等连接与常用数据工具；完整清单见[模块清单](../reference/modules.md)。
- 模块与框架通过声明式契约连接：模块声明端口、数据类型与界面，框架负责加载、建网与投递。

## 能力边界

- 数据面是进程内的数据报模型，不替代真实网络协议；与设备通信由模块承担。
- 不提供脚本化编程接口；扩展以模块为单位。
- 版本处于开发期，允许破坏性变更，规则见[版本与兼容](../reference/versioning.md)。
