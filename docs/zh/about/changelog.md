# 更新日志

每个交付版本的改动，新的在上。写用户能感知的变化：新增了什么、改了什么行为、修了什么问题；不写内部提交号与代码结构。

## 0.2.1.3

**2026-11-27**

上一版加的同名询问在真实操作里**完全没出现**，两个原因都已修掉。

- 修复：默认目录里已有**内容完全相同**的同名组合时，导入被当作「已复用」直接放行，不弹任何提示——询问机制等于失效。现在判定只按名字：名字被占用就问，与内容是否相同无关。这也与资源管理器一致（它只比名字）。
- 修复：拖入或选中一个**只装组合包的外层文件夹**时，冲突列表没有被收集，导入绕过询问并直接报失败。现在这类文件夹与其他入口走同一套询问。
- 修复：把默认目录里的组合包再"导入"一次时，包形态的替换顺序会先删旧目录再改名——来源就是目标时会把自己的目录删掉。现在这种情形直接无操作返回。
- 文档：导入页面把「同名**且内容不同**时」改为「已有同名项时」；设计说明补充为什么不再比较内容。

## 0.2.1.2

**2026-11-27**

导入外部组合件或模块包时，如果默认目录里已有同名项，过去会**悄悄改名成「名字-2」**，界面上却显示成"已导入"。现在改成先问一句。

- 新增：同名时逐条询问「替换 / 跳过 / 取消」，并可勾「为所有同名项执行此操作」一次决定整批，与 Windows 复制文件撞名时的做法一致。取消则整批不再导入，已经导入的项保持原样。
- 修复：导入同名项不再自动加序号。不去问、也没有选择时按失败处理并说明原因，不会留下来源不明的副本。
- 修复：导入后的提示显示**实际落地的名字**，不再是来源名（过去同名换了名字时，提示与列表对不上）。
- 替换不保留副本：手动选替换即视为已知风险。但不会写到一半——先复制到临时目录，成功后才替换，失败时旧内容原样保留。
- 模块包多一条保护：若同名包目录正被**已加载的模块**使用，直接失败并说明占用者；替换它等于删掉正在运行的包。
- 文档：导入相关页面补充撞名处置说明。

## 0.2.1.1

**2026-11-27**

模块清单加了两个识别的线索，另外把界面文本按用途分开维护。

- 新增：模块清单的图块外圈显示**数据类型颜色**。同一类型在哪都同色（与端口标记的色条、叠加层的角色方块同源）；转换器这类同时管两种数据的模块，外圈一色一半；没有端口的离线工具不画圈。鼠标停在行上会说明这圈颜色是什么。
- 新增：模块清单的图块显示**模块封面**。过去所有模块都只有占位字形，原因是没有任何内置模块带封面图——现在随包带了，且作者把 `preview.png` 放到模块工程根目录就会进包，不用改项目文件。
- 修复：换过模块封面后，界面会提示「需重启应用生效」。封面不承载代码，换图不需要重启。
- 修复：只改模块封面时，重新扫描可能不重新归拢，包里的图一直是旧的。
- 调整：界面文本按用途分开维护——用户会看到的中短文本、专业报错、长说明各一份文件。这样改界面措辞时不必在几百条报错里逐条分辨，改报错时也不会顺手把措辞改得不准。中文、模块作者的表不受影响。
- 文档：修正了「让封面进包」的写法（原来给的项目文件条目对包不起作用）；补充分片与分层的说明。

## 0.2.1.0

**2026-11-25**

模块间吸附的两个遗留缺陷，根因是同一处设计分叉，已按下述规则一次改齐。

- 修复：压在主窗口上的模块无法吸附到其它模块。此前只要模块与主窗口有重叠，所有候选位置都被判为遮挡，表现为拖动时既不吸附也不出现对齐标线。
- 修复：不同层的模块之间能贴合但不能对齐。此前跨层参照只提供贴合候选，边对齐与中线对齐从不参与，表现为"能拼上、对不齐"。
- 规则统一为：**能否吸附、能否拼接只看几何**，贴合、边对齐、端口对齐与尺寸相等都不看层；层只用于判断"落位新增的遮挡看不看得见"。
- 遮挡判据改为只看**增量**：拖动开始时就已经重叠的窗口不参与判定，新增重合才拦；压住更低层的窗口允许，模块落在它们之上。
- 缩放吸附同步调整：移动边可吸到任意层窗口的外框边，不再按层筛选。

**其它改动**

- 修复：发布产物启动后窗口一片空白。裁剪清单把渲染链上被间接引用的组件当成"其它平台后端"删掉了，程序照常启动、不报错，只是什么都不显示；现按**渲染链闭合**判定，发布与校验都会自动拦住这类缺件。
- 图片框更名为**图片显示器**，文案随模块更新；界面、文档与内置名称保持一致。
- 发布产物改为落在工程目录下（与仓库并列），不再放到其它磁盘目录；脚本报错提示与文档示例同步。
- 发布工具链收敛：产物裁剪清单与校验清单共用一份定义，避免两份枚举漂移；新增临时产物审计，构建中途留下的散文件与第二临时根会被门禁拦下。
- 文档工作方式调整：更新日志、模块目录与首页"最近更新"改为**手写**，仓库不再包含生成文档正文的脚本；文档站仅作为本地预览工具。
