# 术语表

| 术语 | 含义 |
|---|---|
| 模块 | 独立的业务单元，以包的形式加载，向框架声明端口、数据类型、命令与界面 |
| 模块包 | 模块的分发单位，包含模块自身程序集、清单与自有资源，不含宿主提供的程序集 |
| 端口 | 模块的数据流端点，方向为发送或接收 |
| 数据类型 | 模块声明的定长数据结构，包含标识、形状、传递语义与计量口径 |
| 形状 | 类型的内存布局：原语、定长字节块、定长数组或结构组合 |
| 契约 | 端口声明的类型引用与方向，是建网与兼容判定的依据 |
| 数据单元 | 一个定长数据报，长度等于发送端口契约的尺寸 |
| 网络 | 一条从源集合到宿集合的通路，分为命名网络与按几何对齐的匿名网络 |
| 绑定 | 网络落地后，源端口到宿端口的投递关系 |
| 组合件 | 保存窗口布局、连接关系与模块配置的文件 |
| 停流 | 网络没有在场源的状态；它是派生量，不单独保存 |
| 计量块 | 类型声明中描述有效载荷、样本、通道与速率的可选字段 |
| 角色 | 模块声明的功能块，用于叠加层呈现与信息维度 |
| 叠加层 | 覆盖在窗口之上的诊断呈现层，显示端口、网络与角色信息 |
