# 端口与数据类型

本页是端口语义与类型兼容的速查。机制层面的完整解释见[模块与契约](../concepts/modules-and-contracts.md)与[数据协议](../concepts/data-protocol.md)。

## 端口

- 端口属于模块声明，是数据流的端点；一个端口只有一个方向：发送或接收。
- 方向严格单向；双向通信由两个端口与两条单向网络表达。
- 两个发送端口相接不会产生数据流：连接可以存在，但没有数据可投递。
- 一个接收端口可以接受多条网络的输入；若需要区分来源，模块应自带字段或改用多个端口。
- 端口是否参与自动建网只由是否带有网络标签决定，没有端口级开关。

## 数据类型

类型声明包含：标识、形状、传递语义、计量块、可选解码器、语义元数据。

- **形状是尺寸的唯一来源**，由定长字节数表达，可组合为原语、定长字节块、定长数组与结构。
- **类型身份归模块**：标识建议带模块前缀，跨模块同名即视为同一类型。
- **传递语义**取流、消息、事件三者之一；跨语义不判兼容。
- **计量块**只影响观测口径（有效载荷、样本、通道、速率），不参与兼容判定。
- **解码器**由模块提供，用于呈现层；未提供时显示字节数，不猜测内容。

## 兼容判定

判定逐（源，宿）对进行，顺序固定：

1. 传递语义一致；
2. 形状完全一致（字段名称、原语、长度、顺序、数量全同）；
3. 两侧都声明类型时，类型标识相同；
4. 任一侧未声明类型时只按第 2 条判定。

不兼容即拒绝，没有强制放行的路径。需要连接时，把两侧声明成同一类型，或插入转换模块。框架不做自动转换。

## 网络状态

- 网络由源集合、宿集合、契约引用、诊断计数与状态组成。
- **停流是派生量**：在场源数为零即停流；部分源未锚定不算停流。
- 未建网（无源或无宿）与停流是两种不同状态。
- 只有命名网络会持久化；按几何对齐的网络在加载后重新推导。
