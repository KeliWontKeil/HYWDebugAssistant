# 模块开发

**谁读**：不接触本应用源码、拿到产品发布目录与独立 SDK 目录的模块作者。
**回答什么**：怎样从模板做出一个可构建、可装载/运行的模块；带界面的模块再加设计期预览。
**不写什么**：框架内部实现、仓库自身结构与版本历史——那些在[项目开发](../project/index.md)与[深入理解](../concepts/index.md)。

## 你需要什么

| 需要 | 说明 |
|---|---|
| 独立的 SDK 目录 | 产品发布产物之外的 `HYWDebugAssistant.Sdk-<版本>/`：五个作者包、一个模块模板、README；获取与版本见 [SDK 与版本](sdk-version.md) |
| .NET SDK | 版本见产品说明；模板的 `TargetFramework` 已写好 |
| 可选：Avalonia 扩展 | VS 或 Rider 的 Avalonia 扩展，用来预览模块界面 |

## 先选一条路线

所有路线都从 `template/ModuleTemplate` 开始；生产模块只作为行为参考，不随产品/SDK 分发源码。

| 你的模块 | 起步 | 必读页 |
|---|---|---|
| 只做数据变换（转换、解析、聚合） | 模板，删除视图与 `Sdk.Ui` 引用 | [从零开始](quickstart.md) → [声明面](contracts.md) → [实现](implementation.md) |
| 有窗口、按钮、读数 | 模板 | 再加 [界面](ui.md) 与 [控件](controls.md) |
| 接串口 / TCP / UDP 设备 | 模板 + 参考 `hyw/serial` 的行为 | 再加 [实现](implementation.md) 的“外部接入”与[外部接入](../concepts/access.md) |
| 定时采集、周期发送 | 模板的定时器 | 再加 [自发活动与定时器](activity.md) |

## 建议阅读顺序

1. [从零开始](quickstart.md)：复制模板、改身份、构建、导入、运行，先得到能跑的最小闭环；
2. [模块结构](anatomy.md)：知道一个模块由哪七层组成、每层失败时是什么现象；
3. [声明面](contracts.md)：把类型、端口、角色、显示源、输入、命令声明正确；
4. [实现](implementation.md)：生命周期、收发、配置、上报、显示、文件与外部接入；
5. [界面](ui.md) 与 [控件](controls.md)：视图工厂、刷新、尺寸、主应用验收与设计期预览；
6. [测试与验证](testing.md)：契约自检与行为测试；
7. [发布与装载](publishing.md)：打包、导入、重启与被拒原因。

写代码时随时查 [接口参考](reference.md)：那里列出每个成员、默认值与失败方式。

## 完成判据

所有模块必须满足三件事：

- **可构建**：在仓库外只引 SDK 目录里的作者包，`dotnet build -c Release` 成功，产出 `bin/module-package/Release/<包名>/`；
- **声明面自检**：`ModuleContract.Probe` 的 `Problems` 为空（见[测试与验证](testing.md)）；
- **可装载并运行**：主应用「模块清单」能导入包目录并加入现场；带界面的模块窗口出现，端口、命令与数据按声明可用。

带界面的模块**额外**满足：

- **可预览（仅设计期）**：模块视图的 `.axaml` 能在 Avalonia 预览器中显示带样式的控件、预览值与配置字段。预览只证明 XAML 设计面可加载，不证明实例、生命周期、端口、命令或数据流；不能代替上面的装载/运行验收。

纯数据模块没有视图，不因“不可预览”而不完整。运行形态与预览边界见[模块结构](anatomy.md)和[界面](ui.md)。

## 兼容性验收

如果模块要与**既有类型约定**交换数据（例如 `RawBytes`、`WaveformFrame`），完成判据再加一条：

- 必须与**至少一个内置模块**建网成功，并看到数据流动；
- 只与你自己做的两个新模块互连，只证明两边自洽，**不能证明与既有约定兼容**；
- 建网失败的具体原因在 Issue 面板，不在状态栏或端口悬停里；状态栏的标签设置成功不代表已连接。

内置对端的契约以[数据面](../concepts/data-plane.md)与[波形帧约定](../concepts/waveform-frame.md)为准。`Sdk.Testing` 没有对端比对 API，作者不能用它替代这条实测；现行验证方法见[测试与验证](testing.md)。

## 卡住时

| 现象 | 先看 |
|---|---|
| 还原或编译失败 | [SDK 与版本](sdk-version.md)、[项目与包布局](project-layout.md) |
| 导入被拒 | [发布与装载](publishing.md) 的“被拒原因” |
| 界面空白、没有样式（预览期） | [界面](ui.md) 的“预览排障” |
| 装载后窗口空白、配置字段为空 | [发布与装载](publishing.md) 的加载说明 |
| 连不上、收不到数据 | [声明面](contracts.md)、[实现](implementation.md) 的收发与外部接入 |
| 命令不执行、输入收不到 | [实现](implementation.md) 的“收件箱”、[自发活动与定时器](activity.md) |
| 报文被切碎或粘包 | [外部接入](../concepts/access.md) 的“块边界不承诺” |
