## 0.1 怎么跑起来

1. **关闭正在运行的应用**（否则构建写不进 `App` 输出）。
2. 在工程根执行：

```powershell
.\build.ps1                    # 完整门禁，应全绿
.\tools\dev.ps1 -Mode Run      # 启动应用（先停掉 VS 设计器宿主，避免文件锁）
```

**预期**：外壳窗口出现；正式模块包已自动装入 `modules\`（`text-sender` / `hex-sender` / `data-monitor` / `hex-string-converter`），无需手工选路径。

### 0.1 先看图，再动手（可选）

```powershell
dotnet test tests\HYWDebugAssistant.VisualSnapshots\HYWDebugAssistant.VisualSnapshots.csproj
```

打开 `%TEMP%\hyw-overlay-snapshot\*.png`：叠加层用例留下的窗口快照 + 调色板窗口快照 = **真实渲染结果**。先对照第四节，再启动应用确认交互与手感。

### 0.2 前置与标记

**前置**：① 基础功能可用（外壳与多窗口 · 建网与拓扑 · 配置 · 人机操作三通道 · 持久化与设置）；② 正式模块包（见 §0 预期）可装入可用；③ 先跑一次完整门禁（§0）。

**每条的覆盖标记二选一**：

- 〔**自动化**：`<测试类名>`〕= 已有测试承载该判据，手工只需**抽查**；
- 〔**仅人工**〕= **只有人可判**（观感 / 手感 / 端到端体验）。
