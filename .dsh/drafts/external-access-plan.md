| D8 | **外部接入不入网**：源 / 宿仍只属网络模型；口仍是唯一建网单位 | 标准 §2.1 |
| D9 | **连接操作链**：用户在模块窗口点〔打开 / 关闭〕→ **模块只发起请求**（自己也不操作连接）→ **框架执行并持有会话**；模块窗口必须有这对按钮 | 标准 §1-6 |
| D10 | **UI 不为本轮新增快照用例**：配置表单与状态灯这类界面**在模块里直接看**（用户裁决：历史经验表明这类快照极不可靠） | 用户 2026-10-13 |

## 6. 风险与探针（含验不过的退路）

| # | 风险 | 探针 / 处置 | 验不过的退路 |
|---|---|---|---|
| R1 | 模块包携带的**原生资产**（`runtime.native.System.IO.Ports`）解析不到 | P0.2 | 把原生资产复制到包根并注册解析路径（P0.3）；仍不通 ⇒ 登记 `ARCH-EXCEPTION` 并把串口模块降级为"随应用发布" |
| R2 | 串口的"就绪"托管层没有真异步 | P2.2 用自带泵 | 泵线程改事件驱动；两者都记入验收（线程数） |
| R3 | 会话关闭超时 ⇒ 孤儿线程 | P1.2 停止协议用例 | 收窄适配件的关闭超时为停止超时的分数；验收专列一条 |
| R4 | 框架层被协议词污染 | AR-13 既有规则 | 契约与承载只写"接入 / 会话 / 字节"，协议词只在 `src/Access` |
| R5 | 四个包携带的 `Access` 版本不一致 | P0.2 门禁 + 同一构建产出 | 门禁校验四包内该文件一致 |
| R6 | 配置表单是 D4 的前置，若 P0.1 推迟则整条链阻塞 | P0.1 排在最前 | 无退路：D4 依赖它；若暂不做，则参数只能手写文本（记录为降级） |

## 7. 不做（本轮范围外）

- 框架内置协议实现（TCP/UDP/串口代码不进框架层）
- 外部接入的**用户面形态**（无端口标记、无叠加层节点、无框架画的图；状态与计数由模块控件表现）
- 载荷内来源标识 · 每客户端独立端口 · 每客户端独立源
- 异步 I/O（模块侧）· 数据回显（属数据监视器）
- 诊断面板对会话的专门视图（属增量，后续按需）
- 波形 / FFT / 协议解析等第三批能力
