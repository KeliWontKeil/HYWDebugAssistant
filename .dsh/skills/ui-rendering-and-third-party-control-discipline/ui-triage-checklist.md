# UI 排障查序表与提交前自检

## 一、三条主线的查序（照顺序走，不要跳）

### 主线 A：看不见 / 画不出来

1. **有没有模板/样式？**（第三方或模板化控件的第一问：模板是否在自己的程序集里、是否已显式挂载；"自带"≠"自动生效"）
2. **有没有尺寸？**（高度/宽度是否被自适应压成极小；内容是否根本没渲染出来）
3. **有没有被裁？**（父容器是否内缩 / 是否开了裁剪；贴边的元素是否有一半落在裁剪区外）
4. **有没有被盖？**（层级顺序：谁在谁上面；不透明块会盖住线；透明遮罩是否吃掉了事件）
5. **可见性判据是否直接排除了它？**（很多"看不见"的根因在**判断**，不在绘制）
6. **真的画了吗？**（自绘路径：几何建好后是否真的调用了绘制；是否有断言证明"画出来了"）

### 主线 B：点不到 / 命中错

1. **层级顺序**是什么？（内容 → 交互带/手柄 → 标记层 → 遮罩 → 按钮簇 …按需固定，写进文档）
2. **手柄类是否只在选中/可交互时可命中？**（"垂直居中"的手柄与"垂直居中"的标记必然重叠——这是经典冲突）
3. **"唯一入口"控件是否在最上层？**（如果某个功能只有一个人口，它必须优先命中）
4. **遮罩/装饰层是否设了"不参与命中"？**（视觉变暗但必须仍可点）
5. **元素的字号/对比度/尺寸是否足够"一眼可见"？**（否则用户会认为功能不存在）

### 主线 C：改了没生效 / 还是老样子

1. **有没有消费者？**（开关可改可存但没人读 = 死开关）
2. **有没有绑定/读取？**（加字段的同一笔改动里是否写完了生产者与消费者）
3. **有没有重绘声明？**（改了画刷/颜色但没有失效通知 ⇒ 要等别的操作才刷新）
4. **改动真的被加载了吗？**（产物是否重编、是否被缓存、是否有第二条实现路径覆盖了它）
5. **是不是两处状态各写一遍？**（"谁最后跑谁赢" ⇒ 表现为随机、时好时坏）
6. **这个值在声明文件里有没有键？**（找不到 = 写死在引擎或模板里；先判它属于"语义/布局"（该补声明键）、"外观"（该进全局主题）还是"共有外壳"（框架固定但必须能被显式列举））

## 二、自绘控件提交前自检

- [ ] 坐标口径唯一（要么全物理像素、要么全逻辑单位；换算集中在一处）
- [ ] 跨窗口/跨容器几何经过**显式换算函数**，没有"看起来对"的隐式假设
- [ ] 两端算同一件事时用的是**同一个尺寸变量**
- [ ] 贴边元素已按"线宽/2"内缩，且可见性判据容忍贴边超出
- [ ] 留白是按"最坏情况下线的实际长度"算的，并已写进几何用例
- [ ] 极窄尺寸有**明确退化策略**（不重叠、不越界、省略数量如实标出）
- [ ] 每个公开属性都有消费者；每处绘制路径都有断言或渲染快照证明"画出来了"
- [ ] 需要重绘的属性都已声明失效
- [ ] 画面里的并行信息已按字号分层；没有把两种语义塞进同一行
- [ ] 有一条**真实渲染成图片**的路径可以看结果（不必每次启动应用）
- [ ] 每个影响渲染的值都能指出它的**声明键**（或明确归入"全局主题"或"共有外壳"两类之一），没有"没声明就这样"的字面默认
- [ ] 注释里没有当前坐标 / 尺寸 / 像素值（写意图与关系；具体值指向唯一来源，由注释审计在门禁拦下）
- [ ] 没有把模块视图/窗口的可调宽度、高度、最小尺寸、间距抄进测试当期望值：改 `.axaml` 尺寸不应让测试红；测试只断言"声明 → 模型"的来源关系或"至少填满/不小于"的边界

## 三、高频根因速查

| 现象 | 最可能的根因（按概率） |
|---|---|
| 控件整个不出现，且无报错 | 模板/样式没挂载 → 自适应把高度压没了 → 被裁/被盖 |
| 差 1 个像素的缝 / 系统性错位 | 参照基准取错（客户区 vs 可见外框）；两端尺寸来源不同；两处各自取整 |
| 拖动方向上的抖动（另一个方向正常） | 拿"被自己移动的对象"当输入基准 ⇒ 正回授 |
| 靠近目标时才抖 | 多个候选挤在几像素内 ⇒ 缺粘滞/双向阈值/同坐标去重 |
| 底部/右侧看不见参考线，顶部/左侧正常 | 贴边元素被裁剪，或可见性判据把"贴边超出"排除了 |
| 鼠标指上去不停闪 | 刷新在重建集合 ⇒ 目标控件被换成新对象（对象身份问题） |
| 某个数一直是占位符/0，不报错 | 两个键空间混用；或指标不可重复读（第一个消费者之后全读 0） |
| 只有一个消费者拿到数据，其它全是空 | 观测型指标不幂等（读的时候重算并改写基准） |
| 画了没效果 / 箭头从来没出现 | 几何建好没调用绘制；属性无消费者；缺重绘声明 |
| "单独跑绿、一起跑红" | 静态/单例/全局资源字典里的可变对象（线程亲和、缓存） |
| 改成"看起来更聪明"的几何后端点乱跳 | 用了方位分类/平均位置等业务推断去补几何；改回两点一线 |
| 用户说"做减法"但越改越花 | 把降权做成了"加一层/加样式"（加法）而不是"沉到下层"（减法） |
| 代码改了布局，注释里的"48×24 / 左边距 3px"没跟着改 | 注释在复述当前取值 ⇒ 必然漂移 | 删数字、写关系；由注释审计在门禁拦下 |
